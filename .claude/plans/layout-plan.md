## 二、逐栏组件拆分

### Col 1 — 迷你走势栏
5 个统一样式小卡片，每卡 = 图标+标题 / 折线图 / 底部图例

| # | 标题 | 曲线 |
|---|---|---|
| 1 | XRepo 行情 | 1 / 7 / 14 / 21 / 28 |
| 2 | 非银最优 | 1 / 7 / 14 / 21 / 28 |
| 3 | 交易所回购 | GC001/GC007/GC014/R-001/R-007 |
| 4 | 资金情绪指数 | 情绪指数/大行/中小行/非银，含 "51 平衡" 徽章 |
| 5 | NCD 利率走势 | DR001/DR007/GC001 |

### Col 2 — 行情明细表
3 个垂直堆叠表格：

**2.1 XRepo 行情**：期限|(亿)|逆回购|正回购|(亿)|发送 ; 行 R001/R007/R014/R021/R028
**2.2 非银最优**：期限|量|逆|正|量|发送 ; 行 R001/R007/R014/R028/R028+（R007 默认高亮）
**2.3 交易所回购**：行 GC001/GC007/R-001/R-007/R-014/R-028

色规则：逆回购绿、正回购红（A 股色系）

### Col 3 — 机构明细表

**3.1 大行机构**：银行|(银)|逆回购|正回购|(非)|发送 ; 工商/农业/建设/中国
**3.2 非银报价**（带搜索框 "指定机构："）：长列表，15+ 行，可滚动 ; 联动 Col 2.2 的期限

### Col 4 — 机构走势/结构

**4.1 大行机构走势** — 折线：工商/中国/农业/建设
**4.2 指定机构走势** — 折线（Y 百分比 0-8%）：中泰/中信/鹏扬/北银理财/中欧
**4.3 机构资金结构**（可折叠）— 4 根堆叠柱（日期 03/27-04/02），层：大行/中小行/货币/券商/理财子/保险
**4.4 NCD 利率走势** — 折线 DR001/DR007/GC001

### 底部 — 趋势一览
宽图跨 Col 2+3，高 ≈280px
5 条线：交易所-R-001 / 非银最优-R001 / 中信证券-R001 / 大行-工商银行 / Xrepo-R007
