## 3. 左侧面板

### 3.1 大行利率展示区

| 交互 | 触发方式 | 效果 |
|------|---------|------|
| 手工输入 | 点击按钮 | 打开 手工输入当日利率的页面弹框 |
| 弹框编辑 | 文本框输入 | 修改 （草稿，不影响展示） |
| 保存 | 点击"保存" | 将草稿写回大行利率展示区，关闭弹框 |
| 取消 / 关闭 | 点击"取消"或右上角"✕" | 丢弃草稿，关闭弹框 |
| 重置 | 点击"重置" | 草稿恢复为初始默认值,从数据库获取 |
| 下载 | 点击按钮 | 下载当前利率数据 |

**表格列含义（当日大行价格，5 列）：**

| 列名 | 含义 |
|------|------|
| 机构 | 报价机构名称（大行/股份行等） |
| 非银利率 | 对非银行机构的融出利率（绿色显示） |
| 银行利率 | 对银行机构的融出利率（红色显示） |
| 涨跌bp | 相较上日的利率变动，单位 basis point |
| 更新时间 | 最近一次报价更新时间 |

> 这里存在能否进行数据库写操作的问题,以及一人修改是同步全局还是同步当人的策略选择
>
> 解决方式:根据用户身份权限进行同步,交易员管自己的, 主管或者投资经理可以同步全局

### 3.2 XREPO 表格列含义（8 列）：

| 列名 | 含义 |
|------|------|
| 期限 | 回购品种，如 R001 / R007 |
| 可点击量（左） | 正回购侧可成交笔数 |
| 正回购金额 | 当前正回购报价金额 |
| 正回购利率 | 正回购报价利率（红色，融资成本） |

### 3.4 NCD 行情卡

**状态一览：**

| 状态 | 类型 | 取值 | 默认值 |
|------|------|------|--------|
| `市场` | 市场切换 | `一级市场` / `"二级市场"` | `"一级市场"` |
| `模式` | 显示模式 | `"表格"` / `"图表"` | `"图表"` |
| `期限` | 期限（仅一级） | `"1M"` / `"3M"` / `"6M"` / `"9M"` / `"1Y"` | `"1M"` |
| `展开弹窗` | 展开弹框 | `boolean` | `false` |

**Header 交互（单行）：**

```
NCD  [一级] [二级]  |  [1M][3M][6M][9M][1Y]  →  [趋势图][表格]  [⤢]
                         ↑ 仅 market=primary 时显示
```

| 交互 | 触发方式 | 效果 |
|------|---------|------|
| 切换市场 | 点击"一级" / "二级" | 更新 `市场`；切到"二级"时期限 tab 隐藏 |
| 切换期限 | 点击期限 tab | 更新 `期限`，折线/表格数据联动刷新 |
| 切换模式 | 点击"趋势图" / "表格" | 更新 `模式` |
| 展开 | 点击 ⤢ 图标 | `expanded = true`，弹出NCD一级的数据展示 |
| 收起 | 在 Modal 中点击 ↙ 图标或点击遮罩 | `expanded = false` |

**内容路由：**

| 市场 | 模式 |  内容说明 |
|--------|------|---------|
| `一级` | `趋势图` |  4 条折线：国有/股份制、AAA、AA+、AA |
| `一级` | `表格` |   矩阵表格，4 列（等级）× N 行（银行） |
| `二级` | `趋势图` |  3 条折线：1M、3M、1Y |
| `二级` | `趋势图` | 5 行期限表：最新价 / 涨跌bp / 参考收益 |

**期限数据联动（仅一级）：**

- 利率偏移量：`1M` / `3M` / `6M` / `9M` / `1Y`
- 折线图：从后台接口获取实际数据
- 矩阵表格：每个银行利率加偏移，表头标题同步显示选中期限

**矩阵含义（一级表格）**

- **列**：4 个信用等级分组 — 国有/股份制 / AAA / AA+ / AA
- **行**：各信用等级下的银行，按利率由低到高排列
- **单元格字段**：
  - 银行名称（左侧，灰白色）
  - 发行利率（右侧，琥珀色 `text-amber-400`，已加选中期限偏移）
  - 变动幅度（利率右侧，翠绿色，如 `+2.5`，单位 bp，可选）

**NCD 二级表格列含义**

| 列名 | 含义 |
|------|------|
| 期限 | 到期期限档位（1M / 3M / 6M / 9M / 1Y） |
| 最新 | 最新成交收益率（%），绿色显示 |
| 涨跌bp | 相较上日变动量，单位 basis point |
| 参考收益 | 综合参考收益率（%） |
| 更新时间 | 最近更新时间戳 |

## 4. 主报价板 MainQuoteBoard

**状态一览：**

  | 类型 | 取值 | 说明 |
|------|------|------|
  | 展示层级 | `1` / `2` | 1=只看最优/次优；2=展开全部报价 |
 | 激活分组 | `"逆回购"` / `"正回购"` | 逆回购 / 正回购 |


| 交互 | 触发方式 | 效果 |
|------|---------|------|
| 切换层级 | 点击"1级" / "2级" | 更新面板；2 级时显示可拖拽分隔条 |
| 激活分组 | 点击某分组行 | 更新面板，高亮对应分组 |
| 拖拽分隔条 | mousedown 后 mousemove | 实时更新 页面分割比例，范围锁定 15%–85% |
| 释放拖拽 | mouseup | 停止拖拽，分割比例 写入本地存储, 切换回2级状态不丢失 |
| 发送报价 | 点击行内"发送"按钮 | 触发报价发送逻辑 |

**行过滤规则：**

| 层级 | 展示内容 |
|---|---|
| `1` | 仅"最优"和"次优"排名的行，按品种期限规则过滤 |
| `2` | 全部行，排序：最优 > 次优 > 其他报价 |

**报价行列含义（7 列）：**

| 列名 | 含义 |
|------|------|
| 分组 / 机构 | 品种分组标题行 / 具体报价机构名称（含排名徽章） |
| 期限 | 资金期限（R001 / R007 / R014 / R021 / R028） |
| 金额(总量) | 可成交金额，单位亿 |
| 利率(均价) | 报价利率或分组加权均价（琥珀色高亮） |
| 账户要求 | 对融资方账户类型的限制，如"银行自营" / "不限户" |
| 质押要求 | 对质押物类型的要求，如"大行存单" / "利率债" |
| 操作 | "发送"按钮,唤起聊天窗口,联动聚合聊天室网页 |
