## 1. 产品概述

### 1.1 产品定位

**资金实时行情看板** — 银行间货币市场实时行情工作台。全屏桌面盯盘工具，三栏布局聚合报价、行情和图表分析。

### 1.2 目标用户

- 银行间市场资金交易员（日常盯盘、报价决策）
- 风控/研究部门（市场监控、利率分析）

### 1.3 核心价值

三栏并行布局：左栏参考数据与一级报价、中栏核心报价明细（可切换 1级/2级视图）、右栏分时/历史图表与分析面板。一屏看全，支持手动编辑银行报价，支持多品种叠加和对比分析。

### 1.4 技术约束

| 约束 | 说明 |
|------|------|
| 平台 | Desktop only，1920×1080 及以上 |
| 页面 | SPA，无前端路由 |
| 数据 | 全部内联 Mock 数据，无后端 API |
| 图表 | 自定义 SVG（无第三方图表库依赖） |

## 2. 整体布局与设计思路

### 2.1 三栏布局骨架

```
┌──────────────────────────────────────────────────────────────┐
│ TopBar: 标题 | DR007 2.15% | 资金情绪 51/47/50/49 | 平衡      │
├──────────────────────┬──────────────────┬───────────────────┤
│                      │                  │                   │
│  左栏 (30%)          │  中栏 (35%)      │  右栏 (35%)        │
│                      │                  │                   │
│  ① 大行价格表         │  ② 报价明细      │  ④ 分时图           │
│    手工输入按钮 → 编辑  │    1级/2级切换    │    叠加品种选择      │
│                      │                  │                   │
│  ② XREPO 报价表       │    逆回购报价      │  ⑤ 收盘价走势        │
│                      │    (3组)          │    5日/1月/半年     │
│                      │                  │    叠加 + 对比选择   │
│  ③ 交易所回购          │    正回购报价      │                   │
│    核心/上交所/深交所   │    (3组)          │  ⑥ 参考面板         │
│                      │    ═══ 拖拽分隔 ═══ │    CFETS/利差/      │
│  ④ NCD 走势           │                  │    资金结构          │
│    趋势图/表格切换      │                  │                   │
│                      │                  │                   │
└──────────────────────┴──────────────────┴───────────────────┘
```

### 2.2 分栏设计理由

**30:35:35 比例**：
- 左栏 30%：紧凑的参考数据面板，信息密度高。顶部是可变编辑的银行报价，底部是交易所和 NCD 数据。
- 中栏 35%：核心报价明细区。这是交易员最主要的操作区域——查看逆回购和正回购的详细报价。支持 1级摘要和 2级全量切换。
- 右栏 35%：图表与分析。分时/历史走势 + 利差 + 机构资金结构。

**为什么中栏有可拖拽分隔条？**
中栏内部垂直分为上下两个报价区（逆回购 / 正回购）。交易员在一天中的不同时段会侧重不同的方向（早上更关心逆回购融入资金，下午更关注正回购融出）。拖拽分隔条可以自由调整上下比例，按需分配空间。

### 2.3 栏目固定不可调

三栏之间没有拖拽调整——30:35:35 是经过权衡的固定比例。如果需要调整列宽，则需要改动代码。未来版本可考虑添加列间拖拽。

## 3. 三栏内容区域详解

### 3.1 左栏 —— 参考数据与一级报价

左栏从上到下依次四个卡片：

#### ① 当日大行价格

展示 4 家主要银行的双边报价。列：非银利率 / 银行利率 / 变化BP / 更新时间。

**核心交互**：点击「手工输入」按钮 → 弹出编辑弹窗，可修改所有字段（机构名、利率、BP、时间）。支持保存和重置。修改后的数据在当前会话内生效，刷新页面后恢复默认。

**设计意图**：交易员在实际工作中需要根据自己收到的报价手动调整参考数据。这不是「修改系统数据」，而是「记录我个人收到的报价」。

#### ② XREPO 报价表

展示 XRepo 平台上各期限的正回购和逆回购利率。列：期限 / 可点击量 / 正回购金额 / 正回购利率 / 逆回购利率 / 逆回购金额 / 可点击量 / 操作。操作列为「发送」按钮。

5 个期限品种：R001、R007、R014、R021、R028。

**核心交互 — 品种联动**：点击 XREPO 表中任意一行（如 R007）→ 该行高亮标记为「当前选中品种」→ 右栏分时图和收盘价走势的主品种同步切换为该品种。页面加载时默认选中 R001。这是交易员最自然的盯盘流程：「扫一眼各期限利率 → 发现异动 → 点进去看走势」。

#### ③ 交易所回购

三 Tab 切换：「核心」「上交所」「深交所」。
- 核心：展示沪深两市隔夜（GC001 / R-001）和 7天（GC007 / R-007）的合并视图，每行含加权均价、成交额、最高最低。
- 上交所 / 深交所：分别展示 5 个期限品种的完整行情。

**设计意图**：核心视图解决了「两个交易所数据分开看很麻烦」的问题。交易员大部分时间只需看核心视图的合并摘要，需要细节时再切换到单一交易所。

**核心交互 — 品种联动**：点击任意交易所回购行 → 该行高亮为「当前选中品种」→ 右栏走势图主品种同步切换。交易所品种（GC001/GC007/R-001 等）和 XREPO 的银行间品种共享同一个选中状态——在交易所看完 GC007 走势，回到 XREPO 点 R007，右栏无缝切换。

#### ④ NCD 走势

两 Tab 切换：「趋势图」「表格」。
- 趋势图：自定义 SVG 折线图，显示 1M / 3M / 1Y 三条 NCD 利率曲线。
- 表格：5 个期限（1M ~ 1Y）的 NCD 报价明细。

---

### 3.2 中栏 —— 报价明细（核心操作区）★

中栏是交易员盯盘的主要操作区域。

#### 1级 / 2级 切换

- **1级（摘要）**：每个报价分组仅显示最优和次优两行。信息精炼，快速扫视。
- **2级（全量）**：显示每组的全部报价行。信息完整，适合深度分析。

切换时，中栏内部的两个报价区（逆回购/正回购）同步切换。

#### 逆回购报价（上区）

三个报价分组，按交易对手类型划分：

| 分组 | 机构数 | 特点 |
|------|--------|------|
| 利率地方 | 9 家 | 以地方银行为主 |
| 存单商金 | 7 家 | 理财子和资产机构 |
| 信用 | 9 家 | 基金和券商 |

每行展示：机构名、期限、金额、利率、质押品类型、账户类型，以及报价等级徽章（最优 / 次优 / 报价）。

**核心交互 — 品种联动**：点击任意报价行 → 该行短暂高亮（~300ms）→ 右栏走势图主品种切换为该行的 tenor（R007/R014 等）。中栏的选中是瞬时的——目的是快速切品种看走势，不需要持久高亮。中栏选中后，左栏 XREPO/交易所的高亮同步清除。

#### 正回购报价（下区）

同样三个分组：

| 分组 | 机构数 | 特点 |
|------|--------|------|
| 利率地方 | 7 家 | 以大行为主 |
| 存单商金 | 6 家 | 理财子为主 |
| 信用 | 8 家 | 券商和基金 |

#### 可拖拽分隔条

上下两区之间有一个可拖拽的分隔条。鼠标按住上下拖动可调整逆回购区和正回购区的垂直比例。调整后的比例保存在本地浏览器中，下次打开看板时恢复。

#### 区头点击聚焦

点击逆回购报价或正回购报价的区头（标题栏）→ 该区获得「激活」状态（蓝色左边框高亮），另一个区缩小。再次点击取消聚焦。

---

### 3.3 右栏 —— 图表与分析

右栏从上到下三个面板，按 10:9:11 的固定比例分配高度。

#### ④ 当日分时图

自定义 SVG 折线图，展示当前选中品种的日内走势。默认展示 R001。
- 上部：价格面积图（带渐变填充）+ 可选叠加线。
- 下部：成交量柱状图。
- X 轴：8 个时间标签（09:30 ~ 15:00）。
- 40 个数据点。

**叠加品种选择器**：下拉菜单可选择「不叠加 / DR007 / GC007 / R007」。选择叠加品种后，图表上出现第二条虚线折线，方便对比不同品种的日内走势。
**主品种切换**：当用户在左栏或中栏选中其他品种时，分时图主品种线、面积填充、成交量柱状图全部切换。标题栏同步更新品种名。

#### ⑤ 收盘价走势

与分时图结构相同，但展示的是日频数据。主品种跟随当前选中品种（默认 R001）。
- **时间范围选择**：近5日 / 近1月 / 近半年。切换后图表数据和 X 轴标签同步更新。
- **叠加品种选择**：与分时图共享叠加品种状态。选择后出现琥珀色虚线。
- **对比品种选择**：独立下拉菜单，选择对比品种后出现紫色虚线 + 利差柱状图面板。利差 = 主品种 - 对比品种。可与叠加同时使用。

#### ⑥ 参考面板（底部）

三个 Tab 切换：

- **CFETS 日报统计**：4 个摘要卡片（净融出 +428 亿 / DR007 2.15% / 非银占比 49.8% / 成交总额 5,824 亿）+ 4 行资金净融出详情 + 操作明细。
- **利差**：两个品种的利差柱状图。左右各一个下拉选择器，可选择 DR001 / DR007 / GC007 / R007。正值红色柱，负值青色柱。
- **资金结构**：堆叠柱状图，展示 7 类机构（大行/股份行/理财/理财子/券商/基金/保险）的资金结构。支持 14天 / 1月 / 半年时间范围切换。

## 5. UX 规范

### 5.1 当前状态总览

| 状态类型 | 是否支持 | 说明 |
|----------|----------|------|
| 加载态 | 无 | 所有数据同步渲染，无异步加载 |
| 空状态 | 无 | 数据为硬编码，永远有数据 |
| 错误态 | 无 | 无网络请求，无错误场景 |
| 编辑态 | 有 | 左栏银行报价编辑弹窗 |
| 聚焦态 | 有 | 中栏报价区区头点击激活 |

### 5.2 编辑弹窗 UX

- 打开弹窗时，表单预填当前数据。
- 支持键盘操作（Tab 切换字段、Esc 关闭）。
- 修改后的数据在当前会话内有效，刷新后恢复。

### 5.3 拖拽分隔 UX

- 鼠标悬停分隔条时，光标变为行 resize 光标。
- 拖拽过程中，分隔条位置实时跟随鼠标。
- 松开鼠标后，比例写入 localStorage，下次打开保持。

### 5.4 数据精度

| 类型 | 格式 | 示例 |
|------|------|------|
| 利率 | 保留 2-4 位小数 | 1.37 / 1.3650 |
| 金额 | 亿为单位 | 14.93 |
| BP 变化 | 保留 1 位小数，带符号 | -1.0 |
| 时间 | HH:mm:ss | 10:32:15 |

### 5.5 布局中的固定比例

| 元素 | 比例/高度 |
|------|-----------|
| TopBar | 固定高度 |
| 三栏 | 30:35:35（固定，不可拖拽） |
| 中栏内部 | 默认等分，可通过拖拽调整 |
| 右栏三面板 | 10:9:11（固定） |

## 6. 品种联动交互

左栏和中栏的品种行是右栏走势图的「入口」。用户选中任意品种，右栏图表主品种跟随切换。

### 6.1 全局选中状态：`selectedProduct`

- **初始值**：R001（页面加载时默认选中，左栏 XREPO R001 行高亮）。
- **作用**：驱动右栏分时图和收盘价走势的主品种数据。
- **叠加和对比下拉保持独立**，不受 selectedProduct 影响。

### 6.2 三个入口，统一行为

| 入口 | 可选中品种 | 交互 |
|------|-----------|------|
| 左栏 XREPO 表 | R001 / R007 / R014 / R021 / R028 | 点击行 → 该行高亮 → selectedProduct 更新 |
| 左栏交易所回购（核心/上交所/深交所） | GC001 / GC007 / R-001 / R-007 等 | 点击行 → 该行高亮 → selectedProduct 更新 |
| 中栏报价明细行 | 该行的 tenor 字段 | 点击行 → 短暂高亮（~300ms）→ selectedProduct 更新 |

三个入口共享同一个 selectedProduct。最后一次点击哪个，右栏就切到哪个品种。

### 6.3 视觉反馈

- **左栏选中行**：左侧蓝色竖线 + 背景微亮。其他入口的高亮同步清除。
- **中栏点击行**：短暂高亮 ~300ms 后消失。中栏的核心功能是报价等级和分组，品种切换是附带操作。
- **右栏标题栏**：同步显示当前 selectedProduct 品种名（替换写死的 R001）。

### 6.4 右栏响应

selectedProduct 变化时：
- **分时图**：主品种线、面积填充、成交量柱状图全部切换。
- **收盘价走势**：主品种线切换。5日/1月/半年数据集均需对应品种数据。
- **叠加品种**：独立状态，不受影响。
- **对比品种**：独立状态，利差 = selectedProduct - compareProduct。
- **tooltip**：主品种标签同步更新。

### 6.5 数据要求

当前 Mock 数据仅有 DR001 的分时和历史数据。实现联动需要为 DR007 / GC007 / R007 / R014 等品种补充对应的日内分时和历史收盘数据集。

## 7. 多选品种对比交互

收盘价走势图支持**叠加 + 对比**双维度品种分析。

### 7.1 叠加 (overlayProduct)

- **位置**：分时图面板 header 下拉菜单。
- **选项**：不叠加 / DR007 / GC007 / R007。
- **视觉**：琥珀色虚线叠加在蓝色实线（当前主品种）上。
- **范围**：分时图和收盘价走势图共享同一个叠加状态。

### 7.2 对比 (compareProduct)

- **位置**：收盘价走势面板 header 的「对比」下拉菜单。
- **选项**：不对比 / DR001 / DR007 / GC007 / R007。
- **视觉**：紫色虚线显示对比品种走势。
- **利差面板**：选择对比品种后，图表下方自动展开利差柱状图。
  - 利差 = 当前主品种（selectedProduct）- 对比品种（compareProduct），单位 bp（×100）。
  - 正值红色柱（主品种 > 对比品种），负值青色柱（主品种 < 对比品种）。
  - Y 轴自动适配 min/max 范围。

### 7.3 叠加 + 对比同时使用

- 最多同时显示 3 条线：蓝色实线（主品种）、琥珀色虚线（叠加）、紫色虚线（对比）。
- 图例在图表右上角，每种颜色独立一行。
- 鼠标悬停 tooltip 完整展示：
  - 日期标签
  - 主品种价格 + 成交量
  - 叠加品种价格（如有）
  - 对比品种价格（如有）
  - 利差值（如有对比）

### 7.4 状态独立性

- 叠加品种和对比品种是两个独立的下拉菜单，互不影响。
- 切换时间范围（5日/1月/半年）保留当前的叠加和对比选择。
- 对比品种切换时，利差柱状图同步更新。

## 8. 窗口自适应行为

### 8.1 整体布局自适应

- 根容器 `h-screen w-screen overflow-hidden`，占满全屏。
- 三栏使用 CSS Grid `grid-cols-[30fr_35fr_35fr]`，按固定比例随窗口缩放。
- TopBar 固定高度，main 区域 `flex-1` 填充剩余高度。
- 无最小宽高硬限制，CSS Grid fr 单位自然处理极端尺寸。

### 8.2 面板内独立滚动

- 每栏 `overflow-hidden`，子面板 `overflow-y-auto`。
- 当内容高度超出面板时，出现 5px 宽的自定义滚动条。
- 三栏之间无外层页面滚动条。

### 8.3 SVG 图表自适应

- 分时图 SVG: `viewBox="0 0 680 178"`, `preserveAspectRatio="none"`。
- 收盘价走势图 SVG: `viewBox="0 0 720 186"`, `preserveAspectRatio="none"`。
- 图表 tooltip 通过 `containerRef` 获取实时容器尺寸，正确映射鼠标位置。

### 8.4 分隔条与 resize

- 窗口 resize 不会重置中栏分隔条位置。
- 分隔条比例持久化在 localStorage，跨会话保持。
- 拖拽分隔条时使用 `onMouseMove` + `onMouseUp` 全局事件，不受 resize 影响。

### 8.5 推荐分辨率

- 最佳体验：1920 × 1080 全屏。
- 1280 × 720 以下：面板可能挤压，文字溢出，建议最小 1440 × 900。

## 12. 附录：设计原则

1. **三栏并行**：参考（左）、操作（中）、分析（右），从左到右符合信息处理流程。
2. **1级/2级视图**：快速扫视用 1级摘要，深度分析用 2级全量。同一位置切换，不增加页面复杂度。
3. **本地状态优先**：用户手动编辑的数据保存在会话中，不要求后端接口。
4. **可拖拽分隔**：中栏上下区是交易员最频繁切换焦点的区域，允许自由调整比例。
5. **固定三栏比例**：30:35:35 经过权衡——左栏参考数据最紧凑、中栏报价信息密度最高、右栏图表需要足够空间。
6. **叠加+对比双维度**：叠加解决「同图看趋势」，对比解决「品种间看利差」，两个独立维度互不冲突。
7. **品种联动**：左栏和中栏的所有品种行都是右栏走势图的入口。一次点击切品种，一屏看全，无需手动切换下拉。
