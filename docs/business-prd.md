## 1. 产品概述

### 1.1 产品名称与定位

**资金实时行情看板** — 银行间货币市场实时行情工作台。全屏桌面盯盘工具，单一视图聚合全部资金行情。

### 1.2 目标用户

- **主要用户**：银行间市场资金交易员（日常盯盘、报价决策）
- **次要用户**：金融机构风控/研究部门（市场监控、利率分析）；流动性管理人员（公开市场操作跟踪）

### 1.3 核心价值主张

单一视图聚合全部银行间资金行情：XRepo匿名报价、大行双边价格、交易所回购、非银最优报价、NCD/同业存单报价、OMO公开市场操作、以及分时/历史/对比趋势图。免页面跳转，一站式盯盘。

### 1.4 与竞品的差异

| 对比维度 | 传统终端（Wind/Bloomberg） | 本看板 |
|----------|--------------------------|--------|
| 信息聚合 | 多窗口/多页面切换 | 单屏全部可见 |
| 品种联动 | 手动输入代码切换 | 点击行自动联动图表 |
| 操作路径 | 多步操作（筛选→搜索→切换→查看） | 一步选中→全屏联动 |
| 数据更新 | 需手动刷新或高级订阅 | 自动轮询刷新 |

### 1.5 产品约束

- **平台**：Desktop only，不做移动端/响应式
- **视口**：全屏固定布局，填满浏览器窗口
- **页面**：单页应用（SPA），无多页面
- **数据**：当前阶段全部使用 Mock 数据，为接入真实 API 做好准备

### 1.6 当前状态

可运行的原型。5 个内容区 + 全局筛选栏 + 顶部指标栏。所有交互逻辑（选中→联动→图表切换）已实现，数据层待 API 化。

## 2. 整体布局与设计思路

### 2.1 页面骨架

```
┌─────────────────────────────────────────────┬──────────────┐
│  顶部栏 (40px)                               │              │
│  标题 "资金实时行情看板" | DR007 利率 | 资金面状态  │              │
├─────────────────────────────────────────────┤              │
│  全局筛选栏 (~36px)                          │              │
│  期限: [全部] [1] [7] [14] [21] [28+]       │              │
│  | 金额: [___] ~ [___] 亿                    │              │
│  | 利率: [___] ~ [___] %                     │              │
├────────────────────────┬────────────────────┤              │
│                        │                    │              │
│  ① 主行情表 ~30%       │  ④ 趋势大图 ~65%    │              │
│   XRepo / 大行价格      │   分时 / 历史 / 对比   │              │
│                        │                    │              │
├────────────────────────┤                    │              │
│                        │                    │              │
│  ② 对比行情表 ~28%      │                    │              │
│   交易所回购 / 非银最优    │                    │              │
│   ★ 点击行 → 联动 ④     │                    │              │
│                        │                    │              │
├────────────────────────┼────────────────────┤              │
│                        │                    │              │
│  ③ 底部详情区 ~42%      │  ⑤ 情绪参考区 ~35%  │              │
│   OMO明细/统计/非银明细   │   情绪/回购/NCD/     │              │
│                        │   资金结构/同业存款    │              │
├────────────────────────┴────────────────────┤              │
│   左列 60%              右列 40%             │
└─────────────────────────────────────────────┘
```

### 2.2 分栏设计理由

**60/40 分栏**：
- 左列 60%：数据密集型。三张表从上到下排列——越高越重要，越下数据量越大。
- 右列 40%：图表与参考。大图需要纵向空间（图表可读性），情绪参考补充信息。

**左列三段 30:28:42**：
- ① 30%：核心报价行数少（5-7 行），放最上方视线最先触及。
- ② 28%：与 ① 高度接近，形成「两类市场」的并列感知。这是联动枢纽。
- ③ 42%：OMO 明细和机构报价数据量大，需更多空间。

**右列两段 65:35**：
- ④ 65%：图表是主要分析工具，需要最大面积。
- ⑤ 35%：参考数据，辅助决策。

### 2.3 内容区域统一结构

每个内容区使用相同的卡片结构：
- 顶部标题栏：左侧是 Tab 切换按钮组，右侧是操作按钮（下载/指标）。
- 下方数据区：独立滚动，不受其他区域滚动影响。

### 2.4 窗口自适应行为

本看板设计为填满浏览器窗口，当用户拖拽窗口改变大小时，布局会自适应调整。

#### 最小窗口限制

- **最小宽度**：1280px。低于此宽度，内容区可能无法完整显示。
- **最小高度**：720px。低于此高度，各区域表格和图表可能无法正常显示。

#### 窗口缩小时的行为

| 窗口变化 | 布局响应 |
|----------|----------|
| 高度减小 | 各区域按 flex 比例同步缩小。表格内部出现垂直滚动条。图表按比例缩小，保持纵横比。 |
| 宽度减小 | 左右两列按 60:40 比例同步缩小。表格列宽自适应缩小，文字不截断（必要时出现水平滚动）。 |
| 低于最小高度 | 顶部栏保持固定；筛选栏保持固定；各区域继续按比例缩小，但最小高度不低于内容行高的 3 倍。 |
| 低于最小宽度 | 左列优先保持最小列宽，右列按比例缩小。图表最小宽度不低于 300px。 |

#### 窗口放大时的行为

| 窗口变化 | 布局响应 |
|----------|----------|
| 高度增大 | 各区域按 flex 比例同步放大。表格显示更多行（减少滚动）。图表纵向拉长，显示更多细节。 |
| 宽度增大 | 左右两列按 60:40 比例同步放大。表格列宽增加，数值有更多呼吸空间。图表横向扩展，时间轴显示更多刻度。 |
| 全屏/最大窗口 | 所有内容填满屏幕。表格可能显示全部行而无滚动。图表获得最大展示面积。这是推荐的使用方式。 |

#### 多显示器场景

- 支持跨屏拖拽窗口。布局按新窗口尺寸重新计算。
- 推荐用法：一块屏幕全屏看板，另一块屏幕放交易系统或其他工具。

#### 不支持的场景

- 竖屏/旋转显示器：本看板不做竖屏适配。
- 移动端/平板：不做响应式。
- 分屏模式（Windows Snap / macOS Split View）：不做专门适配，但布局在上述宽高限制内正常工作。

## 3. 设计系统概览

### 3.1 视觉主题

暗色金融终端风格。深色背景减少长时间盯盘的眼疲劳，同时让数据高亮（利率涨跌色）更加突出。

### 3.2 色彩语义

- **数据方向**：正向/上涨用暖色（红/橙），负向/下跌用冷色（绿/青），零值/中性用灰色。
- **选中高亮**：蓝色系标识选中状态，区别于数据涨跌色。
- **机构类型**：7 种机构类型各有独立色系徽章，帮助快速区分。

### 3.3 排版层级

- **字号范围**：9px ~ 16px，逐级递进。数据值使用等宽字体（monospace）保证数字对齐。
- **表格行**：交替行色辅助横向阅读，防止串行。

### 3.4 间距原则

- 区域间紧凑（4px 间隙），最大化数据密度。
- 表格单元格内边距小（水平 8px，垂直 6px），优先展示数据而非留白。

## 4. 五个内容区域：功能与职责

### 4.1 区域 ① — 主行情表（左上）

**职责**：展示一级市场核心报价。这是用户打开看板第一眼看到的数据。

**内容**：
- 「XRepo 行情」Tab：各期限的正回购和逆回购利率。每行 = 一个期限品种。列：期限 | 买方金额 | 买方利率 | 卖方利率 | 卖方金额 | 操作。
- 「大行价格」Tab：主要银行的双边报价。每行 = 一家银行。列：机构名 | 银行利率 | 非银利率 | 更新时间 | 操作。

**设计意图**：两类数据源放在同一位置用 Tab 切换（而非并排），避免信息过载——交易员同一时间只需关注其中一类。

### 4.2 区域 ② — 对比行情表（左中）★ 核心联动入口

**职责**：展示对比市场行情，同时作为**行选中 → 联动全屏**的唯一入口。

**内容**：
- 「交易所回购」Tab：上交所/深交所回购品种。含加权均价、涨跌 BP、OHLC、成交量。
- 「非银最优」Tab：非银机构间最优报价。

**联动效应**（★ 核心交互）：
- 点击某行 → ④ 大图自动切换到该品种的分时走势。
- 点击某行 → ③ 非银明细自动切换到该期限的机构对比。
- 切换数据源 → 选中状态自动清除。

**设计意图**：这是「选中即联动」的枢纽。交易员盯表时随时点选感兴趣的品种，右侧图表立即响应，无需手动输入代码或切换页面。

### 4.3 区域 ③ — 底部详情区（左下）

**职责**：展示低频但重要的历史数据和明细。

**内容**：
- 「逐笔明细」Tab：近两周央行 OMO 操作记录。表是转置的——列为日期、行为字段——方便横向对比每天的操作。
- 「净投放统计」Tab：每日净投放汇总。正数 = 放水，负数 = 回笼。
- 「非银明细」Tab：所有机构在某一期限上的双边报价，按机构类型分组，支持搜索过滤。

**设计意图**：三类数据放同一位置 Tab 切换，节省空间。转置表的设计是因为用户关心「某一天做了哪些操作」，而非「某类操作在每一天的值」。

### 4.4 区域 ④ — 趋势大图区（右上）

**职责**：展示价格趋势图表，是行情分析的核心工具。

**内容**：
- 「分时」Tab：今日日内走势。上部 = 价格面积图 + 加权均价参考线；下部 = 成交量柱状图。
- 「历史」Tab：近期日线走势。同分时布局。
- 「对比」Tab：五条折线叠加——交易所 R-001、非银最优 R001、中信证券 R001、大行工商银行、Xrepo R007——对比跨市场利差。

**联动**：图表标题、数据源、基准利率均由 ② 的选中行驱动。

**设计意图**：价格+成交量双面板是金融图表经典布局。对比图是「宏观概览」，分时/历史是「品种细节」。从对比模式选中品种 → 自动切分时，符合「宏观→微观」的思维路径。

### 4.5 区域 ⑤ — 情绪参考区（右下）

**职责**：展示市场情绪指标和补充参考数据。优先级最低，但决策时常用。

**内容**：
- 「资金情绪」Tab：情绪指数（0-100），低于 40 = 宽松，40-60 = 平衡，高于 60 = 偏紧。含四个细分维度。
- 「分机构回购」Tab：六类机构的正回购交易量堆叠柱状图。
- 「NCD 走势」Tab：同业存单各期限买卖利率和涨跌 BP。
- 「资金结构」Tab：六类机构的资金存量分布。
- 「同业存款」Tab：各期限同业存款利率报价。

**设计意图**：纯消费型信息，不驱动其他视图变化。放在右下角因为优先级最低，但不想隐藏到二级页面。

## 5. 交互规范

### 5.1 全局筛选

| 操作 | 系统反应 | 影响范围 |
|------|----------|----------|
| 点击期限按钮（全部/1/7/14/21/28+） | 即时过滤 | ① XRepo 表 + ② 非银最优表 |
| 点击「全部」 | 取消期限过滤 | 同上 |
| 输入金额范围（最小 ~ 最大，单位亿） | 即时过滤，无需按回车 | ① + ② |
| 输入利率范围（最小 ~ 最大，单位%） | 即时过滤，无需按回车 | ① + ② |
| 清空输入框 | 取消该方向限制 | 同上 |

**不影响**：① 大行价格模式（仅受利率范围影响）、② 交易所回购模式（仅受金额/利率范围影响）、③、④、⑤。

**为什么是大行价格和交易所回购不完全响应？**
- 大行价格没有「期限」和「金额」字段，只适用利率范围；
- 交易所回购品种使用自己的品种代码（GC001 等），不是标准期限。

### 5.2 表格操作

| 操作 | 系统反应 |
|------|----------|
| 鼠标划过表行 | 行背景轻微变亮，辅助横向阅读 |
| ① 点击「XRepo 行情」/「大行价格」Tab | 表结构和数据即时切换，筛选条件保持 |
| ② 点击「交易所回购」/「非银最优」Tab | 切换数据源，同时自动清除之前的选中行 |
| ② 点击某一行数据 ★ | 行高亮选中 → ④ 大图自动切到该品种分时图 → ③ 非银明细切到对应期限 |
| ② 再次点击同一行 | 取消选中，高亮消失，④ 标题恢复默认，③ 回到默认期限 |
| ② 点击行末「报价」按钮 | 不触发行选中（独立操作）。当前为视觉占位按钮 |
| ③ 点击「逐笔明细」/「净投放统计」/「非银明细」Tab | 面板切换，搜索文本保留 |
| ③ 在搜索框输入 | 实时过滤机构列表（匹配机构名和类型） |
| ⑤ 点击任意 Tab | 仅影响区域 ⑤，不影响其他任何区域 |

### 5.3 行选中交互详情（重要）

#### 单选模式（当前实现）

- 用户点击 ② 区域中任意一行 → 该行被选中。
- 同一时间只有一行可被选中。
- 再次点击选中行 → 取消选中。
- 点击其他行 → 选中切换到新行，旧行取消选中。

#### 选中视觉反馈

- 选中行：左侧出现竖线标记 + 背景变亮。
- 未选中行：交替的背景色。
- 表头区域：无选中时显示"点击行 → 联动大图"；有选中时显示"已选: {品种名称}"。

#### 联动链

```
② 选中行
  → ④ 大图标题更新为 "{数据源} · {品种}"
  → ④ 如果在「对比」模式 → 自动切换到「分时」模式
  → ④ 图表数据重新加载对应品种
  → ③ 非银明细 Tab 中的期限自动变为选中品种的期限
  → ③ 非银明细 Tab 中的提示横幅消失
```

#### 多选模式（规划中）

当前仅支持单选。未来版本考虑支持多选，场景如下：

| 场景 | 行为 |
|------|------|
| 按住 Ctrl/Cmd + 点击多行 | 多个行同时高亮选中 |
| 多选后图表响应 | ④ 对比图中仅显示选中的品种系列（未选中的自动隐藏） |
| 取消多选 | 点击空白区域或按 Esc |
| 多选上限 | 最多同时选中 5 个品种（与对比图 5 条线的设计一致） |
| 非银明细响应 | 显示第一个选中品种的期限对应的机构报价 |

### 5.4 图表操作

| 操作 | 系统反应 |
|------|----------|
| 鼠标悬停图表数据点 | 浮动提示框显示精确数值 |
| 点击图例中的某项 | 该系列在图表中隐藏，再次点击恢复显示 |
| 悬停柱状图 | 显示该时间点各机构的具体数值 |
| 点击「分时」/「历史」/「对比」Tab | 图表内容即时切换 |
| 悬停对比图折线 | 显示该时间点所有五条折线的数值 |

### 5.5 窗口 resize 时的交互

| 用户操作 | 系统反应 |
|----------|----------|
| 拖拽窗口边缘改变大小 | 各区域按 flex 比例实时重排，无闪烁、无跳变 |
| 窗口宽度 < 1280px | 左列优先保持最小列宽（表格不截断），右侧图表可能出现水平滚动条 |
| 窗口高度 < 720px | 各区域内部出现垂直滚动条，顶部栏和筛选栏保持固定 |
| 最大化窗口 | 所有区域填满屏幕，表格显示更多行，图表获得最大展示面积 |
| 从最大化恢复 | 回到之前的尺寸，布局比例保持不变 |
| 窗口宽度变化导致表格列过窄 | 表格内部出现水平滚动条，不截断数值文字 |

## 6. UX 规范

### 6.1 加载态（重构后）

| 场景 | 用户看到的 |
|------|-----------|
| 首次打开页面 | 5 个区域显示灰色骨架占位块（骨架屏），模拟内容形状。1.5 秒内完成加载 |
| 数据刷新中 | 旧数据保持显示，不出现闪烁或空白 |
| 图表加载中 | 图表框架可见，中心显示加载旋转图标 |

**超时处理**：超过 5 秒未加载完成，显示「加载超时，点击重试」按钮。

### 6.2 空状态

| 场景 | 用户看到的 |
|------|-----------|
| 筛选后无匹配数据 | 「无匹配数据」居中显示，附带「清空筛选」按钮 |
| 搜索无匹配机构 | 「未找到匹配机构」居中显示 |
| 无选中行时图表标题 | 「—」 |

### 6.3 错误态（重构后）

| 场景 | 用户看到的 |
|------|-----------|
| 网络断开 | 区域右上角出现「网络异常」红色标签，最后成功的数据保持显示 |
| 服务端异常 | 该区域显示「服务异常，稍后重试」+ 重试按钮。其他区域不受影响 |
| 数据格式异常 | 该数据行显示「—」，不崩溃整个页面 |

**关键原则**：单区域错误不影响其他区域。每个区域独立处理自己的错误。

### 6.4 数据实时性感知

## 7. 切换与过渡

### 7.1 Tab 切换

| 场景 | 过渡效果 | 时长 |
|------|----------|------|
| 所有内容区 Tab 切换 | 旧内容淡出 → 新内容淡入 | 150ms |
| 数据源切换（跨表格） | 同上 | 150ms |
| 图表模式切换 | 旧图淡出，新图渐入 | 200ms |

### 7.2 选中行高亮

- 选中：蓝色左边框 + 背景淡蓝，150ms 平滑过渡。
- 取消选中：恢复到交替行色，150ms。

### 7.3 数据更新闪烁

- 实时数据变化时，变化数值短暂高亮闪烁（1.5 秒消退），提示用户数据已更新。

### 7.4 筛选与搜索

- 筛选和搜索即时生效，无动画。直接更新列表。

### 7.5 图表品种切换

- ② 选中行变化 → ④ 图表数据切换：图表平滑过渡到新品种数据（300ms 动画）。

### 7.6 滚动行为

- ② 选中行切换时 **不** 自动滚动到选中行（尊重用户当前视野）。
- Tab 切换时保持滚动位置。
- 过滤后行数变化时保持滚动位置。

## 8. 窗口自适应行为

### 8.1 布局自适应策略

看板采用 flex 弹性布局，核心原则：
- **按比例缩放**：左右分栏保持 60:40，各区域保持设定的 flex 比例。
- **固定元素优先**：顶部栏 (40px) 和筛选栏 (~36px) 高度固定，不参与缩放。
- **内容区弹性**：5 个卡片区域按 flex 比例分配剩余空间。

### 8.2 边界条件

| 条件 | 行为 |
|------|------|
| 窗口宽度 ≥ 1920px | 推荐使用。所有内容完整展示，表格可能有少量空白。 |
| 1280px ≤ 宽度 < 1920px | 正常使用。表格列适当紧凑，图表面积减小但可读。 |
| 宽度 < 1280px | 左侧表格可能出现水平滚动条。右侧图表最小宽度 300px。 |
| 高度 ≥ 900px | 推荐使用。表格可显示全部行而无滚动。 |
| 720px ≤ 高度 < 900px | 正常使用。各区域内部出现滚动条。 |
| 高度 < 720px | 每个区域最小高度 = 表头 + 3 行数据。低于此值内容不可用。 |

### 8.3 推荐配置

- **最佳体验**：1920×1080 或 2560×1440 全屏显示。
- **多屏推荐**：主屏（全屏看板）+ 副屏（交易系统/聊天工具）。

## 10. 数据校验规则

以下规则定义了什么是「有效数据」。所有 Mock 数据和未来真实 API 数据都应符合这些约束。

### 10.1 报价数据规则

| 规则 | 适用数据源 | 说明 |
|------|-----------|------|
| **bidRate ≤ askRate** | 全部报价 | 正回购（买入）利率不得高于逆回购（卖出）利率。违反此规则的数据行应标记为异常，不参与排序和图表渲染。 |
| bidVolume ≥ 0 | 全部报价 | 金额不能为负数。 |
| askVolume ≥ 0 | 全部报价 | 同上。 |
| period 必须在源定义的 periods 列表中 | XRepo, 非银最优, NCD, 同业存款 | 期限值必须是该数据源配置中声明的有效值。非预期期限值应记录警告并隐藏。 |
| changeBp 可由 (当前加权均价 - 昨收) 计算验证 | 交易所回购 | 展示的 BP 变化应接近此计算结果。偏差超过 ±0.5 BP 应标记。 |

### 10.2 机构数据规则

| 规则 | 说明 |
|------|------|
| **机构名必须在 institutions 列表中** | 任何报价行引用的机构名必须存在于已注册的机构列表中。未注册的机构应记录并隐藏该行。 |
| institutionType 必须在 7 种类型之中 | 大行 / 股份行 / 城商行 / 券商 / 基金 / 理财子 / 保险。非预期类型应降级为「其他」。 |

### 10.3 OMO 数据规则

| 规则 | 说明 |
|------|------|
| type 必须在已知操作类型中 | 逆回购 / 逆回购到期 / MLF / MLF到期 / 国库定存 / TMLF。 |
| 「到期」类操作的 amount 可以为负 | 逆回购到期、MLF到期的 amount 表示回笼资金，允许负值。 |
| 「操作」类操作的 amount 必须为正 | 逆回购、MLF、国库定存、TMLF 的 amount 表示投放资金，不允许负值。 |
| 同一天同一类型的多条记录可以共存 | 同一天可能同时有逆回购操作和逆回购到期。 |

### 10.4 趋势数据规则

| 规则 | 说明 |
|------|------|
| time 必须按时间顺序排列 | 分时图 time 从早到晚递增；历史图 time 从旧到新递增。乱序数据应自动排序。 |
| price 和 volume 必须为正数 | 价格和成交量均不得为负值或零。 |
| 数据点数量不低于 2 | 少于 2 个点无法绘制有意义的图表。显示「数据不足」提示。 |

### 10.5 跨数据源一致性规则

| 规则 | 说明 |
|------|------|
| 同一 period 在不同数据源中可能存在但含义不同 | GC001（交易所）和 1（XRepo）都表示隔夜，但利率值不应直接比较。这是不同市场。 |
| 机构报价的 institutionId 必须在 institutions 列表中 | 与机构报价规则一致。 |

## 12. 附录：设计原则

1. **单屏优先**：所有关键信息在一个屏幕上，避免跳转带来的「失去上下文」问题。

2. **选中即联动**：用户在任意位置做选择，相关区域自动响应。页面只有一处「点击行 → 其他地方自动变化」，规则简单一致。

3. **高频在上、低频在下**：① 和 ② 是实时变化的核心行情，放在上半部分；③ 的历史数据和 ⑤ 的参考数据放在下半部分。

4. **数据在左、图表在右**：符合从左到右的阅读习惯——先看具体数字，再看图形趋势。

5. **全局筛选 > 局部筛选**：同一个筛选条件影响多个区域，避免在每个表里重复设置。

6. **信息密度高但不杂乱**：五个区域各有清晰边界，同等优先级的内容用 Tab 折叠。

7. **单区域容错**：一个区域出错不影响其他区域。这是金融看板的可靠性基石。
