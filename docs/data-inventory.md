# 数据清单 — codex 分支

> 补充文档 | 配合 `business-prd.md` 使用

---

## 数据架构说明

codex 分支的**所有数据都是内联常量**，直接定义在 `App.tsx` 中。没有独立的 data/ 目录，没有 API 调用，没有异步数据获取。

---

## 1. 银行报价数据

**位置**: App.tsx, `initialBankRateRows` 常量
**数量**: 4 条

| institution | bankRate | nonBankRate | deltaBp | updatedAt |
|-------------|----------|-------------|---------|-----------|
| 工商银行 | 1.95 | 2.00 | +5 | 10:32:15 |
| 建设银行 | 1.93 | 1.98 | +5 | 10:28:41 |
| 农业银行 | 1.90 | 1.97 | +7 | 10:21:33 |
| 中国银行 | 1.92 | 1.99 | +7 | 10:40:18 |

**约束**: 仅 4 家，缺少交通银行等大行和股份行。bankRate < nonBankRate（银行融资成本更低），差异 2-7bp 符合市场逻辑。支持手工编辑但无持久化。

---

## 2. XREPO 报价

**位置**: App.tsx, `leftSections` 常量中的 XREPO rows
**数量**: 5 条

含 R001 / R007 / R014 / R021 / R028 五个期限品种。含正回购金额/利率、逆回购金额/利率。

**约束**: 利率几乎无变化，无期限结构曲线。

---

## 3. 交易所回购

**位置**: App.tsx, `leftSections` 常量中的 exchange repo rows
**数量**: 上交所 5 品种 + 深交所 5 品种

含加权均价、成交额（亿）、最高/最低价。

**约束**: 品种较完整，成交额有差异。

---

## 4. 报价明细数据

**位置**: App.tsx, `repoQuoteSections` 常量
**数量**: ~46 条报价记录

| 报价方向 | 分组 | 行数 |
|----------|------|------|
| 逆回购 | 利率地方 | 9 |
| 逆回购 | 存单商金 | 7 |
| 逆回购 | 信用 | 9 |
| 正回购 | 利率地方 | 7 |
| 正回购 | 存单商金 | 6 |
| 正回购 | 信用 | 8 |

每行字段：机构名、期限、金额（亿）、利率（%）、质押品类型、账户类型、报价等级（最优/次优/报价）。

**约束**: 机构覆盖约 25 家，期限集中在隔夜和 7 天。报价等级为静态分配（非动态计算）。

**位置**: App.tsx 各内联常量
**数量**:

|------|------|

## 数据校验规则（28 条）

### 一、报价明细数据（1-11）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 1 | bidRate ≤ askRate | 全部报价 | 正回购利率不得高于逆回购利率 |
| 2 | 金额 ≥ 0 | 全部报价 | 不允许负值 |
| 3 | 利率 > 0 | 全部报价 | 利率必须为正数 |
| 4 | 期限在预期列表中 | 全部报价 | R001/R007/R014/R021/R028 |
| 5 | 报价等级有效 | QuoteDetailRow | 必须为 最优 / 次优 / 报价 之一 |
| 6 | 机构名非空 | QuoteDetailRow | 机构名不得为空字符串 |
| 7 | 机构类型在分组中 | QuoteGroup | 利率地方 / 存单商金 / 信用 |
| 8 | 同一分组内机构名不重复 | QuoteGroup.rows | 同组内机构名应唯一 |
| 9 | 质押品类型非空 | QuoteDetailRow | collateral 字段不为空 |
| 10 | 账户类型非空 | QuoteDetailRow | accountType 字段不为空 |
| 11 | 更新时间格式合法 | BankRateRow | HH:mm:ss 格式 |

### 二、XREPO 数据（12-15）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 12 | bidRate ≤ askRate | XREPO 行 | 正回购利率 ≤ 逆回购利率 |
| 13 | 金额 ≥ 0 | XREPO 行 | 正回购金额和逆回购金额均 ≥ 0 |
| 14 | 可点击量 ≥ 0 | XREPO 行 | 左右两侧可点击量均 ≥ 0 |
| 15 | 期限在预期列表中 | XREPO 行 | R001/R007/R014/R021/R028 |

### 三、交易所回购数据（16-18）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 16 | 最新价 > 0 | 交易所行 | 成交利率必须大于 0 |
| 17 | 涨跌 bp 绝对值 ≤ 500 | 交易所行 | 异常波动标记，阈值 500bp |
| 18 | 成交额 ≥ 0 | 交易所行 | 成交额不得为负 |

### 四、NCD 数据（19-22）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 19 | bidRate ≤ askRate | NCD 行 | 买入收益率 ≤ 卖出收益率 |
| 20 | 利率 > 0 | NCD 行 | 所有收益率必须为正 |
| 21 | 期限在预期列表中 | NCD 行 | 1M / 3M / 6M / 9M / 1Y |
| 22 | 银行名称非空 | NCD 行 | name 字段不为空 |

### 五、CFETS 数据（23-25）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 23 | buyRate ≤ sellRate（两者非 null 时） | CfetsTermRow | 正回购利率 ≤ 逆回购利率 |
| 24 | 金额 ≥ 0 | CfetsTermRow | buyAmt / sellAmt / netInflow 均 ≥ 0（非 null 时） |
| 25 | 机构类型在已知列表中 | CfetsInstKey | 8 类机构（大行/中小行/券商/保险/基金/货基/理财子/其他） |

### 六、图表数据（26-28）

| # | 规则 | 适用数据 | 说明 |
|---|------|----------|------|
| 26 | 数据点按时间排序 | 全部分时/历史数据 | 分时图从早到晚，历史图从旧到新 |
| 27 | 价格和成交量 ≥ 0 | 全部图表数据 | 不允许负值 |
| 28 | 数据点 ≥ 2 | 全部图表数据 | 至少需要 2 个点绘制折线 |
