# 数据清单 — codex 分支

> 补充文档 | 配合 `business-prd.md` 使用

---

## 数据架构说明

codex 分支的**所有数据都是内联常量**，直接定义在 `App.tsx` 中。没有独立的 data/ 目录，没有 API 调用，没有异步数据获取。

---

## 1. 银行报价数据

**位置**: App.tsx, `initialBankRateRows` 常量
**数量**: 4 条

| institution | bankRate | nonBankRate | deltaBp | updatedAt |
|-------------|----------|-------------|---------|-----------|
| 工商银行 | 1.95 | 2.00 | +5 | 10:32:15 |
| 建设银行 | 1.93 | 1.98 | +5 | 10:28:41 |
| 农业银行 | 1.90 | 1.97 | +7 | 10:21:33 |
| 中国银行 | 1.92 | 1.99 | +7 | 10:40:18 |

**约束**: 仅 4 家，缺少交通银行等大行和股份行。bankRate < nonBankRate（银行融资成本更低），差异 2-7bp 符合市场逻辑。支持手工编辑但无持久化。

**数量**: 5 条

含 R001 / R007 / R014 / R021 / R028 五个期限品种。含正回购金额/利率、逆回购金额/利率。

**约束**: 利率几乎无变化，无期限结构曲线。

## 3. 交易所回购

**位置**: App.tsx, `leftSections` 常量中的 exchange repo rows
**数量**: 上交所 5 品种 + 深交所 5 品种

含加权均价、成交额（亿）、最高/最低价。

**约束**: 品种较完整，成交额有差异。

## 4. 报价明细数据

**位置**: App.tsx, `repoQuoteSections` 常量
**数量**: ~46 条报价记录

| 报价方向 | 分组 | 行数 |
|----------|------|------|
| 逆回购 | 利率地方 | 9 |
| 逆回购 | 存单商金 | 7 |
| 逆回购 | 信用 | 9 |
| 正回购 | 利率地方 | 7 |
| 正回购 | 存单商金 | 6 |
| 正回购 | 信用 | 8 |

**约束**: 机构覆盖约 25 家，期限集中在隔夜和 7 天。报价等级为静态分配（非动态计算）。

## 数据校验规则

### 报价规则

| 规则 | 说明 |
|------|------|
| bidRate ≤ askRate | 正回购利率不得高于逆回购利率 |
| 金额 ≥ 0 | 不允许负值 |
| 期限在预期列表 | R001/R007/R014/R021/R028 等 |
| 机构名唯一 | 同一分组内机构名不重复 |

### 图表数据规则

| 规则 | 说明 |
|------|------|
| 数据点时间有序 | 从早到晚 / 从旧到新 |
| 价格 > 0 | 不允许零或负值 |
| 数据点 ≥ 2 | 至少需要 2 个点绘制折线 |
