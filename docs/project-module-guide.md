# 资金看板（RepoBroad）业务模块说明

## 项目定位

面向银行间市场资金交易员的综合看板工具，整合回购报价、机构行情、执行进度、趋势分析等多维度信息，辅助交易员快速决策和高效执行。

---

## 页面整体结构

看板采用**三栏布局**：

- **左栏 — 行情摘要**：各市场行情入口卡片，一眼掌握关键品种的最新价格和状态
- **中栏 — 工作台**：上半部分是报价看板（核心交易工作区），下半部分是执行矩阵（当日头寸和资金缺口）
- **右栏 — 辅助分析**：趋势图表、市场情绪、资金结构等分析工具

点击左栏卡片可打开对应模块的全屏详情页。

### 1. 报价看板

交易员的核心工作界面，汇总展示当前市场上所有机构的回购报价。

**业务功能：**
- 按正回购（融入）/ 逆回购（融出）分区展示报价
- 按质押物类型分视图：最优报价、全部报价、国债地方、存单商金、信用
- 按期限筛选（隔夜、7天等）
- 按金额范围、券商来源、对手方标签等多维度过滤
- 机构名称 / 账户 / 质押物搜索
- 报价排序（按金额或利率）
- 置顶关注的报价
- 快速编辑报价信息
- 点击报价可发起对话（询价、还价等）
- 底部辅助 Tab 快速切换查看 XREPO / NCD / 交易所行情

**Tab 切换：**

顶部分区 Tab：

| Tab | 说明 |
|-----|------|
| 市场逆回购 | 逆回购（融出）方向的报价 |
| 市场正回购 | 正回购（融入）方向的报价 |

视图模式 Tab：

| Tab | 说明 |
|-----|------|
| 最优 | 每个质押物分组下仅展示最优报价 |
| 全部 | 展示所有报价 |
| 国债地方 | 仅质押物为利率债/地方债的报价 |
| 存单商金 | 仅质押物为同业存单/商金的报价 |
| 信用 | 仅质押物为信用债的报价 |

底部辅助 Tab：

| Tab | 说明 |
|-----|------|
| XREPO | 内嵌 XREPO 匿名回购摘要表 |
| NCD | 内嵌同业存单全期限矩阵 |
| 交易所 | 内嵌交易所回购快照表 |

**接口描述：**

#### 接口 1.1：获取报价分区列表

> 获取正回购和逆回购两个分区下所有报价数据，每个分区按质押物分组（利率地方、存单商金、信用），分组内为逐笔报价明细

返回字段 — 分区（Section）：

| 字段 | 说明 |
|------|------|
| id | 分区标识：reverse（逆回购）/ forward（正回购） |
| title | 分区标题，如"市场逆回购"、"市场正回购" |
| groups | 该分区下的报价分组列表 |

返回字段 — 报价分组（Group）：

| 字段 | 说明 |
|------|------|
| id | 分组唯一标识 |
| name | 分组名称：利率地方 / 存单商金 / 信用 |
| tenorSummary | 期限汇总，如"R001 / R007 / R014" |
| totalAmount | 分组报价总金额，如"25亿" |
| averageRate | 分组平均利率，如"1.40%" |
| collateral | 质押物类型描述，如"利率债 / 地方债" |
| badges | 标签列表，如 ["R001 最优", "R007 次优"] |
| rows | 该分组下的逐笔报价明细列表 |

返回字段 — 报价明细行：

| 字段 | 说明 |
|------|------|
| id | 报价唯一标识 |
| institution | 报价机构名称 |
| tenor | 期限，如"R001"、"R007"、"R014"、"R021" |
| amount | 报价金额，如"10亿" |
| rate | 报价利率，如"1.35%" |
| collateral | 质押物，如"利率"、"地方债"、"利率地方存单商金"、"大行存单"、"AAA"、"AA+"、"年金户" |
| rank | 报价等级：最优 / 次优 / 报价 |
| reason | 排名原因说明 |
| accountType | 账户类型，如"自营户"、"商金户"、"理财子"、"保险资管"、"公募基金"、"券商自营"、"券商资管"、"城商行自营"、"大行自营" |
| minimum | 起点金额，如"5亿起" |
| updatedAt | 最后更新时间，如"10:53:27" |

#### 接口 1.2：获取机构联系人映射

> 获取机构到联系人姓名的映射关系，用于发起报价对话时显示联系人

返回字段：

| 字段 | 说明 |
|------|------|
| institution（key） | 机构名称 |
| contactName（value） | 联系人姓名 |

#### 接口 1.3：获取机构券商映射

> 获取每个机构对应的货币中介（券商来源），用于券商维度筛选

返回字段：

| 字段 | 说明 |
|------|------|
| institution（key） | 机构名称 |
| broker（value） | 货币中介名称，可选值：国际 / 国利 / 平安 / 中诚 / 信唐 / 上田 |

#### 接口 1.4：获取机构标签映射

> 获取每个机构对应的对手方标签，用于标签维度筛选

返回字段：

| 字段 | 说明 |
|------|------|
| institution（key） | 机构名称 |
| tags（value） | 标签列表，可选值：保险/保障 / 稳定出钱 / 出散量 / 应急 / 券商自营 |

#### 接口 1.5：获取全局筛选配置

> 获取报价看板全局筛选的当前参数设置

返回字段：

| 字段 | 说明 |
|------|------|
| amountMin | 金额下限 |
| amountMax | 金额上限 |
| rateMin | 利率下限 |
| rateMax | 利率上限 |

### 2. 执行矩阵 / 资金缺口

跟踪当日资金需求的完成进度，帮助交易员管理头寸执行情况。

**业务功能：**
- 资金缺口矩阵：按天数列展示总缺口和期限安排
- 执行进度列表：逐笔展示每个账户的执行状态
- 按方向切换（正回购需求 / 逆回购需求）
- 按账户搜索、按状态筛选（全部/未开始/进行中/已完成）
- 按剩余金额排序

**Tab 切换：**

| Tab | 说明 |
|-----|------|
| 正回购需求 | 正回购方向的资金缺口和执行进度 |
| 逆回购需求 | 逆回购方向的资金缺口和执行进度 |

状态筛选：

| 值 | 说明 |
|----|------|
| 全部 | 不筛选 |
| 未开始 | 进度为空 |
| 进行中 | 进度 >0% 且 <100% |
| 已完成 | 进度 100% |

**接口描述：**

#### 接口 2.1：获取资金缺口矩阵

> 按方向获取资金缺口的天数维度矩阵，含总缺口行和期限安排行

请求参数：

| 参数 | 说明 |
|------|------|
| direction | 方向：repo（正回购）/ reverse（逆回购） |

返回字段 — 列定义（动态列，正/逆回购列数不同）：

正回购列：无天数、1天、2天、6天、7天、13天、14天、其他交易员、剩余缺口

逆回购列：无天数、1天、7天、14天、21天、其他交易员、剩余缺口

每列：

| 字段 | 说明 |
|------|------|
| key | 列标识 |
| label | 列显示名称 |

返回字段 — 行：

| 字段 | 说明 |
|------|------|
| label | 行名称："总缺口" 或 "期限安排" |
| type | 行类型：single（单值）/ paired（配对值） |
| values | 各列的金额数值（万元） |
| pairedValues | 仅 paired 类型行，各列含 {done: 已安排, need: 需安排}（万元） |

#### 接口 2.2：获取需求矩阵（质押物维度）

> 按方向获取各质押物分组在各期限下的需求量和完成量

请求参数：

| 参数 | 说明 |
|------|------|
| direction | 方向：repo / reverse |

返回字段 — 需求行：

| 字段 | 说明 |
|------|------|
| label | 质押物分组名称：利率地方 / 存单商金 / 信用 |
| cells[R001].need | R001 需求量（亿元） |
| cells[R001].done | R001 已完成量（亿元） |
| cells[R007].need | R007 需求量（亿元） |
| cells[R007].done | R007 已完成量（亿元） |

返回字段 — 汇总：

| 字段 | 说明 |
|------|------|
| rowTotals | 每行（质押物分组）的需求/完成汇总 |
| columnTotals | 每列（期限）的需求/完成汇总 |
| grandTotal | 总计 {need, done} |

#### 接口 2.3：获取执行进度列表

> 获取当日所有账户的交易执行进度

返回字段（每行一个账户）：

| 字段 | 说明 |
|------|------|
| account | 账户名称，如"泰康稳健增利A" |
| direction | 方向：repo / reverse |
| total | 总金额（亿元） |
| done | 已完成金额（亿元） |
| remaining | 剩余金额（亿元） |
| progress | 完成进度百分比（可为空，表示未开始） |
| issuedAt | 下单时间（可为空） |
| tradeNote | 交易备注，如"R001质押回购"、"已全部成交" |
| investNote | 投资备注，如"利率债配置"、"流动性备付" |
| counterpartyTag | 对手方标签（可为空），可选值：保险/保障 / 稳定出钱 / 出散量 / 应急 / 券商自营 |

#### 接口 2.4：获取资金缺口账户列表

> 获取所有存在资金缺口的账户及其缺口总金额

返回字段：

| 字段 | 说明 |
|------|------|
| account | 账户名称 |
| total | 缺口总金额（亿元） |

#### 接口 2.5：获取在途交易列表

> 获取当前正在执行中的交易明细

返回字段：

| 字段 | 说明 |
|------|------|
| account | 账户名称 |
| direction | 方向：repo / reverse |
| total | 总金额（亿元） |
| done | 已完成金额（亿元） |
| progress | 完成进度百分比 |
| issuedAt | 下单时间 |
| tradeNote | 交易备注 |
| investNote | 投资备注 |
| counterpartyTag | 对手方标签（可为空） |

#### 接口 2.6：获取资金缺口明细

> 将需求矩阵拆解为逐笔缺口行，标注账户、方向、质押物、期限、优先级和建议

返回字段：

| 字段 | 说明 |
|------|------|
| id | 缺口记录唯一标识 |
| direction | 方向：repo / reverse |
| directionLabel | 方向中文标签："正回购" / "逆回购" |
| account | 账户名称 |
| collateral | 质押物 |
| tenor | 期限：R001 / R007 |
| need | 需求量（亿元） |
| done | 已完成量（亿元） |
| gap | 缺口量（亿元） |
| progress | 完成进度（0-100%） |
| priority | 优先级：高 / 中 / 低 |
| suggestion | 建议对手方 |

### 3. 大行价格

实时展示国有大行（工农中建交等）的资金报价，是市场定价的核心锚点。

**业务功能：**
- 各大行隔夜和 7 天的非银利率、银行利率
- 涨跌幅（bp）和利差计算
- 大行价格历史趋势图
- 利差走势对比
- 报价是否活跃的状态标识
- 银行利率手动编辑（用于内部参考价调整）

**期限维度：** ON（隔夜）、7D（7天）

**机构列表：** 工商银行、建设银行、农业银行、中国银行（可配置白名单）

**接口描述：**

#### 接口 3.1：获取大行利率报价列表

> 获取各大行在各期限下的实时利率数据，每行为一个 机构 × 期限 的组合

返回字段：

| 字段 | 说明 |
|------|------|
| institution | 机构名称 |
| tenor | 期限：ON（隔夜）/ 7D（7天） |
| nonBankRate | 非银利率（当前报价），如"1.95%" |
| refNonBankRate | 非银参考利率（基准值） |
| deltaNonBankBp | 非银利率涨跌（bp） |
| bankRate | 银行利率（当前报价） |
| refBankRate | 银行参考利率（基准值） |
| deltaBp | 银行利率涨跌（bp） |
| updatedAt | 最后更新时间 |
| hasQuote | 当前是否有活跃报价 |

#### 接口 3.2：获取大行价格趋势数据

> 获取大行价格的历史趋势序列（用于趋势图和利差图）

请求参数：

| 参数 | 说明 |
|------|------|
| range | 时间范围：5d / 1m / 6m |

返回字段：

| 字段 | 说明 |
|------|------|
| dates | 日期标签序列 |
| rates | 利率序列 |
| spreads | 利差序列 |

#### 接口 3.3：获取大行白名单配置

> 获取当前展示的大行列表配置

返回字段：

| 字段 | 说明 |
|------|------|
| institutions | 大行名称列表，如 ["工商银行", "建设银行", "农业银行", "中国银行"] |

### 4. XREPO 匿名回购

展示银行间匿名撮合回购平台（X-Repo）的行情数据。

**业务功能：**
- 多品种行情总览
- 各品种最新价、涨跌、成交量
- 历史成交走势对比
- 行内迷你趋势图
- 按期限筛选
- 支持叠加对比品种

**接口描述：**

#### 接口 4.1：获取 XREPO 行情摘要表

> 获取所有合约的实时行情数据

返回字段（每行一个合约）：

| 字段 | 说明 |
|------|------|
| 合约名称 | R001、R001_mini、DFR001_mini、CDR001_mini、R004、R007、R007_mini、R014、R014_mini 等 |
| 正回购量(亿) | 正回购挂单量，格式"5 (0)"表示"总量 (已成)" |
| 正回购利率(%) | 正回购利率 |
| 逆回购利率(%) | 逆回购利率 |
| 逆回购量(亿) | 逆回购挂单量 |
| 时间 | 最后更新时间 |

#### 接口 4.2：获取 XREPO 历史走势

> 获取指定合约的历史成交走势数据

请求参数：

| 参数 | 说明 |
|------|------|
| contractName | 合约名称，如"R001" |
| range | 时间范围：today / 5d / 1m / 6m |
| compareProduct | 对比品种（可选）：无 / DR001 / DR007 / GC007 / R007 |

返回字段：

| 字段 | 说明 |
|------|------|
| dates | 日期/时间序列 |
| rates | 利率序列 |
| volumes | 成交量序列 |
| compareRates | 对比品种利率序列（如有） |

### 6. 同业存单（NCD）

展示同业存单一级和二级市场的收益率数据。

**业务功能：**
- 一级市场按期限、按银行评级分组展示发行报价
- 全期限矩阵视图：1M × 3M × 6M × 9M × 1Y
- 二级市场走势曲线
- 非银限购标识
- 摘要表（期限 / 利率 / 涨跌 / 参考 / 时间）

**期限维度：** 1M、3M、6M、9M、1Y

**趋势时间范围：** 14D、1M、3M、6M

**接口描述：**

#### 接口 6.1：获取 NCD 摘要表

> 获取各标准期限的利率、涨跌、参考价

返回字段（每行一个期限）：

| 字段 | 说明 |
|------|------|
| 期限 | 14D / 1M / 2M / 3M / 6M / 9M / 1Y / 18M / 2Y / 3Y |
| 利率 | 当前利率，如"2.03%" |
| 涨跌 | 涨跌 bp，如"+2"、"-1" |
| 参考 | 参考利率 |
| 时间 | 更新时间 |

#### 接口 6.2：获取 NCD 一级市场分组报价

> 获取指定期限下各评级分组的一级发行报价

请求参数：

| 参数 | 说明 |
|------|------|
| period | 期限：1M / 3M / 6M / 9M / 1Y |

返回字段 — 分组：

| 字段 | 说明 |
|------|------|
| label | 分组名称：国有/股份制、AAA、AA+、AA |
| rows | 该分组下各发行方的报价列表 |

返回字段 — 每行：

| 字段 | 说明 |
|------|------|
| name | 发行方名称 |
| rate | 发行利率 |
| change | 涨跌 bp（可为空） |
| marker | 是否重点标记 |

#### 接口 6.3：获取 NCD 全期限矩阵

> 获取各评级分组在所有期限下的利率矩阵

返回字段 — 分组：

| 字段 | 说明 |
|------|------|
| label | 分组名称：国有/股份制、AAA、AA+、AA |
| cells | 以期限为 key 的矩阵数据（1M/3M/6M/9M/1Y） |

返回字段 — 每个单元格：

| 字段 | 说明 |
|------|------|
| name | 发行方名称 |
| rate | 发行利率 |
| change | 涨跌（可为空） |
