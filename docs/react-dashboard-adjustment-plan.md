## 需求拆解

### 1. 左侧入口与中间模块

- 左侧删除入口直接删除，不保留占位。
- 中间删除的内容保留空位。
- 中间的「匿名成交走势图」需要保留，不参与删除。
- 「历史成交走势」不再作为独立中间模块展示，迁移到 XRepo 的背面。

需要确认/保留的模块策略：

| 模块 | 左侧入口 | 中间内容 |
| --- | --- | --- |
| 行情摘要今日预览 | 删除 | 留空 |
| DR007 / 资金情绪 | 删除 | 留空 |
| 历史成交趋势 | 删除 | 移入 XRepo 背面 |
| 匿名成交走势图 | 删除入口 | 中间保留图表 |
| 个人 & 机构 | 删除 | 留空 |

### 2. XRepo 只展示 R001 相关数据

- XRepo 仅展示合约名称包含 `R001` 的数据。
- 保留 `R001-mini`、`DFR001-mini`、`CDR001-mini` 等包含 `R001` 的合约。
- 删除/隐藏不包含 `R001` 的期限或合约，例如 `R007`、`R014`、`R021`、`R028`。
- XRepo 摘要、表格、图表、筛选项统一按 `contractName.includes("R001")` 或等价规则过滤。

验收点：

- XRepo 表格中可以看到 `R001`、`R001-mini` 等。
- 不出现 `R007`、`R014` 等非 R001 合约。

### 3. XRepo 背面：历史成交走势

- 历史成交走势放到 XRepo 卡片背面。
- 点击 XRepo 某一行时触发翻转。
- 被点击行作为默认传入参数，决定背面历史走势展示的合约。
- 例如点击 `R001-mini`，背面默认展示 `R001-mini` 的历史成交趋势。
- 背面需要支持返回正面。
- 返回正面支持两种方式：
  - 再次点击背面空白区域返回。
  - 点击背面右上角的返回按钮返回。

建议状态设计：

```ts
const [flippedXrepoContract, setFlippedXrepoContract] = useState<string | null>(null);
```

交互：

```text
XRepo 正面表格行点击
  -> setFlippedXrepoContract(row.contractName)
  -> 卡片翻转
  -> 历史成交走势读取 flippedXrepoContract

XRepo 背面空白区域点击 / 返回按钮点击
  -> setFlippedXrepoContract(null)
  -> 卡片翻回正面
```

### 6. 机构分期限统计移动到中间，并支持入口弹窗

参考图：机构分期限统计大图。

目标：

- 将机构分期限统计移动到中间行情矩阵区，作为中间区核心统计模块。
- 中间区默认展示一个压缩版统计图/统计摘要。
- 左侧「机构分期限统计入口」保留为轻量入口，不直接铺开大图。
- 入口中的「期限」和「指标」改为下拉框展示。
- 点击入口或入口中的展开按钮后，打开机构分期限统计大弹窗。
- 大弹窗做成更接近参考图的密集统计视图。
- 顶部保留指标选择：
  - 加权利率
  - 交易额
  - 回购余额
  - 跨月金额
  - 净融入金额
- 机构类型通过 checkbox 控制显示。
- 期限通过 checkbox 控制显示。
- 展示模式支持：
  - 正回购 / 逆回购
  - 折线图 / 柱状图
  - 期限 / 机构
- 默认可优先落地为柱状堆叠图。

交互调整：

- 图例点击仍保留筛选/高亮。
- 非图例项点击不再直接切换图表。
- 非图例项点击改为下拉框展开明细。
- 下拉明细展示该项对应的机构、期限、指标值、同比/环比或更新时间。
- 入口区的期限下拉框只控制入口摘要和弹窗默认参数。
- 入口区的指标下拉框只控制入口摘要和弹窗默认参数。
- 大弹窗内部仍保留完整筛选能力。
