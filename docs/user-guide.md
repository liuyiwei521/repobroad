# 资金实时行情看板 — 用户使用说明与设计思路

> 面向用户：资金交易员、风控人员、流动性管理人员

---

## 一、产品定位

资金实时行情看板是一块**全屏桌面盯盘工具**。它把银行间货币市场的核心行情——匿名报价、双边价格、交易所回购、机构对比、公开市场操作、以及价格走势——全部聚合在一个屏幕上，不需要跳转、不需要切换页面、不需要手动刷新（上线后）。

设计目标是：**一眼看清市场全貌，一键下钻到品种细节**。

---

## 二、页面布局：为什么这样分区

整个屏幕被分成**左六右四**两栏，左侧负责「数据」，右侧负责「图表」。

```
┌─────────────────────────────────────────────┬──────────────┐
│  顶部栏：标题 + 关键市场指标                    │              │
├─────────────────────────────────────────────┤              │
│  全局筛选：期限 / 金额 / 利率                   │              │
├────────────────────────┬────────────────────┤              │
│  ① 核心报价表           │  ④ 趋势大图          │              │
│    你最关心的            │    分时 / 历史 / 对比  │              │
│    一级市场行情           │                     │              │
├────────────────────────┤                     │              │
│  ② 对比行情表            │                     │              │
│    点击某一行 →          │    根据你的选中        │              │
│    联动右侧大图           │    自动切换品种        │              │
├────────────────────────┼─────────────────────┤              │
│  ③ 公开市场操作 + 机构明细 │  ⑤ 市场情绪 + 参考数据 │              │
│    央行操作全记录          │    资金面温度 + 补充    │              │
│    机构级报价对比          │    数据一览            │              │
└────────────────────────┴─────────────────────┘
```

### 为什么要 60/40 分栏

- 左侧占 60%：数据密集型内容。三张表从上到下排列，越高越重要。① 是市场最核心的报价，放在最顶上，占用约 1/3 的左侧高度；② 是对比数据，点击后联动右侧，放在中间过渡位置；③ 是对历史数据和明细的深挖，放在底部。
- 右侧占 40%：图表和参考信息。④ 大图区占用右侧的大部分（约 2/3），因为图表需要足够的纵向空间来展示趋势；⑤ 情绪参考占用剩余空间。

### 为什么要三段式左列（30:28:42）

- ① 主行情表占比 30%：只需要 5-7 行数据，不需要太高。放在最上方是因为它是用户第一眼看到的市场价格。
- ② 对比行情表占比 28%：与 ① 高度相近，视觉上形成"两类市场"的并列感知。
- ③ 底部详情占比 42%：OMO 明细和机构报价数据量大（可能十几列、几十行），需要更多空间来展示和滚动。

## 三、五个内容区域：各自做什么，怎么用

### 区域 ① —— 核心报价表（左上）

**看到什么**：两张可切换的表——「XRepo 行情」和「大行价格」。

- XRepo 行情：展示市场匿名询价/报价平台上各期限的正回购和逆回购利率。每一行是一个期限品种，列依次为期限、买方金额、买方利率、卖方利率、卖方金额。
- 大行价格：展示主要银行报出的双边价格。每一行是一家银行，列依次为机构名、银行利率、非银利率、更新时间。

**怎么操作**：
- 点击表头的两个 Tab 切换数据源。
- 右侧有下载按钮（上线后可导出 CSV）。
- 报价按钮（上线后可点开报价弹窗）。

**设计思路**：将最核心的一级市场行情放在用户视线最容易到达的位置（左上角）。两类数据源放在同一个位置用 Tab 切换，而不是并排展示，是为了避免信息过载——交易员同一时间只需要看其中一类。

---

### 区域 ② —— 对比行情表（左中）★ 核心交互区

**看到什么**：两张可切换的表——「交易所回购」和「非银最优」。

- 交易所回购：展示上交所/深交所回购品种的行情，含加权均价、涨跌 BP、最高最低价、成交量。
- 非银最优：展示非银机构间的最优报价，数据结构与 XRepo 类似。

**怎么操作 ★ 最重要的交互**：
- **点击任意一行数据** → 右侧 ④ 大图区自动切换到该品种的分时走势图。
- **再次点击同一行** → 取消选中，大图回到默认状态。
- **切换数据源 Tab** → 选中状态自动清除。

**联动效果**：
- 你选中了「GC007」，右侧大图立刻显示 GC007 的日内价格走势。
- 同时，底部 ③ 的「非银明细」Tab 会自动显示与选中期限匹配的机构报价列表。

**设计思路**：这是整个页面的「联动枢纽」。交易员在盯住几张表的同时，随时可以点选一个感兴趣的品种，右侧图表立即展示它的走势，不用手动输入代码或切换页面。这种「选中即联动」的模式减少了操作步数，让盯盘更流畅。交易所回购放在了比非银更突出的默认位置，因为交易所数据更完整（有涨跌 BP、加权均价、OHLC）。

---

### 区域 ③ —— 底部详情区（左下）

**看到什么**：三个 Tab 切换——「逐笔明细」「净投放统计」「非银明细」。

- 逐笔明细：近两周央行公开市场操作（逆回购/MLF/国库定存）的每一笔记录。表是转置的——列为日期，行为操作类型、期限、利率、金额——这样方便横向对比每天的操作。
- 净投放统计：每天的资金净投放汇总。正数表示央行放水（净投放），负数表示回笼。同时展示逆回购和 MLF 的到期与续做情况。
- 非银明细：展示所有机构在某一个期限上的双边报价，按机构类型分组，每个机构有类型标签。上方搜索框可以快速过滤机构。

**怎么操作**：
- 切换 Tab 看不同数据。
- 在「非银明细」Tab 中搜索框输入机构名或类型进行过滤。
- 「非银明细」的展示期限受 ② 区域联动影响——如果你在 ② 选中了某行，这里自动切到对应期限。

**设计思路**：将三类低频但重要的数据放在同一位置用 Tab 切换，节省空间。OMO 数据用转置表而非传统行列表，是因为用户关心的是「每一天做了哪些操作」，而不是「某类操作在每一天的值」。「非银明细」与 ② 的联动让用户在选择品种后立刻能看到所有机构的报价差，识别最优交易对手。

---

### 区域 ④ —— 趋势大图区（右上）

**看到什么**：三种图表模式——「分时」「历史」「对比」。

- 分时图：展示当前选中品种的今日日内走势。上部是价格面积图（含加权均价参考线），下部是成交量柱状图。
- 历史图：展示当前选中品种的近期日线走势，结构同分时。
- 对比图：五条折线叠加在一起——交易所 R-001、非银最优 R001、中信证券 R001、大行工商银行、Xrepo R007——让你一眼看出不同市场、不同机构的利率差异和走势同步性。

**怎么操作**：
- 点击表头三个 Tab 切换图表模式。
- 在 ② 区域点击某一行 → 图表自动切换为「分时」模式并加载该品种数据。
- 鼠标悬停图表显示具体数值。

**设计思路**：分时图和历史图共享同样的「价格+成交量」双面板布局，因为这是金融图表最经典的组合——价格在上体现趋势，成交量在下体现活跃度。对比图不响应选中行，因为它的用途是「宏观概览」——五条线放在一起对比跨市场利差。从对比模式点击 ② 的品种会自动切到分时，这是有意为之：用户在「宏观概览 → 具体品种」的思维路径上，系统自动帮用户走了第一步。

---

### 区域 ⑤ —— 情绪参考区（右下）

**看到什么**：五个 Tab——「资金情绪」「分机构回购」「NCD走势」「资金结构」「同业存款」。

- 资金情绪：一个大的情绪指数（0-100），低于 40 表示宽松，40-60 平衡，高于 60 偏紧。同时展示全市场、大行、中小行、非银四个细分维度的子指数。下方有简短的市场解读文字。
- 分机构回购：六类机构的正回购交易量堆叠柱状图，展示各类型机构在回购市场的参与度变化。
- NCD 走势：同业存单各期限（1M/3M/6M/9M/1Y）的买卖利率和涨跌 BP。
- 资金结构：六类机构的资金存量分布。
- 同业存款：各期限的同业存款利率报价。

**怎么操作**：
- 点击 Tab 切换不同参考数据。
- 悬停图表查看具体数值。

**设计思路**：这五个 Tab 是「一屏看全」理念的延伸——它们在逻辑上不属于核心盯盘流程，但交易员在做决策时经常需要参考。放在右下角是因为它们优先级最低，但又不希望隐藏到二级页面。用本地 Tab 切换（不联动其他区域）是因为情绪和结构数据不需要驱动其他视图变化——它们是纯消费型信息。

## 四、图表交互：怎么看趋势图

图表区不仅仅是「看」，还支持多种交互方式来帮助你分析数据。

### 悬停查看具体数值

将鼠标移动到图表的任意数据点上，会出现一个浮动提示框，显示该时间点的精确数值：

- **分时图 / 历史图**：价格区悬停显示最新利率和加权均价；成交量区悬停显示具体成交量数值。
- **对比图**：悬停在任意时间点，同时显示五条折线在该时刻的精确利率（精确到小数点后四位）。
- **分机构回购柱状图**：悬停在某一天的柱子上，显示各类机构在该日期的正回购交易量。

### 图例交互：显示/隐藏数据系列

对比图和分机构回购图的图例（Legend）是可以点击的：

- **点击图例中的某一项** → 该条折线（或柱子）在图表中隐藏，再次点击 → 重新显示。
- 用途：当五条折线叠加在一起时，暂时隐藏几条可以让你聚焦在关心的品种上。比如只保留「交易所 R-001」和「非银最优 R001」两条线对比。

### 参考线：快速判断价格水平

在分时图和历史图的价格区，有一条虚线标注了当前数据段的**平均利率水平**。价格线在这条参考线上方运行表示利率高于时段均值，下方表示低于均值。

### 图表模式切换的联动

对比图 → 选中品种 → 自动切到分时图（这在第三部分已经说明）。补充一点：如果你从「分时」切到「历史」，再切回「分时」，图表数据保持一致的品种（因为品种来自 ② 的选中行，没有变）。

### 未来将支持的图表交互（规划中）

以下功能在当前版本中尚未实现，但已在重构计划中：

| 交互 | 描述 |
|------|------|
| **滚轮缩放时间轴** | 在图表上滚动鼠标滚轮，放大或缩小时间范围。放大后可以看到更短时间内的价格波动细节；缩小后看到更长周期的趋势。 |
| **拖拽平移** | 放大时间轴后，按住鼠标拖拽图表左右滑动，浏览不同时间段的数据。 |
| **十字光标追踪** | 鼠标在图表上移动时，显示一条纵贯价格区和成交量区的竖线，价格和成交量的对应关系一目了然。 |
| **双击全屏** | 双击图表区域，图表展开为全屏视图，适合需要仔细分析走势时使用。再次双击或按 Esc 退出全屏。 |
| **时间范围快捷选择** | 在图表上方提供快捷按钮：今日 / 近3天 / 近7天 / 近30天，点击快速切换时间窗口。 |

## 五、表格交互：怎么看和操作数据行

### 行悬停高亮

鼠标划过任意数据行时，该行会轻微变亮。这是一个辅助横读的视觉提示——当一行数据很长时，高亮帮助你锁定当前正在看的那一行，避免串行。

### 选中行的视觉反馈

当你在 ② 对比行情表中点击选中一行时：
- 该行左侧出现一条竖线标记
- 行背景变为淡色高亮
- 表头区域显示当前选中的品种名称
- 再次点击同一行 → 取消选中，高亮消失

### 报价按钮的独立性

每行末尾的「报价」按钮是独立的，点击它不会触发整行的选中操作。这意味着你可以：
- 在已经选中某行的情况下，点击另一行的「报价」按钮 → 选中状态保持不变
- 先选中一行看走势，再点报价按钮进行询价——两个操作互不干扰

### 未来将支持的表格交互（规划中）

| 交互 | 描述 |
|------|------|
| **多选品种对比（Ctrl/Cmd + 点击）** | 按住 Ctrl 或 Cmd 键，点击多个行，可以同时选中多个品种。右侧对比图会自动只显示你选中的品种（未选中的自动隐藏），方便你聚焦在 2-3 个关心的品种上做跨市场对比。最多同时选中 5 个。再次点击已选中的行可取消该行的选中。按 Esc 或点击空白区域取消全部选中。 |
| **列排序** | 点击表头中的列名，按该列升序/降序排列行。例如点击「正回购利率」列头，按利率从低到高排列，找出最优报价。 |
| **右键菜单** | 在表格行上点击右键，弹出快捷菜单：复制数据 / 设为关注品种 / 查看历史走势 / 导出该品种数据。 |
| **键盘导航** | 用键盘 ↑ ↓ 键在表格行之间移动，Enter 键选中当前行，Esc 取消选中。熟练后比鼠标更快。 |
| **固定行 / 置顶** | 右键某行 → 「置顶显示」，该行始终排在最上面，方便持续关注某个重点品种。 |

## 六、全局筛选：怎么过滤数据

位置在顶部栏下方，包含三个筛选条件：

- **期限**：一组按钮（全部、1天、7天、14天、21天、28天及以上）。点击后，① XRepo 表和 ② 非银最优表只显示对应期限的数据。选「全部」则不限制。
- **金额范围**：两个输入框（最小 ~ 最大，单位亿）。输入后过滤交易量在指定范围内的行。留空表示不限制该方向。
- **利率范围**：两个输入框（最小 ~ 最大，单位%）。输入后过滤利率在指定范围内的行。留空表示不限制。

**影响范围**：这三个筛选同时作用于 ① 和 ② 两个区域。③、④、⑤ 不受影响。

**设计思路**：将筛选放在全局位置而非每个表格内部，是基于一个洞察——交易员在盯盘时通常用一个标准（比如只看 7 天期限、只看 1-3 亿的成交量）同时审视多个市场。全局筛选减少了重复操作。为什么 ③、④、⑤ 不受影响？因为 ③ 和 ⑤ 是参考数据，不需要按交易条件过滤；④ 的图表联动来自 ② 的选中行，已经有自己的品种切换机制。

## 七、核心交互流程：一个典型的盯盘场景

> 假设你是一个资金交易员，早上 10 点打开看板：

1. **扫一眼顶部栏** → DR007 利率 2.15%（红色上箭头），资金面「平衡」。市场不紧也不松，正常。

2. **看左侧 ① 主行情表** → 当前在「XRepo 行情」Tab，7 天正回购利率 1.25%，逆回购利率 2.00%。利差约 75bp。

3. **在全局筛选中点「7」** → 两张表都只显示 7 天品种，快速过滤掉不关心的期限。

4. **目光下移到 ② 交易所回购表** → 想看交易所市场是否和银行间一致。点击「GC007」这一行。

5. **右侧 ④ 大图自动切换** → 显示 GC007 的今日分时走势。价格在 1.37% 附近窄幅波动，成交量柱状图显示上午 10 点左右有一波放量。

6. **切换到「历史」模式** → 看 GC007 的近期日线走势，确认当前利率处于近一周的低位。

7. **目光下移到 ③ 底部详情区** → 切换到「非银明细」Tab（此时已自动显示 7 天期限），搜索「券商」→ 看到中信、中泰、国君、华泰四家券商的报价差。发现中信证券比大行贵约 1.5bp。

8. **看右侧 ⑤ 情绪参考** → 切换到「资金情绪」Tab，情绪指数 51（平衡），四个子指数中非银 49 略低于全市场 51，说明非银端稍微宽松。

9. **决策**：银行间和交易所 7 天利率都在低位，资金面平衡偏松，是融入的好时机。

**这个流程的关键**：从看 → 筛 → 比 → 联动 → 深挖 → 参考 → 决策，全部在一个屏幕上完成，没有页面跳转、没有手动输入品种代码。

## 八、完整交互规则速查表

### 全局筛选

| 操作 | 系统反应 |
|------|----------|
| 点击期限按钮 | ① XRepo 和 ② 非银最优即时过滤 |
| 输入金额/利率范围 | 即时过滤，不需要按回车 |
| 选择「全部」期限 | 取消期限过滤，显示所有期限数据 |

### 表格操作

| 操作 | 系统反应 |
|------|----------|
| 鼠标划过行 | 行背景轻微变亮，辅助横向阅读 |
| 在 ① 切换数据源 Tab | 表结构和数据即时切换 |
| 在 ② 点击一行数据 | 行高亮 + ④ 大图切到该品种分时 + ③ 非银明细切到对应期限 |
| 在 ② 再次点击同一行 | 取消选中，高亮消失，④ 标题恢复默认 |
| 在 ② 切换数据源 Tab | 自动清除之前的选中状态 |
| 点击「报价」按钮 | 不触发行选中（独立操作） |
| 在 ③ 非银明细搜索框输入 | 实时过滤机构列表 |
| 搜索无结果 | 列表为空，修改搜索词即可恢复 |

### 图表操作

## 九、窗口缩放与多屏使用

本看板设计为填满浏览器窗口，窗口大小变化时布局会自动适应。

### 窗口缩小时的行为

- 各内容区域按比例同步缩小，保持左右 60:40 的分栏比例。
- 表格内容超出时出现独立滚动条，不影响其他区域。
- 图表随容器缩小，保持可读性。

### 窗口放大时

- 各区域按比例同步放大。表格显示更多行（减少滚动），图表获得更大的展示面积。
- 全屏或最大化窗口是推荐的使用方式——所有数据一览无余。

### 边界限制

- **建议最小窗口**：1280 × 720 像素。低于此尺寸，表格可能无法完整展示，图表可能过于压缩。
- **最佳体验**：1920 × 1080 或更高分辨率，全屏显示。

### 多屏推荐

- 主屏幕全屏显示看板。
- 副屏幕用于交易系统、聊天工具或其他应用。
- 看板支持跨屏拖拽窗口，布局按新窗口尺寸自动重排。

## 十、什么时候会看到空数据

- 全局筛选条件太严格，导致 ① 或 ② 的区域没有匹配的行 → 该区域显示「无匹配数据」。此时放宽筛选条件即可。
- 在 ③ 非银明细搜索框中输入了不存在的机构名 → 机构列表为空。此时修改搜索关键词或清空搜索框。

## 十一、设计原则回顾

1. **单屏优先**：所有关键信息在一个屏幕上，避免跳转带来的「失去上下文」问题。这是 Bloomberg 终端的经典设计理念。

2. **选中即联动**：用户在任意位置做选择，相关区域自动响应，减少手动同步。页面上只有一处需要「点击行 → 其他地方自动变化」，这个规则简单一致。

3. **高频在上、低频在下**：① 和 ② 是实时变化的核心行情，放在上半部分；③ 的历史数据和 ⑤ 的参考数据放在下半部分。

4. **数据在左、图表在右**：符合从左到右的阅读习惯——先看具体数字，再看图形趋势。

5. **全局筛选 > 局部筛选**：同一个筛选条件影响多个区域，避免在每个表里重复设置。

6. **信息密度高但不杂乱**：五个区域各有清晰边界（深色卡片 + 分隔线），同等优先级的内容用 Tab 折叠，表格行用交替色辅助横向阅读。
