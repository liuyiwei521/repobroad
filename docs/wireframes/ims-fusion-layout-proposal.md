# IMS 融合布局建议

目标：保留 IMS 这张图的工作台框架，把“非银行价格”提升为中上主工作区，把“趋势图”放到右侧，同时尽量不牺牲原来“在途单/研究信息”的使用效率。

## 推荐方案

- 左侧仍保留“功能栏 + 条件筛选”，因为这是交易员高频入口，不能挪走。
- 中上区域改成“非银行价格主板”，作为页面视觉和操作核心。
- 右侧区域改成“趋势图面板”，默认显示趋势，研究信息切到二级 tab。
- 中下区域保留“在途单 / 历史 / 已发送 / 已完成”等任务表，承接操作闭环。

## 推荐比例

- 左功能栏：固定 `56px`
- 左筛选区：`320px ~ 360px`
- 中央主区：`1fr`
- 右侧趋势区：`320px ~ 380px`
- 中央主区内部：上 `62%`，下 `38%`

## 我建议这样调整

### 1. 非银行价格要成为页面主中心

原因：
- 这是最需要盯、最需要点、最需要比较的区域。
- 放在中上最符合“看盘 -> 选券 -> 发起动作”的视线顺序。
- 你现在这张 IMS 布局本身就天然适合把大列表放在中央主区。

建议：
- 中上列表只放“非银行价格”主数据，不再混入太多次级模块。
- “简称/标签”这一列保留并强化，作为识别效率最高的信息点。
- 一行展开时优先显示：券名、标签、剩余期限、对手方、Bid、Vol.Bid。

### 2. 趋势图放右侧，但不要做成单一大图

原因：
- 右侧宽度有限，单一大图信息密度反而不高。
- 交易员更需要“快速判断”而不是沉浸式分析。

建议右侧拆成三段：
- 趋势图 1：当前券分时主图
- 趋势图 2：同期限对比 / 价差图
- 趋势图 3：成交量或机构行为小图

这样比“一张大图”更适合盯盘。

### 3. 右侧最好做成 `趋势 | 研究` 双 tab

这是我最推荐的点。

原因：
- 你现在截图里的右侧是“内部研究/公开市场数据”，这些信息仍然有价值。
- 如果直接把右侧整块换成趋势图，会损失原有研究入口。
- 用 tab 可以保留原有信息资产，同时让趋势图成为默认视图。

建议：
- 默认 tab：`趋势`
- 次级 tab：`研究`
- 选中某只券后，`趋势` tab 自动刷新；`研究` tab 保持该券资料联动

### 4. 中下区域继续保留任务表，不要挪到右侧

原因：
- 在途单、已发送、待反馈本质是操作后状态区，不应该抢占主分析区。
- 放在中下最符合“上面看价格，下面看执行”的习惯。

建议：
- 中下表格与中上非银行价格联动
- 点击中上报价行时，中下自动过滤相关在途单
- 若没有关联任务，中下显示“推荐动作 / 最近沟通 / 历史询价”

### 5. 左侧筛选建议保持不动，只做轻量收敛

建议：
- 保留现有大类筛选结构
- 把低频筛选折叠进“更多条件”
- 把高频条件放在最上：期限、评级、授信、是否免税、是否公开/私募

这样能减少左侧视觉噪音，不影响老用户习惯。

## 两个可选版本

### A 版：我最推荐

- 右侧整列默认显示趋势图
- 研究信息放到右侧 tab 第二层
- 中上只做非银行价格主板

适合：
- 盯盘优先
- 交易反应速度优先

### B 版：更稳妥

- 右侧上半：趋势图
- 右侧下半：研究摘要
- 不做 tab，信息始终可见

适合：
- 研究信息必须常驻
- 用户不希望切 tab

## 如果落到当前页面，我的最终建议

优先做 A 版，然后加一个小开关支持切到 B 版。

一句话概括就是：

`左边筛选不动，中上专注非银行价格，右边专注趋势，下面承接在途任务。`
