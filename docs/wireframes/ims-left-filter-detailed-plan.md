# 左侧筛选区详细线框图与实施计划

目标：把左侧筛选区做成一个高频、稳定、可扩展的工作面板，既保留老交易员的操作习惯，也让新布局里的“非银行价格主板”更容易被快速过滤和命中。

## 设计原则

- 上面放高频：搜索、期限、评级、授信、标签
- 中间放结构化条件：按组折叠，减少噪音
- 下面放辅助区：我的方案、快捷条件、命中摘要
- 所有筛选默认“可看见结果”，不要做隐藏状态太深的二级弹窗

## 左侧筛选区分层

### 第一层：固定高频区

始终可见，不折叠。

- 搜索框
- 快速期限
- 快速价格范围
- 高评级快捷项
- 高频标签

### 第二层：条件分组区

可折叠，可展开，多组并列。

- 债券类型
- 常用概念
- 发行/主体属性
- 剩余期限
- 评级维度
- 投资属性

### 第三层：辅助操作区

放在左下，支持复用和反馈。

- 我的方案
- 我的自选
- 快捷条件
- 命中摘要

## 推荐交互

### 1. 固定高频区不折叠

原因：
- 高频筛选必须一眼能看到
- 交易员不会愿意频繁展开/收起

建议：
- 搜索、期限、价格区间、高频标签全部固定在顶部

### 2. 条件分组默认只展开 2 到 3 组

默认展开：
- 债券类型
- 主体评级
- 剩余期限

默认收起：
- 常用概念
- 投资属性
- 次级属性
- YY评分等低频条件

### 3. 标签选择要支持“多选 + 高亮 + 一键清除”

建议：
- 已选标签用高亮底色
- 每组右上角有“清空”
- 顶部显示“已选条件数”

### 4. 保存方案要轻量

建议：
- 点击 `保存方案` 后只弹一个轻量输入层
- 自动保存最近一次筛选状态为 `上次条件`

### 5. 结果摘要必须联动中央主板

建议：
- 每次筛选变更后，左下摘要立即更新
- 点击摘要项可反向过滤中央列表

例如：
- 点“非银行报价 9”只看非银行有价条目
- 点“最优报价 3”只看带最优标识的券

## 实施计划

### 第 1 阶段：结构重排

目标：
- 先把左侧布局层级整理清楚

工作项：
- 固定顶部高频区
- 折叠中部条件组
- 独立底部辅助区
- 增加底部操作栏

产出：
- 静态布局可用
- 与中央主板视觉关系稳定

### 第 2 阶段：高频筛选可用化

目标：
- 先保证核心筛选链路顺畅

工作项：
- 搜索联动
- 期限过滤
- 金额/利率范围过滤
- 高频标签过滤
- 主体评级过滤

产出：
- 可以覆盖 70% 以上高频场景

### 第 3 阶段：分组条件增强

目标：
- 补齐深层筛选能力

工作项：
- 常用概念分组
- 投资属性分组
- 次级/永续/隐含评级
- 多条件组合逻辑

产出：
- 专业用户可完成深筛

### 第 4 阶段：方案与摘要联动

目标：
- 提升复用效率

工作项：
- 保存方案
- 最近使用
- 我的自选
- 结果摘要联动点击

产出：
- 日常盯盘效率明显提升

### 第 5 阶段：细节优化

目标：
- 让筛选区更像成熟交易工作台

工作项：
- 条件计数
- 清空分组
- hover 提示
- 已选条件条
- 键盘导航

产出：
- 体验更稳定，更接近正式生产界面

## 最终建议

左侧筛选不要追求“功能全都同时展开”，而要追求：

`高频条件永远靠上，低频条件按组收纳，左下只放复用与反馈。`

如果你接下来要做界面改造，我建议优先实现：

1. 固定高频区
2. 中部分组折叠
3. 左下方案 + 摘要

这三步完成后，整个页面的工作流就会顺很多。
