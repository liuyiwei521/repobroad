# 非银行价格主面板：左上角筛选布局

你的新要求已经固定为：

`期限 + 金额区间 + 利率区间 + 账户要求 + 质押要求`

这 5 类核心筛选项，统一放在新图里“非银行价格主面板”的左上角。

## 布局原则

- 筛选项属于“看盘前置动作”，应该贴近主列表起点
- 放左上角最符合从左到右、从上到下的操作路径
- 筛选条不能抢掉主表头空间，所以要做成紧凑型工具区
- 右上角仍保留 `1级/2级/下载` 这类视图与操作按钮

## 更紧凑的终端版

```text
+--------------------------------------------------------------------------------------+
| 非银报价                          [1级][2级][下载]                                   |
| [全部][R001][R007][R014][R021][R028]                                                 |
| 金额 [0 ~ 不限]亿   利率 [0.00 ~ 不限]%                                             |
| 账户要求 [自营/专户]   质押要求 [利率/存单]                                         |
|--------------------------------------------------------------------------------------|
| 分组/机构 | 期限 | 金额 | 利率 | 账户 | 质押 | 时间 | 操作                          |
| ...                                                                                  |
+--------------------------------------------------------------------------------------+
```

## 我建议这样处理

### 1. 期限放第一行

原因：
- 期限是最核心的一级过滤维度
- 用户通常先定期限，再看金额和利率

### 2. 金额和利率放第二行

原因：
- 这是典型的范围条件
- 两组并排最节省横向空间

### 3. 账户要求和质押要求放第三行

原因：
- 这两项通常是约束条件，不如期限和价格高频
- 放在第三行更符合阅读层级

### 4. 右上只放视图按钮，不混筛选

原因：
- 筛选和视图控制职责不同
- 混在一起会让顶部工具区变乱

## 实施建议

如果落到页面实现，顺序建议是：

1. 先把筛选条整体移到主面板左上
2. 再把期限切换改成第一行标签组
3. 再补金额/利率范围输入
4. 最后接账户要求、质押要求下拉

一句话定稿：

`非银行价格主面板左上放筛选，右上放视图控制，下面直接承接报价表。`
