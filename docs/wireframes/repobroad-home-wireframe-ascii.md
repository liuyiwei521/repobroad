| 报价编辑弹窗                           |    | 报价沟通弹窗                           |

说明：

- 左侧入口栏：自适应摘要卡与预览模块
- 中部矩阵栏：矩阵卡片 + 底部标签内容
- 右侧主报价板：双分区主工作台
- 详情弹层页：从左栏模块点开的大视图
