# 右上角机构热度走势开发计划

## 1. 结论

- 按当前 React 看板的近期规划，右上角目标模块应为`机构热度走势`。
- 当前线上主入口仍未接好这块，实际右栏顶部展示的是`加权价格走势`。

依据：

- `src/main.tsx` 当前直接加载 `src/app/App.tsx`，所以以 React 主入口为准。
- `src/app/App.tsx` 的 `RightSidebar()` 目前依次渲染：
  - `HistoryClosePanel`（加权价格走势）
  - `IntradayPanel`（匿名成交走势图）
  - `RightLowerPanel`（机构分期限统计）
- `src/app/features/barometer/BarometerMatrixCard.tsx` 已经存在独立的`机构热度走势`组件。
- `docs/react-dashboard-adjustment-plan.md`、`docs/react-dashboard-update-summary.md` 也都把右侧模块口径写成了`机构热度走势`。

这说明当前问题不是“要不要做”，而是“feature 已有，但还没接回当前主布局”。

## 2. 现状与差距

### 当前现状

- 主布局右上：`HistoryClosePanel`
- 主布局右中：`IntradayPanel`
- 主布局右下：`CfetsInstPanel`
- `BarometerMatrixCard`：已拆到 `src/app/features/barometer/`，但未挂载到 `RightSidebar()`

### 关键差距

1. 右上角模块与最新产品口径不一致。
2. `BarometerMatrixCard` 虽已可用，但没有进入 live layout。
3. 当前“分机构统计”筛选存在口径不一致：
   - `笔数 / 量` 会随机构类型变化
   - `价` 当前不会随机构类型变化
4. 右栏布局高度配比是按“加权价格走势”设计的，替换后需要重新校准。

## 3. 开发目标

将当前 React 主页面右上角统一为`机构热度走势`，并满足以下要求：

- 默认展示 `BarometerMatrixCard`
- 保留`隔夜 / 7D`切换
- 保留`价 / 笔数 / 量`切换
- 保留机构类型筛选
- 机构筛选对三类指标都生效
- 原`加权价格走势`不丢失，继续通过页框/入口打开
- 右栏三块卡片在 1920 宽度下不挤压、不溢出

## 4. 分阶段计划

### M1. 现状接线与布局替换

目标：先把 live layout 接对。

任务：

- 在 `src/app/App.tsx` 的 `RightSidebar()` 中，把顶部卡片从 `HistoryClosePanel` 替换为 `BarometerMatrixCard`
- 保持中部 `IntradayPanel`、底部 `RightLowerPanel` 不变
- 重新调整右栏 `gridTemplateRows`
- 检查右栏卡片标题高度、内边距、滚动边界是否统一

产出：

- 右上角变为`机构热度走势`
- `BarometerMatrixCard` 不再是“已拆分但未接线”的孤立 feature

### M2. 指标口径补齐

目标：让“机构筛选”对三类指标行为一致。

任务：

- 审核 `src/app/features/barometer/BarometerMatrixCard.tsx`
- 审核 `src/app/features/barometer/barometer.data.ts`
- 审核 `src/app/features/barometer/barometer.utils.ts`
- 为`价`口径补齐按机构类型变化的数据生成逻辑
- 统一 today / yesterday、正回购 / 逆回购、价 / 笔数 / 量三条维度的生成方式

重点说明：

- 当前实现里，`metric === "price"` 时直接使用原始序列，没有套用机构画像；这会导致切换“大型银行/券商/基金”后，价格线不变。
- 这属于功能可见但口径未闭环，建议本轮一起修掉。

产出：

- 机构筛选对`价 / 笔数 / 量`全部生效
- tooltip、图例、曲线含义一致

### M3. 交互补强

目标：让这块从“能看”变成“好用”。

任务：

- 在卡片头部补充更新时间/状态文案
- 增加“展开查看”入口，复用现有 page frame 机制或新增 `market-sentiment` 入口页框
- 明确图例顺序：
  - 今日正回购
  - 今日逆回购
  - 昨日正回购
  - 昨日逆回购
- 校正 tooltip 排版，避免小数位和单位跳动
- 统一选择器样式，使其与右侧其他卡片一致

产出：

- 右上角卡片既能扫看，也能深看

### M4. 加权价格走势迁移收口

目标：替换右上角后，不让老能力“消失”。

任务：

- 确认 `weighted-price` 入口仍可从现有页框打开
- 如入口不够显性，为其增加稳定打开路径：
  - 左侧入口
  - 中部摘要卡
  - 或右上卡片内快捷跳转
- 清理不再需要的旧右上布局假设

产出：

- `机构热度走势`成为常驻右上
- `加权价格走势`转为二级打开能力

### M5. 回归验证

目标：确保替换不伤主页面。

任务：

- 执行 `npm run build:react`
- 检查右栏三块卡片在默认分栏、拖拽分栏、窄宽度下的显示
- 验证切换：
  - 隔夜 / 7D
  - 价 / 笔数 / 量
  - 全部机构 / 大型银行 / 券商 / 基金
- 验证 tooltip、坐标轴、图例、下拉框不遮挡
- 验证 `weighted-price` 页框仍可打开

## 6. 风险与注意点

1. `App.tsx` 里仍保留一批旧图表实现，容易误接到未使用组件。
2. 右栏高度比较紧，替换后如果不调 row ratio，tooltip 和下拉框容易挤压。
3. `价` 口径如果继续不随机构变化，会造成“筛选有 UI、没结果”的假象。
4. 如果后面要接真实接口，建议把 mock 生成逻辑再下沉一层，避免组件里混太多业务口径。

## 7. 建议实施顺序

建议按下面顺序做，风险最低：

1. 先替换 `RightSidebar()` 顶部挂载
2. 再补齐 `price` 维度的机构筛选逻辑
3. 再做展开入口和头部交互
4. 最后做样式回归和构建验证

## 8. 验收标准

- 进入首页后，右上角默认显示`机构热度走势`
- 机构筛选切换时，`价 / 笔数 / 量`三类图表都有变化
- 图例、tooltip、单位、坐标轴口径一致
- `加权价格走势`仍能从现有入口打开
- `npm run build:react` 通过
