# 左侧自适应入口栏开发计划

## 1. 目标

将左侧功能入口栏做成可根据宽度自动适应的入口系统。

左侧入口支持三种展示形态：

1. 图标态：宽度很窄时，只展示图标。
2. 简述态：宽度适中时，展示图标、标题和一行简述。
3. 小弹窗态：图标态或简述态下，hover / focus 入口时展示小弹窗，说明该入口内容。

同时，每个入口点击后打开一个稍大的弹窗，也就是统一的 `PageFrame`，承载对应业务模块页面。

## 2. 改版后的交互结构

```text
+----------------------+---------------------------------------------------------------+
| 左侧自适应入口栏       | 中间主工作区：非银报价                                      |
|                      |                                                               |
| 宽度很窄              | +-----------------------------------------------------------+ |
| [图标]                | | MainQuoteBoard                                             | |
| [图标]  hover -> 小弹窗| | 期限筛选 / 1级2级 / 报价列表 / 报价编辑                    | |
| [图标]                | +-----------------------------------------------------------+ |
|                      |                                                               |
| 宽度适中              |                                                               |
| [图标] 今天大行价格    |                                                               |
|        价格表/录入     |                                                               |
| [图标] XREPO          |                                                               |
|        发送/下载       |                                                               |
+----------------------+---------------------------------------------------------------+

点击任意入口：

+--------------------------------------------------------------------------+
| PageFrame: 加权价格走势 / 今天大行价格 / NCD ...       [刷新] [下载] [关闭] |
+--------------------------------------------------------------------------+
| 对应模块内容                                                               |
+--------------------------------------------------------------------------+
```

## 3. 宽度自适应规则

建议使用容器宽度判断，而不是窗口宽度判断。这样左侧栏被拖拽、折叠或未来进入抽屉时都能正常适配。

| 左侧栏宽度 | 展示形态 | 内容 |
|---|---|---|
| `<= 72px` | 图标态 | 只显示图标，隐藏标题和简述 |
| `73px - 180px` | 简述态-紧凑 | 显示图标 + 标题，简述隐藏或极短 |
| `181px - 280px` | 简述态-完整 | 显示图标 + 标题 + 一行简述 |
| `> 280px` | 宽列表态 | 显示分组、标题、简述、更新时间或状态 |

小弹窗规则：

- 图标态：hover / keyboard focus 时必须显示小弹窗，否则用户不知道图标含义。
- 简述态：hover 时可以显示更完整说明、数据状态、快捷操作。
- 小弹窗不承载复杂表格，只做说明和状态预览。
- 点击入口永远打开较大的 `PageFrame`，不要在小弹窗内完成复杂业务。

## 4. 组件设计

### 4.1 新增组件

```text
AdaptiveEntryRail
  - 负责左侧栏整体布局
  - 通过 ResizeObserver 判断自身宽度
  - 根据宽度输出 displayMode

ModuleEntryGroup
  - 负责分组展示
  - 例如：行情摘要、趋势分析、全局工具

ModuleEntryItem
  - 单个入口
  - 支持图标、标题、简述、状态、未读/更新标记
  - click 打开 PageFrame
  - hover/focus 打开 EntryPreviewPopover

EntryPreviewPopover
  - 小弹窗
  - 展示入口说明、更新时间、关键指标

PageFrame
  - 较大的弹窗容器
  - 统一标题、关闭、刷新、下载、独立打开按钮
  - 根据 activeFrame 渲染对应模块内容
```

### 4.2 状态设计

```ts
type EntryDisplayMode = "icon" | "compact" | "summary" | "wide";

type ModuleEntryId =
  | "big-bank-price"
  | "xrepo"
  | "exchange-repo"
  | "ncd"
  | "weighted-price"
  | "anonymous-trade"
  | "institution-period"
  | "global-filter"
  | "market-sentiment";

type ActiveFrame = {
  id: ModuleEntryId;
  title: string;
} | null;
```

### 4.3 入口配置

入口建议使用配置数组统一维护，避免散落在 JSX 里。

```ts

    group: "行情摘要",
    title: "今天大行价格",
    description: "大行当日隔夜和7天资金价格",

    description: "R001 历史走势与成交量",

  },
];
```

## 5. 页面布局调整

当前布局是：

```text
LeftSummaryPanel | MainQuoteBoard | RightSidebar
```

目标布局是：

```text
AdaptiveEntryRail | MainQuoteBoard
```

`LeftSummaryPanel` 和 `RightSidebar` 不再常驻渲染，需要拆出其中的内容模块，交给 `PageFrame` 按需渲染。

建议拆分：

| 原模块 | 新去向 |
|---|---|
| 今天大行价格 | `PageFrameContentBigBankPrice` |
| XREPO | `PageFrameContentXrepo` |
| 交易所回购 | `PageFrameContentExchangeRepo` |
| NCD | `PageFrameContentNcd` |
| 加权价格走势 | `PageFrameContentWeightedPrice` |
| 匿名成交走势图 | `PageFrameContentAnonymousTrade` |
| 机构分期限统计 | `PageFrameContentInstitutionPeriod` |
| 金额 / 利率筛选 | `PageFrameContentGlobalFilter` |
| DR007 / 资金情绪 | `PageFrameContentMarketSentiment` |

## 6. 开发步骤

### 阶段 1：组件骨架

1. 新增 `AdaptiveEntryRail`。
2. 新增 `ModuleEntryItem`。
3. 新增入口配置 `moduleEntries`。
4. 在 `App` 中把三栏布局先调整为「左入口栏 + 中间报价区」。
5. 先不迁移复杂内容，只让入口可点击并显示空 `PageFrame`。

验收：

- 左侧入口栏能显示所有入口。
- 中间报价区保持原有操作不受影响。
- 点击入口能打开和关闭大弹窗。

### 阶段 2：宽度自适应

1. 给 `AdaptiveEntryRail` 增加 `ResizeObserver`。
2. 根据容器宽度计算 `displayMode`。
3. 分别实现图标态、紧凑态、简述态、宽列表态。
4. 保留左侧栏拖拽能力，拖动后入口形态自动变化。

验收：

- 窄宽度只显示图标。
- 中等宽度显示标题。
- 较宽宽度显示标题和简述。
- 拖拽宽度时不需要刷新页面，入口形态实时变化。

### 阶段 3：小弹窗

1. 新增 `EntryPreviewPopover`。
2. 图标态 hover / focus 时展示小弹窗。
3. 简述态 hover 时展示更完整描述和状态。
4. 处理贴边定位，避免弹窗超出视口。

验收：

- 鼠标 hover 入口可看到小弹窗。
- 键盘 focus 入口也可看到小弹窗。
- 小弹窗不会遮挡当前入口。
- 小弹窗不会跑出屏幕右侧或底部。

### 阶段 4：大弹窗内容迁移

1. 从 `LeftSummaryPanel` 拆出今天大行价格内容。
2. 从 `LeftSummaryPanel` 拆出 XREPO 内容。
3. 拆出交易所回购和 NCD 内容。
4. 从 `RightSidebar` 拆出三个趋势图内容。
5. 将这些内容接入 `PageFrame`。

验收：

- 每个入口打开后都能看到对应内容。
- 原有 tab、筛选、hover tooltip 可继续使用。
- 关闭大弹窗后，中间报价板状态不丢失。

### 阶段 5：交互补齐

1. 为 `PageFrame` 增加标题、关闭、刷新、下载、独立打开按钮。
2. 对尚未实现的下载 / 发送按钮提供禁用态或提示。
3. 增加 Escape 关闭弹窗。
4. 增加点击遮罩关闭，可根据业务风险决定是否开启。
5. 大弹窗内的手工输入二级弹窗要保证层级高于 `PageFrame`。

验收：

- Escape 能关闭当前大弹窗。
- 下载未实现时不假装可用。
- 弹窗层级清楚，不互相遮挡。
- 手工输入、NCD 展开等二级弹窗能正常工作。

### 阶段 6：视觉与可用性校验

1. 检查不同宽度下文字截断。
2. 检查图标态是否足够可识别。
3. 检查小弹窗和大弹窗的层级、阴影、边框。
4. 检查键盘可访问性。
5. 用浏览器截图校验窄、中、宽三种左栏状态。

验收：

- `64px` 左栏：图标态正常。
- `140px` 左栏：紧凑态正常。
- `220px` 左栏：简述态正常。
- `320px` 左栏：宽列表态正常。
- 大弹窗在桌面尺寸下不遮挡中间报价板关键状态。

## 7. 需要重点注意的风险

1. 原 `LeftSummaryPanel` 和 `RightSidebar` 里有不少本地 state，拆分时要避免状态丢失。
2. `HistoryClosePanel` 和 `IntradayPanel` 当前共享 `overlayProduct` 状态，迁移到不同页框后要决定是否继续共享。
3. 部分按钮当前只是视觉样式，进入大弹窗后会更像真实操作，需要补禁用态或提示。
4. 图表 tooltip 使用 fixed 定位，大弹窗内需要确认定位不会偏移。
5. 大弹窗内再打开手工输入、NCD 展开等二级弹窗时，要统一 z-index。

## 8. 推荐实现顺序

```text
1. 新增入口配置
2. 新增 AdaptiveEntryRail
3. 新增 PageFrame 空壳
4. 替换 App 主布局
5. 实现宽度自适应
6. 实现入口小弹窗
7. 迁移左侧行情模块
8. 迁移右侧趋势模块
9. 补齐禁用态 / loading / 空态
10. 浏览器截图校验
```

## 9. 最小可交付版本

第一版可以只做到：

- 左侧入口栏支持图标态和简述态。
- hover 显示小弹窗。
- 点击入口打开统一大弹窗。
- 大弹窗先接入今天大行价格、加权价格走势、匿名成交走势图三个代表模块。
- 其他入口先显示“模块接入中”的空态。

这样可以最快验证整体交互是否符合预期，再逐步迁移剩余模块。
