# 当前主看板统一组件样式规范

> 适用范围：`src/app/App.tsx` 当前主入口及首页可见模块
>
> 参考样式来源：
> - `C:\Users\Administrator\Downloads\城投债存量统计(按地区).html`
> - `C:\Users\Administrator\Downloads\城投债存量统计(按地区)_files\style.css`
>
> 补充参考：
> - `docs/tdx-pui-white-theme-spec.md`
> - `docs/theme-system-overview.md`

---

## 1. 目标

本规范只解决一件事：

- 同一种组件，在当前主看板里只能有一种默认样式。

允许存在尺寸档位，但不允许同层级、同语义组件各写各的视觉。

本规范优先约束以下高频组件：

- 卡片容器
- 卡片标题区
- 筛选工具栏
- 输入框 / 下拉框 / 自动完成
- 页签 / 筛选标签 / 分段切换
- 按钮
- 表格
- 图表区
- 状态标签 / badge / 提示框

---

## 2. 总原则

### 2.1 一类组件只保留一套默认样式

- 同样是“筛选下拉框”，不能一部分是 `20px`，一部分是 `24px`，一部分依赖浏览器默认高度。
- 同样是“卡片头部按钮”，不能一部分用 `text-mini`，另一部分用 `text-micro`，除非语义层级不同。
- 同样是“图表卡片头部”，不能一张卡片两行稀疏、一张卡片一行紧挤、一张卡片自定义红底 tab。

### 2.2 允许分档，但分档必须稳定

当前主看板只允许 3 个密度档：

| 档位 | 高度 | 用途 |
| --- | --- | --- |
| `standard` | `28px` | 弹窗表单、编辑器、确认操作 |
| `compact` | `24px` | 主看板工具栏、图表卡片筛选、页签、轻操作 |
| `micro` | `20px` | 行内 icon action、极窄状态标签 |

规则：

- 主看板首页默认使用 `compact`
- 弹窗 / 表单默认使用 `standard`
- `micro` 只能用于辅助动作，不能成为主操作尺寸

### 2.3 优先复用现有基础原语

当前项目内已经存在可复用基础样式，后续统一应优先复用，而不是继续写裸 Tailwind 组合：

- `.tk-panel`
- `.tk-panel-header`
- `.tk-field`
- `.tk-field--compact`
- `.tk-button`
- `.tk-chip`
- `.tk-badge`
- `.tdx-terminal-tooltip`

---

## 3. 参考 CSS 抽取出的视觉基线

参考页 CSS 的核心特征是典型 PUI 白色主题工作台风格：

- 白底内容区：`#ffffff`
- 轻灰边框：`#dddddd`
- 分隔线：`#eeeeee`
- 主文字：`#333333`
- 次文字：`#666666`
- 弱提示：`#999999`
- 禁用文字：`#cccccc`
- 品牌强调色：`#b42f32`
- Hover 背景：`#f5f5f5`
- 控件圆角：`4px`
- 非弹层模块不依赖重阴影
- 工具栏 / tab / select / tag 的标准高度以 `28px` 为母版

当前主看板为了提高密度，可以在主页面降一级用 `24px`，但必须整页统一降，不允许同类控件混用 `28 / 24 / 20 / auto`。

## 4. 统一组件规范

## 4.1 卡片容器 `PanelCard`

### 视觉要求

- 背景统一为白色内容底
- 外边框统一为 `1px solid #dddddd`
- 圆角统一为 `4px`
- 默认不加重阴影
- 容器内部分层优先用细分隔线，不用厚色块

### 结构要求

标准卡片结构统一为：

1. 标题区
2. 筛选 / 操作区
3. 内容区

如果没有筛选区，可以只有：

1. 标题区
2. 内容区

### 禁止事项

- 同层卡片一部分 `rounded-xl` 语义、一部分 `rounded-md` 语义随意混用
- 一部分卡片走纯白边框体系，一部分卡片走深色底 + 高饱和 hover
- 同样是首页信息卡，有的像图表卡，有的像弹窗卡

### 适用组件

- `MainQuoteBoard`
- `BarometerMatrixCard`
- `IntradayPanel`
- `HistoryClosePanel`
- `InstitutionPeriodMatrixCard`
- `CombinedDemandMatrixCard`
- `XrepoInlineHistoryChart`

---

## 4.2 卡片标题区 `PanelHeader`

### 视觉要求

- 标题左对齐
- 标题字号统一 `14px`
- 标题字重统一 `600`
- 辅助说明 / 更新时间统一 `12px`
- 标题区底部分隔线统一 `1px solid #eeeeee`

### 间距要求

- 主标题行统一 `padding: 8px 12px`
- 如果存在第二行筛选栏，筛选栏统一 `padding: 4px 12px`
- 标题区和筛选区之间只能使用细分隔线，不使用大色块切层

### 规则

- 图表卡片的标题区结构必须一致
- 标题右侧元信息的字号、颜色、对齐必须一致
- 不能一张卡标题行 `py-2.5`，另一张卡 `py-1.5`，第三张卡再单独写 `text-[11px]`

### 例外

- 主报价面板属于“复合主面板”，可以有更复杂的双层标题结构
- 但其内部筛选区仍必须遵守本规范的控件尺寸和字体规则

---

## 4.3 筛选工具栏 `FilterBar`

### 适用范围

- 主报价区二级筛选
- 右侧图表卡片筛选
- 历史图 / 机构统计 / XRepo 内嵌图的小工具栏

### 默认档位

- 当前主看板统一使用 `compact = 24px`

### 视觉要求

- 工具栏控件统一垂直对齐
- 标签文本统一 `11px`
- 控件间横向间距统一 `6px`
- 紧凑分隔线高度统一 `20px`

### 规则

- 同一行内禁止混入 `20px`、`24px`、`28px`、浏览器默认高度 4 套尺寸
- 工具栏中的 `label`、`select`、`input`、`button`、`chip` 必须围绕同一高度基线排布
- 工具栏中出现下拉框时，必须使用统一下拉框 primitive，不允许裸写一套新样式

---

## 4.4 输入框 / 下拉框 `Field`

### 4.4.1 CompactField

主看板首页默认字段样式。

### 样式要求

- 高度：`24px`
- 圆角：`4px`
- 背景：白底
- 边框：`1px solid #dddddd`
- 文字：`11px`
- 文本色：`#333333`
- placeholder：`#999999`
- 左右内边距：`8px`

### 技术要求

- 输入框和下拉框都必须基于 `.tk-field`
- 紧凑态统一走 `.tk-field--compact` 或等价的统一 class 组合
- 原生 `select` 必须显式锁定高度，不能继续依赖浏览器默认高度

### 4.4.2 StandardField

只用于弹窗、编辑表单、录入区。

### 样式要求

- 高度：`28px`
- 其他视觉规则与 `CompactField` 保持同一风格，只放大尺寸

### 禁止事项

- 图表卡片里继续写 `rounded-md border bg-... px-1.5 py-0.5 text-xs`
- 一个页面同时存在 `h-5`、`h-6`、未设高度的同类下拉框

---

## 4.5 页签 / 标签 / 分段切换 `Chip` / `Segmented`

### 原则

当前主看板只保留两类切换控件：

1. `CompactFilterChip`
2. `CompactSegmentedTabs`

### 4.5.1 CompactFilterChip

用于：

- 期限筛选
- 抵押品筛选
- 排名筛选
- 小范围条件切换

### 样式要求

- 高度：`24px`
- 字号：`11px`
- 默认：白底 + 灰边框 + 深灰字
- hover：浅灰底 + 品牌边框
- active：浅红底 `rgba(180, 47, 50, 0.08)` + 品牌边框 + 品牌文字

### 4.5.2 CompactSegmentedTabs

用于：

- 图表卡内部的范围切换
- 指标切换
- 视图切换

### 样式要求

- 高度：`24px`
- 与 `CompactFilterChip` 保持同一字号和圆角
- 只允许通过 active 态表达切换，不允许单独发明一套红底块样式

### 规则

- 当前主页面不再允许同时存在：
  - `miniChipClass`
  - `auxTabClass`
  - `BarometerSegmentedControl` 自定义红底按钮
  - `XrepoInlineHistoryChart` 本地 `miniChipClass`
  这 4 套并行样式
- 必须合并成同一个 compact 体系

---

## 4.6 按钮 `Button`

### 4.6.1 MainCanvasButton

主页面卡片头部和工具栏的默认按钮。

### 样式要求

- 高度：`24px`
- 字号：`11px`
- 默认：白底、灰边、深灰字
- hover：浅灰底、品牌边框、深色文字

### 4.6.2 DialogButton

弹窗确认 / 取消按钮。

### 样式要求

- 高度：`28px`
- 字号：`12px`

### 4.6.3 InlineMicroAction

行内图标按钮、极窄操作按钮。

### 样式要求

- 高度：`20px`
- 宽高尽量一致
- 只作为辅助动作，不作为主操作

### 规则

- 同一级标题栏按钮不能一部分 `24px`，一部分 `20px`
- “打开大图”“下载”“导出”“更多”这类同层动作必须用同一尺寸档

---

## 4.7 表格 `DataTable`

### 视觉要求

- 表头背景统一 `#f5f5f5`
- 表头文字统一 `12px`、`#666666`
- 行边框统一使用细灰边框
- 表体文字统一使用基础正文字号，不再零散硬编码
- 行 hover 统一使用浅灰高亮

### 对齐要求

- 代码 / 名称类：左对齐
- 数值 / 比例 / 价格类：右对齐
- 时间 / 日期类：居中或左对齐，但整表保持一致
- 数字列建议统一使用 tabular-nums

### 密度要求

- 同一张表内行高保持一致
- 同一层表头单元格不能同时出现 `11px`、`12px`、`13px` 混排

### 规则

- `DenseTable` 允许更紧凑，但必须是整个模块统一的 dense 方案
- 不能把标题、状态、数值、标签都各自硬编码成不同字号

---

## 4.8 图表区 `ChartCanvas`

### 视觉要求

- 图表背景保持干净，不增加营销化装饰
- 网格线统一浅灰
- 轴标签统一 `10px` 或 `11px`
- 图例文字统一 `11px` 或 `12px`
- Tooltip 统一白底、灰边、`4px` 圆角、轻阴影

### 颜色要求

优先使用参考 CSS 和白板规范中的稳定图表色板：

- 蓝：`#4691f7`
- 橙：`#fa7602`
- 黄：`#faba02`
- 紫：`#7c75cb`
- 红：`#f01414`
- 绿：`#14a014`

规则：

- 同一指标跨页面尽量保持同色
- 同类型折线图不要每张卡都重新定义一组颜色

---

## 4.9 状态标签 `StatusTag` / `Badge`

### 适用范围

- 表格内状态
- 重要标识
- 轻量 badge

### 统一要求

- 同一类状态标签统一圆角、边框粗细、字号、内边距
- 表格内状态标签默认使用 `20px` 高
- 文本统一不超过一行

### 状态语义

- `neutral`
- `brand`
- `up`
- `down`
- `warn`

### 规则

- 不能一处用纯色实心块，一处用描边，一处再用不同圆角，除非语义完全不同

---

## 4.10 Tooltip / 下拉浮层 / 自动完成浮层

### 样式要求

- 背景：白色
- 边框：`1px solid #dddddd`
- 圆角：`4px`
- 文本：`12px`
- 阴影：轻阴影
- hover 行背景：`#f5f5f5`

### 规则

- 自动完成浮层、普通 tooltip、下拉菜单，必须属于同一视觉家族
- 不允许某些浮层还是暗底，某些已经白底

---

## 4.11 Empty / Loading

### Empty

统一文案建议：

`提示：该品种无此项记录，或在当前过滤条件下没有数据`

规则：

- 空状态内嵌到当前容器
- 不引入大插图
- 保持金融工作台语气克制

### Loading

- 只覆盖内容区，不覆盖卡片标题区
- 保持布局稳定，不因 loading 改变卡片高度

## 6. 当前页面必须消灭的样式反模式

### 6.1 裸写原生 select

以下写法需要淘汰：

- `rounded-md border ... px-1.5 py-0.5 text-xs`
- 未显式设置高度的原生 `select`

原因：

- 会继续造成同类下拉框高度不一致
- 破坏主页面统一控件体系

### 6.2 重复实现 chip / tab helper

以下本地 helper 不应长期并存：

- `miniChipClass`
- `auxTabClass`
- `BarometerSegmentedControl` 内本地 button 样式
- `XrepoInlineHistoryChart` 内本地 `miniChipClass`

目标：

- 合并成一套 compact chip / segmented primitive

### 6.3 交互控件硬编码字号

禁止在可复用控件上继续直接使用：

- `text-[11px]`
- `text-[12px]`
- `text-xs`

除非：

- 该内容是图表坐标轴
- 该内容是纯注释 / footnote
- 该内容不是可复用交互控件

### 6.4 同层按钮尺寸不一致

同一个卡片头部内：

- 不能一个按钮 `24px`
- 另一个按钮 `20px`
- 第三个按钮再跟随内容自然撑高

### 6.5 同层卡片头部密度不一致

同一列里的图表卡片：

- 不能某张标题区两行过松
- 不能某张筛选栏 padding 更厚
- 不能某张卡片的标题元信息比别的卡片更抢眼

## 7. 推荐的主页面统一落地口径

为避免后续继续混搭，建议主页面明确固化为以下原语：

| 原语 | 统一样式 |
| --- | --- |
| `PanelCard` | 白底、灰边、4px 圆角、无重阴影 |
| `PanelHeader` | 标题 14px/600，说明 12px，细分隔线 |
| `CompactFilterBar` | 主页面默认工具栏，24px 体系 |
| `CompactField` | 所有首页筛选输入 / 下拉 / 自动完成 |
| `CompactFilterChip` | 所有首页轻量筛选标签 |
| `CompactSegmentedTabs` | 所有首页图表范围 / 指标切换 |
| `MainCanvasButton` | 所有首页头部动作按钮 |
| `DenseTable` | 所有高密度业务表格 |
| `StatusTag` | 所有行内状态标签 |
| `LightTooltip` | 所有 tooltip / 浮层 |

---

## 8. 验收清单

满足以下条件，才能算“主页面样式统一完成”：

- 首页所有筛选下拉框高度一致
- 首页所有筛选输入框高度一致
- 首页所有图表卡片头部结构一致
- 首页所有 chip / tab 只保留一套 compact 视觉
- 首页所有头部按钮只保留一套 compact 视觉
- 首页所有行内状态标签只保留一套样式家族
- 首页所有复用控件不再直接硬编码字号 / 边框 / 背景
- 不再出现“同一种组件多套样式并行”

---

## 9. 实施优先级

建议按以下顺序收口：

1. 统一 `Field`
2. 统一 `Chip / Segmented`
3. 统一 `PanelHeader`
4. 统一 `Button`
5. 统一 `StatusTag`
6. 统一 `DenseTable`

原因：

- `Field` 和 `Chip` 是当前视觉割裂最明显的来源
- `PanelHeader` 决定整页卡片是否像同一套系统
- `Button` 和 `StatusTag` 收口后，交互层会明显稳定

## 10. 与现有文档的关系

- `docs/tdx-pui-white-theme-spec.md` 负责描述白色主题和 PUI 参考样式的完整来源
- `docs/theme-system-overview.md` 负责描述主题文件层级、变量映射和 CSS 覆盖策略
- 本文档只负责当前主看板的执行口径：哪些组件必须统一、统一成什么样、哪些混搭必须消失

本文优先级高于单个页面组件内部的临时样式决定。
