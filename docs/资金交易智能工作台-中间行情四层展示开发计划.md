# 资金交易智能工作台-中间行情四层展示开发计划

> 创建日期：2026-05-28  
> 目标分支：`codex-middle-four-layer-dev-plan`  
> 适用范围：中间投研 / 行情数据摘要区，以及从摘要区进入的行情详情与放大分析能力。

## 1. 背景与目标

当前页面已经具备左侧行情表、右侧趋势图和中间报价区，但“中间部分”的行情摘要需要从单纯入口升级为可部署验证的四层展示体系：

```text
图标层       = 状态提醒
概览层       = 决策摘要
详情层       = 日常查看 / 操作
放大详情层   = 深度分析 / 横向对比 / 批量处理
```

本计划的目标不是把同一块内容简单放大缩小，而是让每一层回答不同问题：

| 层级 | 用户问题 | 设计原则 |
|---|---|---|
| 图标层 | 现在有没有异常或值得关注的变化？ | 只展示状态、方向、异常数量或关键提示 |
| 概览层 | 这个模块值不值得点进去？ | 展示 1 个主指标、2-3 个支撑指标、更新时间 / 状态 |
| 详情层 | 我能不能完成日常查看和操作？ | 提供表格、筛选、切换、发单、下载等主工作流 |
| 放大详情层 | 我要深入分析或批量处理什么？ | 提供大图、矩阵、排行、对比、分布、批量操作 |

## 3. 四层展示总设计

### 3.1 图标层

图标层用于中间栏极窄态、收缩态或模块导航条。

通用字段：

| 字段 | 说明 |
|---|---|
| `moduleId` | 模块 ID |
| `icon` | 模块图标 |
| `status` | `normal` / `warning` / `error` / `empty` / `delayed` |
| `direction` | 上行 / 下行 / 横盘 / 分化扩大 / 分化收敛 |
| `badge` | 异常数、可点击量、更新时间短标 |
| `tooltip` | 展示主指标、更新时间、状态原因 |

交互：

- hover 显示 tooltip；
- 单击图标打开概览滑出层；
- 有异常时图标保留固定位置，不能因无数据消失；
- `error`、`delayed`、`empty` 必须有非颜色提示。

### 3.2 概览层

概览层是中间栏默认态。

通用要求：

- 每个模块至少展示 1 个主指标；
- 至少展示 2 个支撑数据；
- 必须展示更新时间、数据日期或数据状态；
- 允许迷你趋势，但不能替代主指标；
- 卡片点击进入详情层；
- 卡片内小控件点击不冒泡打开详情。

### 3.3 详情层

详情层为中等浮框或中栏上层详情面板。

通用要求：

- 不遮挡右侧主行情 / 聊天区域；
- 同时只允许一个详情浮框；
- 标题区展示模块名、当前上下文、更新时间 / 状态；
- 支持模块内部 tab、期限、周期、产品切换；
- `Esc`、关闭按钮、遮罩关闭；
- 数据刷新时保持用户当前筛选上下文。

### 3.4 放大详情层

放大详情层用于深度分析，不是详情层的等比放大。

建议形态：

| 类型 | 适用模块 |
|---|---|
| 大图分析面板 | 加权价格走势、匿名成交走势、NCD |
| 深度报价面板 | X-Repo 双边 |
| 横向对比表 / 热力矩阵 | 今日大行情价格、机构分期限统计 |
| 场内外价差分析 | 交易所回购 |

通用要求：

- 从详情层进入时继承产品、期限、指标、时间范围；
- 支持导出当前视图；
- 支持更完整 tooltip、标注、排行、筛选；
- 有明确返回详情层或关闭入口；
- 后续可复用 `MarketChartPage` 的全屏图表能力，但需要统一深色主题和数据模型。

## 4. 模块详细设计

### 4.1 今日大行情价格

核心：看资金面松紧和大行 / 非银报价中枢。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示资金面松 / 紧 / 平衡状态，附最新更新时间；异常时显示缺报价或延迟标记 |
| 概览层 | 展示大行、非银核心期限报价，如隔夜、7D；展示涨跌方向和更新时间 |
| 详情层 | 全机构报价表：机构、期限、非银利率、涨跌、银行利率、涨跌、更新时间；保留手工输入和下载入口 |
| 放大详情 | 多机构、多期限横向对比；支持期限列扩展、机构筛选、价差热力、历史变动 |

开发任务：

- 抽象 `BankPriceSummaryCard`；
- 将现有 `LeftSummaryPanel` 中的大行价格逻辑接入概览卡；
- 将 `BankRateEditorModal` 保留为详情层操作；
- 新增放大详情的机构 × 期限对比表。

验收点：

- 缺 7D 报价时不撑坏布局；
- 手工修改后概览、详情同步刷新；
- 下载按钮从展示态变为可导出；
- 更新时间清晰可见。

### 4.2 X-Repo 双边

核心：看可成交报价，并进入发单操作。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示可成交 / 无量 / 异常；badge 展示可点击量或异常状态 |
| 概览层 | 展示主合约最优价、量、可点数量、更新时间 |
| 详情层 | 合约报价表 + 发单操作；使用“报价行情 / X-Repo双边”口径，含合约筛选、新订单、一键激活、发送 |
| 放大详情 | 深度报价、成交分布、正逆两侧深度、批量发送、成交回放 |

开发任务：

- 抽象 `XRepoSummaryCard`；
- 将现有静态 `leftSections` 中 XREPO 数据升级为模块数据源；
- 为“发送”按钮预留业务回调；
- 为“下载”接入 CSV / Excel 导出；
- 新增 `XRepoDepthPanel` 放大详情。

验收点：

- 无量、取数失败、延迟三种状态有明确展示；
- 发单按钮具备 loading、成功、失败状态；
- 合约筛选不会重置当前展开层级；
- 批量操作必须有二次确认。

### 4.3 交易所回购

核心：看场内回购价格方向，并作为场外报价参照。

| 层级 | 设计 |

| 概览层 | 展示 GC001 / R001 最新值和涨跌，补充成交量 |
| 详情层 | 核心 / 上交所 / 深交所三视图表格 |
| 放大详情 | 场内外价差、历史走势、沪深对比、成交量变化 |

开发任务：

- 将 `ExchangeRepoCard` 拆成摘要、详情、放大详情三层能力；
- 核心视图保留 GC001、GC007、R-001、R-007 代表品种；
- 明确“核心视图只展示代表品种”文案；

验收点：

- 三个 tab 切换不丢失选中品种；
- 下载按钮导出当前视图；
- 延迟数据必须展示延迟时间；
- 场内外价差需要标明对比基准来源。

### 4.4 NCD

核心：看存单利率方向、评级分层和期限曲线。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示利率上 / 下行，附关键评级状态 |
| 概览层 | 展示关键评级和期限的曲线变化，如 AAA 1M / 1Y 最新值和涨跌 |
| 详情层 | 趋势图 + 期限切换；一级 / 二级切换；趋势图 / 表格切换 |
| 放大详情 | 多评级、多期限、利差分析；一级与二级联动对比 |

开发任务：

- 为一级趋势图补充期限切换，不再固定 1M；
- 展开后的趋势视图继承当前期限；
- 增加评级利差视图；
- 将一级 / 二级状态、期限、时间范围统一到模块上下文。

验收点：

- 一级、二级切换后可理解当前展示口径；
- 详情和放大详情继承同一期限；
- hover tooltip 展示评级、期限、日期、收益率、涨跌；
- 无数据时曲线区域保留高度并展示空态。

### 4.5 加权价格走势

核心：看近 5 日价格变化，并确认成交量是否支撑趋势。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示趋势方向，上行 / 下行 / 横盘 |
| 概览层 | 展示近 5 日价格和成交量变化 |
| 详情层 | 折线 + 柱状图；产品、对比品种、时间范围切换 |
| 放大详情 | 跨产品、跨区间、量价联动分析 |

开发任务：

- `HistoryClosePanel` 增加产品选择，不再固定 R001；
- 拆除或显性化来自匿名成交模块的隐藏叠加联动；
- 未选择对比时展示成交量柱；
- 选择对比时明确切换为利差柱，并给出图例。

验收点：

- 产品切换、对比切换、时间范围切换互不重置；
- 成交量柱和利差柱不能混淆；
- tooltip 展示日期、加权价格、成交量 / 利差；
- 放大详情支持多产品并排比较。

### 4.6 匿名成交走势

核心：看日内成交中枢、波动强弱和异常点。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示日内波动强弱，异常点数量 |
| 概览层 | 展示当前成交中枢、偏离均线、异常点 |
| 详情层 | 日内成交趋势；产品切换、叠加品种、参考线 |

- 匿名成交叠加品种不再隐式影响加权价格走势，或增加联动提示和开关；
- 新增异常点识别和标记；

验收点：

- 无叠加时图中指标与文案一致；
- 叠加品种影响范围必须清晰；
- tooltip 展示时间、成交利率、参考线偏离、成交量；
- 异常点点击可定位到明细。

### 4.7 机构分期限统计

核心：看机构结构分化，判断谁更贵、谁更便宜。

| 层级 | 设计 |
|---|---|
| 图标层 | 显示分化是否明显，价差扩大 / 收敛 |
| 概览层 | 展示哪类机构最贵 / 最便宜，以及当前期限和指标 |
| 详情层 | 机构曲线对比；期限、指标、机构类型切换 |
| 放大详情 | 多机构矩阵、期限结构、排名、热力图 |

开发任务：

- `CfetsInstPanel` 保留曲线对比作为详情层；
- `activeRange` 要么接入时间范围，要么从接口和组件中移除；
- 激活或删除 `matrix`、`bond` 的未接入口径，避免 UI 死分支；
- 新增机构 × 期限 × 指标矩阵放大详情。

验收点：

- 图例点击隐藏 / 恢复曲线后状态可见；
- 期限和指标切换后概览同步刷新；
- 放大矩阵支持排序和导出；
- 多机构颜色不依赖单一色相，避免难以区分。

## 5. 数据与状态模型

建议新增统一模块配置：

```ts
type MarketLayerStatus = "normal" | "warning" | "error" | "empty" | "delayed";

type MarketLayerModule = {
  id: string;
  title: string;
  group: "基准价格" | "走势统计";
  status: MarketLayerStatus;
  updatedAt: string;
  iconSummary: {
    direction?: "up" | "down" | "flat" | "wide" | "narrow";
    badge?: string;
    tooltip: string;
  };
  overview: {
    primary: string;
    secondary: string[];
    miniTrend?: number[];
  };
  context: {
    product?: string;
    tenor?: string;
    range?: string;
    metric?: string;
    market?: string;
  };
};
```

开发原则：

- 概览层、详情层、放大详情层共享同一个 `context`；
- 所有数据异常都走统一 `status`；
- “下载”“发送”“手工输入”必须有明确事件出口；
- 当前先接前端状态，接口接入时替换数据源，不重写 UI 层。

## 6. 组件拆分建议

建议从 `App.tsx` 中逐步拆出以下组件，降低单文件复杂度：

```text
src/app/features/market-layers/
  MarketLayerRail.tsx
  MarketLayerOverview.tsx
  MarketLayerDetailPopover.tsx
  MarketLayerExpandedView.tsx
  modules/
    BankPriceLayer.tsx
    XRepoLayer.tsx
    ExchangeRepoLayer.tsx
    NcdLayer.tsx
    WeightedPriceLayer.tsx
    AnonymousTradeLayer.tsx
    InstitutionTermLayer.tsx
```

拆分顺序：

1. 先抽配置和纯展示组件；
2. 再迁移单个模块；
3. 最后再做放大详情；
4. 每次迁移后保持原页面视觉和现有交互不退化。

## 9. 风险与待确认

| 风险 / 问题 | 影响 | 建议 |
|---|---|---|
| `App.tsx` 文件过大 | 后续维护困难 | 先按模块拆分，再做功能增强 |
| 部分按钮只有视觉无交互 | 部署验证无法通过 | M5 集中补齐动作出口 |
| 加权走势和匿名成交存在隐藏联动 | 用户难以理解 | 拆除联动或增加显式联动开关 |
| NCD 一级趋势固定 1M | 与四层设计不一致 | 补期限上下文并贯穿展开层 |
| `matrix` / `bond` 死分支 | 造成验收口径混乱 | 明确下线或接入导航 |
| 放大详情数据量大 | 图表和矩阵性能风险 | 大表使用虚拟滚动，大图限制默认序列数量 |

## 10. 推荐优先级

优先级建议：

1. `X-Repo双边`：最接近真实交易动作，优先打通详情和放大详情。
2. `加权价格走势`、`匿名成交走势`：先解决隐藏联动和文案 / 数据不一致。
3. `NCD`：补齐期限上下文继承。
4. `机构分期限统计`：最后做矩阵放大详情，工作量最大但价值高。
5. `今日大行情价格`、`交易所回购`：以补导出、状态和放大分析为主。
