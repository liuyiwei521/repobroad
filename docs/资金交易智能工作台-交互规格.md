# 资金交易智能工作台 · 交互规格（前端）

> 纯交互行为清单。每个控件的 点击 / 双击 / hover / 键盘 / 状态 / 联动 行为。
> 不含产品背景，配合《产品详细描述》使用。

---

## 0. 全局约定

### 0.1 交互术语

| 术语 | 定义 |
|---|---|
| 单击 | 鼠标左键 click（mousedown + mouseup 同一目标） |
| 双击 | dblclick，间隔 < 300ms |
| hover | mouseenter 显示 / mouseleave 隐藏，hover 提示延迟 300ms 出现 |
| 选中 | 元素进入 selected 态，带高亮边框，唯一或多选见各控件 |
| 联动 | 操作 A 引发其他区域 B 的状态变化 |
| 闪烁 | 数据更新时背景色短暂高亮（≤600ms）后恢复，涨绿跌红 |

### 0.2 全局键盘

| 按键 | 行为 |
|---|---|
| `Esc` | 关闭最上层浮层（聊天弹窗 → 中等浮框 → 全屏矩阵，按层级逐层关） |
| `Tab` / `Shift+Tab` | 焦点在当前可交互区内前进/后退 |
| `Enter` | 触发当前焦点控件的主操作 |
| `Ctrl/Cmd + S` | 当全屏分配矩阵打开时 = 保存分配；否则无操作 |

### 0.3 焦点与层级

- 浮层打开时，焦点锁定在浮层内（focus trap），背景不可 Tab 到达。
- 同时只允许一个全屏矩阵；聊天弹窗可与全屏矩阵共存（矩阵在更上层）。
- 任意浮层打开时，底层三栏仍实时刷新数据（不冻结）。

### 0.4 数据刷新

- 报价盘、台账数值、待分配、聊天为实时推送，更新时对应行/单元格闪烁。
- 用户正在编辑的输入框（分配格子、聊天输入框、试算利率）在编辑期间**不被推送覆盖**；失焦后恢复同步。

## 1. 顶栏

### 1.1 资金面基准（DR007 / 情绪四值 / 结论）

| 事件 | 行为 |
|---|---|
| hover | 显示 tooltip：四值口径说明与更新时间 |
| 单击 | 无（纯展示）；如需详情走中栏"资金面情绪"入口 |
| 数据更新 | 数值闪烁，涨绿跌红 |

### 1.2 账户切换

| 事件 | 行为 |
|---|---|
| 单击 | 展开账户/产品下拉 |
| 选择项 | 切换当前上下文，左/中/右栏全部按新账户刷新；切换前若有未保存编辑 → 二次确认 |
| 键盘 | 下拉打开时 `↑/↓` 移动，`Enter` 选定，`Esc` 收起 |

### 1.3 通知铃铛

| 事件 | 行为 |
|---|---|
| 单击 | 展开通知面板（AI 待决策、系统提示） |
| 角标 | 未读数；点开后清零 |
| 单击某条通知 | 跳转到对应位置（如左栏待决策项 / 对应聊天弹窗） |

## 2. 左栏 · 任务

### 2.1 栏头 — 试算利率

| 事件 | 行为 |
|---|---|
| 单击数值 | 转为可编辑输入框，全选当前值 |
| 输入 | 仅接受数字与小数点；非法输入边框变红、阻止失焦提交 |
| `Enter` / 失焦 | 提交新值 → 台账所有账户保本金额、保本利率重算并闪烁 |
| `Esc` | 取消编辑，恢复原值 |

### 2.2 交易单台账 — 表头

| 事件 | 行为 |
|---|---|
| hover 列头 | 显示该列完整名称 tooltip |
| 单击列头 | 无排序（排序由手动拖拽行实现，见 2.3）；列头不可点排序 |

### 2.3 交易单台账 — 账户行

| 事件 | 行为 |
|---|---|
| hover | 行底色加深；右侧出现轻量操作把手（拖拽手柄） |
| 单击 | 选中该行（唯一选中，高亮边框）→ **联动右栏报价盘**：筛出并高亮能满足该账户的报价（利率≥保本、品种/质押/账户要求匹配） |
| 再次单击已选中行 | 取消选中 → 报价盘取消筛选高亮 |
| 双击 | 打开全屏分配矩阵，定位到该账户行 |
| 拖拽手柄 | 进入拖拽排序；拖动时其他行让位预览；松手提交新顺序（顺序本地持久化） |
| 键盘 `↑/↓` | 在台账行间移动选中（焦点在台账时） |
| 键盘 `Enter` | 等同双击：打开全屏矩阵定位该账户 |

### 2.4 交易单台账 — 行状态（视觉，非交互）

| 状态 | 表现 | 可交互性 |
|---|---|---|
| 正常 | 常规显示 | 可选中/拖拽/双击 |
| 保本预警 | 左边框 + 保本率红字 | 同正常 |
| 已完成 100% | 整行淡化 | 仍可选中/双击查看，拖拽允许 |
| 数据更新 | 未出/完成度/保本率闪烁 | — |

### 2.5 待分配额度区

#### 2.5.1 区块头

| 事件 | 行为 |
|---|---|
| 显示条件 | 有待分配条目时显示；无则整区隐藏，台账上移 |
| hover 角标 | tooltip：待分配总金额与笔数 |

#### 2.5.2 待分配条目

| 事件 | 行为 |
|---|---|
| hover | 行底色加深 |
| 单击条目主体 | 唤起该对手的聊天弹窗（含成交上下文） |
| 单击"分配"按钮 | 打开全屏分配矩阵，预置该笔待分配额度为当前操作对象（对应对手列高亮） |
| 新条目到达 | 从顶部插入并短暂高亮，伴随角标数 +1 |
| 条目被分配完成 | 淡出移除 |

## 3. 中栏 · 投研 / 行情入口

### 3.1 入口条（通用）

| 事件 | 行为 |
|---|---|
| hover | 整条底色加深，放大图标变为高亮态 |
| 单击任意区域 | 打开对应**中等浮框**（不遮挡右栏报价盘） |
| 单击放大图标 | 同上（图标只是显式入口） |
| 代表值数据更新 | 代表值闪烁，涨绿跌红 |
| 键盘 `Enter` | 焦点在该条时打开浮框 |

### 3.2 中等浮框（投研/行情详情）

| 事件 | 行为 |
|---|---|
| 打开 | 浮于中栏区域上层，定位不覆盖右栏；focus trap 生效 |
| 内部 tab/周期切换（如近5日/1M/半年） | 切换图表数据，仅刷新框内 |
| 单击框外遮罩 | 关闭浮框 |
| 关闭按钮 / `Esc` | 关闭浮框 |
| 多次打开不同入口 | 替换当前浮框内容（同时只存在一个中等浮框） |

### 3.3 弹性收缩（响应缩放，非用户直接控件）

| 阶段 | 触发 | 中栏行为 | 入口条交互变化 |
|---|---|---|---|
| 宽松 | ≥100% 宽度充裕 | 完整显示 | 正常 |
| 紧张 | 空间变少 | 省副标题，留名称+代表值 | 单击仍打开浮框 |
| 极限 | 空间极少 | 收成窄边/图标条 | 单击窄边图标 → 临时滑出入口浮层；滑出层内单击某条 → 打开中等浮框；点窄边外 / `Esc` 收回滑出层 |
| 矩阵打开 | 进入全屏矩阵 | 中栏折叠（不可交互） | — |

> 收缩为自动响应布局宽度，无需用户手动切换。

## 4. 右栏 · 非银报价盘

### 4.1 层级切换（1级 / 2级）

| 事件 | 行为 |
|---|---|
| 单击 | 切换报价层级，列表整体刷新；当前态高亮 |
| 键盘 | 焦点在切换器时 `←/→` 切换 |

### 4.2 筛选条（金额 / 利率区间，方向）

| 控件 | 事件 | 行为 |
|---|---|---|
| 金额区间输入 | 输入 | 仅数字；下限>上限时标红阻止 |
| 利率区间输入 | 输入 | 同上 |
| 区间提交 | `Enter`/失焦 | 按区间过滤报价列表 |
| 正/逆回购方向 | 单击 | 上下同屏均在，方向控件用于定位/折叠对应区块（非互斥切换） |

### 4.3 期限标签（R001…R028）

| 事件 | 行为 |
|---|---|
| 单击 | 选中该期限，列表按期限过滤；当前态高亮（单选） |
| 再次单击已选 | 取消该期限过滤（恢复全部） |
| 键盘 | 焦点在标签组时 `←/→` 移动并即时过滤 |

### 4.4 分组头（利率地方 / 存单商金 / 信用）

| 事件 | 行为 |
|---|---|
| hover | tooltip：分组口径 |
| 单击 | 折叠/展开该分组（汇总均价始终可见） |

### 4.5 报价行（核心）

| 事件 | 行为 |
|---|---|
| hover | 行底色加深；显示该行押券/账户要求全文 tooltip（若被简称截断） |
| **单击** | 唤起聊天弹窗（快捷发送消息），定位到该对手；弹窗顶部带本条报价摘要 |
| **双击** | 直接发送（无修正确认，无中间弹窗）；发送后行出现"已发送"瞬时状态标记 |
| 价格更新 | 该行利率单元格闪烁，涨绿跌红 |
| 被左栏账户筛选命中 | 行高亮为"匹配"态（与 hover 区分）；未命中行可置灰 |
| 键盘 `↑/↓` | 焦点在列表时移动当前行 |
| 键盘 `Enter` | = 单击（唤起聊天弹窗） |
| 键盘 `Shift+Enter` | = 双击（直接发送） |

### 4.6 最优/次优标签（视觉，非交互）

- 由 AI 自动标注，随数据刷新更新；不可点击。

## 5. 聊天弹窗

### 5.1 弹窗容器

| 事件 | 行为 |
|---|---|
| 打开来源 | 报价行单击 / 待分配条目单击 / 通知跳转 |
| 形态 | 浮于上层，不遮挡左栏与中栏关键区 |
| 拖拽标题栏 | 移动弹窗位置（限制在视口内） |
| 关闭按钮 / `Esc` | 关闭弹窗（不影响后台会话与解析） |
| 多次从不同对手打开 | 见 5.4 多会话策略 |

### 5.2 报价摘要条（弹窗顶部）

| 事件 | 行为 |
|---|---|
| 展示 | AI 解析出的品种/期限/价/建议 |
| 单击 | 可定位到右栏报价盘对应行（高亮）；非必须 |

### 5.3 消息流与输入

| 控件 | 事件 | 行为 |
|---|---|---|
| 消息流 | 新消息到达 | 自动滚到底；若用户上滑查看历史则不强制滚动，显示"新消息"提示按钮 |
| 输入框 | 输入 | 普通文本输入；编辑期间不被推送覆盖 |
| 输入框 | `Enter` | 发送消息 |
| 输入框 | `Shift+Enter` | 换行 |
| 发送按钮 | 单击 | 发送消息 |

### 5.4 成交后 — "立即分配"快捷入口

| 事件 | 行为 |
|---|---|
| 出现条件 | 该会话产生成交（AI 解析判定）后，在弹窗内出现按钮 |
| 单击 | 打开全屏分配矩阵，预置该笔成交额度（等同左栏"分配"按钮入口） |

### 5.5 多会话策略（待最终确认，前端预留）

| 选项 | 行为 |
|---|---|
| A 单弹窗替换 | 打开新对手 → 替换当前弹窗内容 |
| B 有限多弹窗 | 允许 N 个弹窗平铺/堆叠（N 上限由配置决定），各自独立 |

> 实现时以配置项 `chatPopup.mode = 'replace' \| 'multi'` 控制，默认 `replace`。

## 6. 全屏分配矩阵

### 6.1 容器与开关

| 事件 | 行为 |
|---|---|
| 打开来源 | 左栏台账行双击 / 待分配"分配" / 聊天"立即分配" / 台账"展开" |
| 打开效果 | 覆盖三栏全屏；中栏折叠让位；矩阵层级高于聊天弹窗 |
| 收起按钮 / `Esc` | 关闭矩阵，恢复常态三栏；若有未保存编辑 → 二次确认 |

### 6.2 冻结窗格滚动

| 区域 | 行为 |
|---|---|
| 左侧账户列（含指令/未出等） | 横向滚动时**固定**不动 |
| 顶部对手行（含总额/差额行） | 纵向滚动时**固定**不动 |
| 中间格子区 | 横向（看 20+ 对手）+ 纵向（看全部账户）滚动 |
| 滚轮 / 触控板 | 在格子区滚动；Shift+滚轮 = 横向滚动 |

### 6.3 分配格子（单元格）

| 事件 | 行为 |
|---|---|
| 单击 | 选中单元格（高亮），进入可编辑 |
| 双击 / 直接键入 | 进入编辑并替换内容 |
| 输入 | 仅数字与小数点；非法输入标红 |
| `Enter` | 提交，焦点下移到同列下一账户格 |
| `Tab` | 提交，焦点右移到同账户下一对手格 |
| `Esc` | 取消本格编辑，恢复原值 |
| 方向键 `↑↓←→` | 在格子间移动选中（非编辑态） |
| 提交后联动 | 该对手列"差额"实时重算；该账户行汇总/完成度预览更新 |
| 推送冲突 | 正在编辑的格子不被覆盖；失焦后同步 |

### 6.4 校验显示（实时，非交互）

| 元素 | 行为 |
|---|---|
| 差额行 | 0 = 正常色；>0（未分完）= 提示色；<0 不允许（输入即被阻止，超出对手总额无法提交） |
| 账户未出列 | 随分配额变化实时更新预览 |
| 备注列 | 展示账户限制文本；hover 显示全文 |

### 6.5 工具栏按钮

| 按钮 | 单击行为 |
|---|---|
| 自动分配 | 调 AI 生成草案，填充各格子（覆盖空格，已手填格是否覆盖 → 二次确认）；不可分账户在备注/格内标注原因 |
| 保存分配 | 校验通过后保存 → 回写左栏台账（已出/未出/完成度刷新、保本重算）；**允许差额非 0 保存** |
| 新增需求 | 占位，单击暂无功能逻辑（保留按钮，置 disabled 或 toast"暂未开放"） |
| 广播 | 占位，同上 |
| 收起 | 见 6.1 |

### 6.6 矩阵键盘汇总

| 按键 | 行为 |
|---|---|
| `↑↓←→` | 移动选中格 |
| 键入数字 | 直接编辑当前格 |
| `Enter` | 提交并下移 |
| `Tab` / `Shift+Tab` | 提交并右移 / 左移 |
| `Esc` | 取消格编辑；再次 `Esc` 关闭矩阵 |
| `Ctrl/Cmd+S` | 保存分配 |

## 8. 状态与边界清单

| 场景 | 期望行为 |
|---|---|
| 编辑中收到推送 | 不覆盖正在编辑的输入；失焦后同步 |
| 多浮层叠加 | `Esc` 自上而下逐层关闭（矩阵 > 聊天 > 中等浮框） |
| 待分配区为空 | 整区隐藏，台账上移 |
| 报价区间下限>上限 | 标红，阻止过滤提交 |
| 矩阵差额<0（超对手总额） | 输入即阻止，无法提交该格 |
| 矩阵差额>0 保存 | 允许保存（留差额） |
| 自动分配覆盖手填格 | 二次确认后才覆盖 |
| 关闭矩阵/切换账户有未保存编辑 | 二次确认 |
| 极限缩放中栏 | 收成窄边图标，功能经滑出层保留 |
| 已完成账户(100%) | 行淡化，仍可交互 |
