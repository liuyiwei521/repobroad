## 1. 产品概述

### 1.1 一句话定位

面向资金交易员的单屏一体化智能工作台，以**任务为核心**，将任务、投研、行情、交易四个支柱整合到同一屏幕，由 AI 贯穿全流程（实时解析报价、辅助分配、提示决策、跟踪进度），形成"判断方向 → 抓住机会 → 完成成交 → 回写任务进度"的完整闭环。

### 1.2 目标用户

资金交易台的交易员。其典型工作节奏为高频、快节奏，每天面对大量来自不同对手的私聊询价与报价，核心 KPI 是：在满足保本与合规约束的前提下，把各账户的指令缺口（未出金额）做到 0。

### 1.3 解决的核心问题

| 割裂 | 老版现状 | 新版方案 |
|---|---|---|
| 目标与机会 | 指令台账在 Excel，报价在看板，需反复对照 | 台账缺口与报价盘联动，点账户即筛匹配报价 |
| 沟通与系统 | 私聊在外部工具，谈成后手工录入 | AI 实时解析私聊，自动结构化为报价盘数据 |
| 判断与动作 | 投研判断停留在"看一眼" | 投研底价/观点直接作用于报价与分配决策 |

### 1.4 设计原则

- **任务为核心**：左栏任务与右栏报价盘是不可压缩的"硬骨头"，中栏投研为弹性缓冲。
- **一屏完成**：常规交易动作（看判断、抓机会、谈成交、盯进度）不需要切换页面。
- **AI 包揽重复劳动**：解析、匹配、分配草案、进度跟踪由 AI 完成，人只做决策。
- **高频友好**：信息密度高、关键数突出、操作链路短，不依赖 hover 才出现关键信息。

## 2. 总体架构

### 2.1 四个支柱

| 支柱 | 回答的问题 | 承载内容 | 界面落位 |
|---|---|---|---|
| 投研 | 今天往哪个方向、底价多少？ | 资金面松紧、走势预测、AI 观点 | 中栏 + 顶栏 |
| 行情 | 市场上有什么机会、谁在报？ | 基准价、非银报价盘、走势统计 | 中栏（基准/走势）+ 右栏（报价盘） |
| 任务 | 我今天必须完成什么？ | 交易单台账、待分配额度 | 左栏 + 全屏分配矩阵 |
| 交易 | 怎么把机会变成成交？ | 私聊、解析、报价、成交、分配 | 报价盘操作 + 聊天弹窗 |

### 2.2 核心数据流与闭环

```
私聊（高频口语）
   │  AI 解析（品种/期限/价/对手）
   ▼
报价盘（结构化、可比、可操作）  ← 投研提供判断依据
   │  单击聊 / 双击发
   ▼
私聊成交
   │
   ▼
待分配额度（左栏提醒 + 弹窗快捷入口）
   │  分配矩阵：账户 × 对手，手动/AI 填格
   ▼
保存分配 → 回写台账（已出↑、未出↓、完成度↑、保本重算）
```

**闭环要义**：成交不是终点，回写任务才是闭环真正合上的地方。

### 2.3 AI 助手的角色

贯穿四环，承担：

- 解析私聊消息为结构化报价，实时推送报价盘
- 在报价盘每个分组内自动标注最优/次优价
- 为缺口账户匹配可成交报价（结合保本、品种、质押、账户要求）
- 生成分配草案（接口校验 + 保本约束 + 优先级排序）
- 跟踪指令进度，在需要人决策的节点发出提示

## 3. 整体布局

### 3.1 屏幕与适配

- 目标屏幕：1K（1920×1080）单屏。
- 缩放支持：80%–150%。
- 布局方式：弹性比例布局，不写死像素；缩放时优先保住核心数据。
- 风格：深色金融终端，沿用老版基调，紧凑高密度。

### 3.2 区域划分

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：DR007 · 资金情绪四值 · 松紧结论 · 账户/日期/通知          │
├──────────────┬──────────────────┬───────────────────────────┤
│ 左栏 · 任务   │ 中栏 · 投研/行情   │ 右栏 · 非银报价盘            │
│ （核心）      │ 入口（弹性缓冲）    │ （主战场，最宽）             │
│              │                  │                           │
│ 交易单台账    │ 单列入口列表       │ 逆回购报价（上）             │
│ （精简视图）  │ · 投研            │ 正回购报价（下）             │
│              │ · 基准价格         │ 上下同屏                    │
│ 待分配额度    │ · 走势统计         │                           │
├──────────────┴──────────────────┴───────────────────────────┤
│ 浮层：聊天弹窗（浮于上层）／全屏分配矩阵（覆盖三栏）             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 三栏基准比例与优先级

| 栏位 | 基准宽度 | 优先级 | 说明 |
|---|---|---|---|
| 左栏 · 任务 | ~22% | 高（硬骨头） | 核心，缩放时尽量不压缩 |
| 中栏 · 投研/行情 | ~28% | 低（弹性缓冲） | 空间紧张时优先收缩，直至收成窄边 |
| 右栏 · 报价盘 | ~50% | 高（硬骨头） | 主战场，优先保证宽度 |

## 5. 左栏 · 任务（核心）

左栏是"任务为核心"的直接体现，自上而下：栏头 → 交易单台账（主体）→ 待分配额度区。

### 5.1 栏头

- 标题"任务"。
- 右上角：**试算利率**（如 1.35%），可点击编辑。
- 联动：修改试算利率后，下方所有账户的保本金额、保本利率联动重算。

### 5.2 交易单台账（精简视图）

交易指令执行台账的精简形态，供高频时快速扫看进度与保本。完整字段在全屏视图展开（见第 8 章）。

#### 5.2.1 展示列

| 列 | 含义 | 展示要点 |
|---|---|---|
| 账户 | 机构-产品-托管行（如 泰康人寿-长寿分红2025-招行） | 最宽列 |
| 期限 | 指令期限 | — |
| 未出 | 尚未做掉的缺口金额 | 核心数，预警色 |
| 完成度 | 已出 / 指令 的百分比 | 带色块：100%/75% 绿、0% 灰 |
| 保本利率 | 账户保本利率 | 触及/超过当前可得报价时飘红预警 |

#### 5.2.2 行状态

| 状态 | 视觉表现 |
|---|---|
| 正常 | 常规显示 |
| 保本预警 | 左边框 + 保本率红字，最需关注 |
| 已完成（100%） | 整行淡化，降低存在感 |

#### 5.2.3 交互

- **手动排序**：支持账户拖拽排序，不做自动排序。
- **点击账户行**：右栏报价盘自动筛出能满足该账户的报价（利率 ≥ 保本、品种/质押/账户要求匹配），并高亮匹配项——把"目标"与"弹药"连起来。

#### 5.2.4 边界

- 账户较多（十余行）时台账区可纵向滚动。
- 缺口为 0 但仍在列表中的账户（已完成）保留显示但淡化，便于全天对账。

### 5.3 待分配额度区

位于台账下方。交易员在私聊谈成一笔后，该笔成交额度不会自动归属到具体账户，而是先形成"待分配额度"，由交易员决定拆分到哪些账户。

#### 5.3.1 触发与提醒机制（A 主 + B 辅）

| 方案 | 位置 | 作用 |
|---|---|---|
| A（主） | 左栏待分配区 | 成交后挂出常驻条目，绝不遗漏 |
| B（辅） | 聊天弹窗内 | 成交瞬间提供"立即分配"快捷入口，上下文连贯 |

> 不采用独立强制浮层（方案 C）：高频成交下频繁弹窗会打断其他操作。

#### 5.3.2 待分配条目字段

| 字段 | 示例 |
|---|---|
| 对手 | 某农商行 |
| 金额 | 5 亿 |
| 成交利率 | @1.42 |
| 时间 | 10:32 |
| 品种/方向 | 逆回购 |
| 操作 | "分配"按钮 |

区块头显示：`待分配额度 ×N` + 汇总金额角标。

#### 5.3.3 处理流程

1. 点击"分配"（或聊天弹窗内"立即分配"）→ 进入全屏分配矩阵；
2. 在矩阵中拆分到各账户（可先用 AI 自动分配填一版）；
3. **分配确认后才回写台账**（确认是回写的唯一触发点）；
4. 回写：相关账户已出↑、未出↓、完成度↑、保本重算；
5. 该待分配条目消失；区内无条目时整区隐藏，台账上移。

#### 5.3.4 规则

- 成交量不会超过总缺口（不出现超额场景）。
- 待分配是"临时状态"：视觉上突出但短暂，处理完即消失。

## 6. 中栏 · 投研 / 行情入口（弹性缓冲）

中栏是投研与行情参考的索引面板，定位为"做判断时随时瞟一眼、要深看时点开"。窄、轻、只给代表值，不抢主视线。

### 6.1 入口条形态

每条入口统一为：

```
[名称]  [副标题=里面是什么]            [代表值（带涨跌色）]  [放大图标]
```

点击任一条 → 弹出**中等浮框**展示完整内容（列表/图表/矩阵），浮框不遮挡右侧报价盘。

### 6.2 入口内容（分三组）

| 分组 | 入口项 | 代表值示例 | 放大后展示 |
|---|---|---|---|
| 投研 | 资金面情绪 | DR007 + 四值，结论"平衡" | 情绪明细、历史走势 |
| 投研 | AI 投研观点 | 方向 + 建议（"7D 上浮 2bp"） | 完整观点与依据 |
| 基准价格 | 今天大行价格 | 工建农中各期限，隔夜价+涨跌 | 四大行各期限完整表 |
| 基准价格 | 交易所回购 | GC001 1.37 -1.0 | GC/R 系列完整列表 |
| 基准价格 | XREPO | 质押式回购挂单代表值 | 完整挂单 |
| 基准价格 | NCD 同业存单 | 1Y 1.92 | 一级/二级，趋势图/表格 |
| 走势统计 | 加权价格走势 | 代表期限最新加权值+涨跌 | 多周期价格线 + 成交量 |
| 走势统计 | 匿名成交走势 | 日内加权均价 | 日内加权利率/成交量图 |
| 走势统计 | 机构分期限统计 | 矩阵入口 | 机构类型 × 期限 × 指标矩阵 |

> 分组用小标题分隔（投研 / 基准价格 / 走势统计），让长列表有层次。
> 代表值是中栏的灵魂：选每块最该一眼看到的数，使中栏不点开也有信息价值。

### 6.3 弹性收缩策略

优先级：**左栏任务 ≈ 右栏报价盘 > 中栏投研**。空间紧张时优先牺牲中栏。

| 阶段 | 触发 | 中栏表现 | 空间去向 |
|---|---|---|---|
| ① 宽松 | 100% 及以上 | 完整：名称+副标题+代表值 | 三栏正常 |
| ② 紧张 | 缩放偏大 | 变窄：省副标题，留名称+代表值 | 主要给报价盘 |
| ③ 极限 | 150% 等 | 收成窄边/图标条 | 报价盘主导 |

- 极限态：点窄边图标 → 临时滑出入口浮层，看完收回；功能不丢、常态不占空间。
- 全屏分配矩阵展开时，中栏折叠让位（见第 8 章）。

## 7. 右栏 · 非银报价盘（主战场）

右栏占最宽，承载后台实时解析出的对手报价流。继承老版核心报价区并强化。

### 7.1 结构（自上而下）

1. **栏头 + 层级切换**：标题"非银报价盘"，1 级 / 2 级切换。
2. **筛选条**：金额区间、利率区间（0~不限），正回购 / 逆回购方向。
3. **期限标签**：R001 / R007 / R014 / R021 / R028。
4. **报价列表（主体）**：上下同屏，逆回购在上、正回购在下。

### 7.2 列表的三层结构

| 层 | 内容 |
|---|---|
| 第一层（方向） | 逆回购、正回购，上下同屏不切换 |
| 第二层（分组） | 利率地方 / 存单商金 / 信用；每组带汇总金额 + 组内均价 |
| 第三层（报价行） | 单条解析出的报价（见下） |

### 7.3 报价行字段

| 字段 | 含义 | 展示 |
|---|---|---|
| 最优/次优 | AI 自动标注组内最优 | 绿/黄色块 |
| 机构 | 报价方 | 有空间优先展示 |
| 期限 | R001 等 | — |
| 金额 | 报价量（总量） | — |
| 利率 | 均价 | 最关键字段，加粗高亮 |
| 押券要求 | 利率/信用/地方债/国股存单 | **关键数据，单独成列** |
| 账户要求 | 自营/可专户/非专户/年金户 | **关键数据，单独成列** |
| 方向 | 正 / 逆 | — |

> 押券要求与账户要求是分配可行性的关键约束，单独成列常驻，不弱化、不藏 hover。
> 列较多（8 列），最窄缩放下可对押券/账户用简称，整体保持全展示。

### 7.4 交互

| 操作 | 动作 |
|---|---|
| 单击报价行 | 唤起聊天弹窗（快捷发送消息） |
| 双击报价行 | 直接发送，不经修正（无修正接口） |
| 实时刷新 | 后台持续解析，价格变动时该行闪烁 |
| 与左栏联动 | 点左栏缺口账户 → 报价盘高亮可满足该账户的报价 |

### 7.5 规则

- 报价为只读实时流：高频下报价不修正、也来不及修正，因此无确认/编辑环节。
- 三个分组（利率地方/存单商金/信用）在正、逆回购下各自都有。

## 8. 全屏分配矩阵（任务完整视图）

分配是"任务为核心"闭环中信息量最大、最具含金量的界面，同时是左栏台账的**完整视图**。

### 8.1 与左栏台账的关系

- 左栏台账 = 精简视图（仅 5 列）。
- 全屏矩阵 = 完整视图（指令表全字段 + 对手分配列）。
- "展开"与"分配"通向**同一张全屏矩阵**。

### 8.2 触发与布局变形

- 触发入口：左栏台账"展开"、待分配"分配"、聊天弹窗"立即分配"。
- 布局变形：进入时**中栏投研折叠让位**，矩阵全屏展开（覆盖三栏）；右上角"收起"返回常态三栏。

### 8.3 矩阵结构

```
            │ 阳光保险 │ 平安资管 │ 中泰证券 │ … (对手 20+) │
  ──────────┼─────────┼─────────┼─────────┼────────────┤
  总额  →   │  0.60   │  5.10   │  5.00   │     …      │  ← 顶部冻结
  差额  →   │  0.00   │  0.00   │  0.00   │     …      │  ← 顶部冻结
  ──────────┼─────────┼─────────┼─────────┼────────────┤
  长寿分红   │    ·    │  5.10   │  5.00   │     …      │
  智选分红   │  0.60   │    ·    │    ·    │     …      │
  团体保险   │    ·    │    ·    │    ·    │     …      │
   ↑左侧冻结 │         （格子=分配金额，可滚动）           │
```

| 维度 | 内容 |
|---|---|
| 纵向（行） | 账户/指令：指令号、账户、账户简称、期限、备注、指令金额、未出等完整字段 |
| 横向（列） | 对手/资金方（20+），每列为一笔成交进来的额度 |
| 格子 | 账户 × 对手 交叉，填该对手分配给该账户的金额 |
| 总额行 | 每个对手列的成交总量 |
| 差额行 | 对手额度分配后剩余（0 表示该对手已分完） |
| 备注 | 账户分配限制（如"不能留趴账""出早还""开CD只限公募/一级交易"） |

### 8.4 关键规格

- **格子手动敲数字**；AI"自动分配"可先填一版，再手动调整。
- **允许留差额**：不强制分完，未分配额度可留存，差额非 0 也能保存。
- **冻结窗格**：对手列 20+，左侧账户列冻结、顶部对手行（含总额/差额）冻结，中间格子区横向/纵向滚动（Excel 冻结窗格体验）。
- **双向校验**：纵向校验账户是否凑够未出，横向校验对手额度是否分完。
- **占位按钮**："新增需求""广播"在界面占位，功能本期暂不展开。
- **保存回写**：保存分配后回写左栏台账（已出/未出/完成度刷新、保本重算）。

### 8.5 AI 自动分配逻辑（概要）

> 详细算法另行评审，此处给出主干环节。

1. **接口校验（最硬约束）**：调后台校验账户准入白名单、剩余可投额度、账户要求与质押要求匹配。账户限制数据须经接口实时获取，不依赖前端静态数据。
2. **保本约束**：剔除保本利率高于成交利率的账户。
3. **优先级排序**：按既定优先级（如保本紧迫度、完成度、缺口规模）对候选账户排序。
4. **按序灌水**：从高优先账户起逐个填满，受账户剩余额度二次约束。
5. **生成方案 + 标注不可分原因**：被剔除账户标注原因（超额度/未准入/质押不符等），供交易员核对调整。

## 9. 聊天弹窗与报价自动解析

### 9.1 报价自动解析

- 交易员与对手仍按习惯在私聊中用自然语言沟通。
- AI 实时将口语消息解析为结构化报价（品种/期限/价/对手），自动填入右栏报价盘。
- 高频场景下报价不修正、来不及修正 → 报价盘为只读实时流。

### 9.2 聊天弹窗

| 区域 | 内容 |
|---|---|
| 形态 | 浮于上层，不占栏位，左栏任务与中栏投研始终可见 |
| 顶部 | AI 解析出的报价摘要（品种/期限/价/建议） |
| 中部 | 私聊消息流（左右气泡） |
| 底部 | 回复框 + 发送 |
| 成交后 | 弹窗内出现"立即分配"快捷入口，连接全屏分配矩阵 |

### 9.3 多会话（高频场景）

- 高频私聊存在多对手并行沟通。
- 弹窗形态与并发数量在交互细化阶段进一步确定（如单弹窗替换 / 有限多弹窗平铺）。

### 10.1 后端 / 接口依赖

## 11. 术语表

| 术语 | 含义 |
|---|---|
| 未出金额 | 账户指令金额中尚未成交做掉的部分（缺口） |
| 完成度 | 已出 / 指令 的百分比 |
| 保本利率 | 账户按试算利率测算出的、成交需达到的最低利率 |
| 试算利率 | 全局参数，用于测算各账户保本金额/保本利率 |
| 待分配额度 | 已成交但尚未归属到具体账户的额度 |
| 非银报价盘 | 后台解析出的非银对手报价的结构化列表 |
| 正/逆回购 | 资金融出（逆回购）/ 融入（正回购）方向 |
| 押券要求 | 报价对应的质押品类型（利率/信用/地方债/国股存单等） |
| 账户要求 | 报价对成交账户性质的要求（自营/可专户/年金户等） |
