## 01. 主工作台常态（1920 × 1080）

### 区域标注

| 编号 | 区域 | 说明 |
|---|---|---|
| 1 | 顶栏 | 全局导航、搜索、消息、通知与用户区 |

## 04. 右栏非银报价盘 / 聚合聊天面板

### 区域标注

| 编号 | 区域 | 说明 |
|---|---|---|
| 1 | 栏头与当前方向 | 非银报价盘标题、正回购 / 逆回购互斥切换、1级 / 2级切换 |
| 2 | 筛选与期限标签 | 发送机构搜索、期限标签、刷新、筛选；期限标签用于定位或过滤行情 |
| 3 | 上半区：行情报价 | 按“利率地方 / 存单商金 / 信用”分组，展示发送机构在各期限的报价 |
| 4 | 下半区：历史聊天对手 | 按未回复 / 已回复 / 全部切换，每个对手两行展示 |
| 5 | 行情与聊天联动 | 点击行情可定位相关聊天对手；点击聊天对手打开聊天弹窗 |
| 6 | 实时刷新 | 行情报价、聊天未读、最新回复实时更新并闪烁提示 |

### 上半区行情报价字段

| 字段 | 说明 |
|---|---|
| 状态 | 最优 / 次优 / 普通，用于交易员快速扫行情 |
| 发送机构 | 该行情的发送机构或报价来源 |
| R001 / R007 / R014 / R021 / R028 | 每个期限的报价，单元格格式建议为“利率 / 金额”，如 `1.42/5` 表示 1.42%、5 亿 |
| 限户要求 | 自营、可专户、年金户、非专户等 |
| 操作 | 明细、定位聊天、快捷发送等入口 |

> 注意：行情表内不展示“方向”字段。方向由栏头的 `[逆回购] [正回购]` 互斥切换控制。

### 下半区历史聊天对手字段

| 行次 | 展示内容 | 示例 |
|---|---|---|
| 第一行 | 期限 / 分组 / 限户要求 / 金额 / 利率 / 押券 | `R007｜利率地方｜可专户｜5.0亿｜@1.42｜利率债` |
| 第二行 | 用户名 / 机构 / 最新回复 / 时间 | `kai123｜某农商行｜最新回复：可以，5亿，1.42给你 10:53:27` |

### 交互规则

| 事件 | 行为 |
|---|---|
| 单击 `[逆回购] / [正回购]` | 互斥切换当前方向，刷新上方行情与下方历史聊天对手 |
| 单击期限标签 | 过滤或定位对应期限的行情与聊天记录 |
| 单击行情单元格 | 定位到关联历史聊天对手；如果只有一个关联会话，可直接打开聊天弹窗 |
| 单击“明细” | 展示该发送机构在当前方向下的完整报价明细 |
| 单击历史聊天对手 | 打开聊天弹窗，带入该对手、该行情上下文 |
| 切换“未回复 / 已回复 / 全部” | 过滤历史聊天对手列表 |
| 新行情到达 | 对应单元格闪烁，并按当前排序规则刷新位置 |

### 快捷分配展开逻辑

```text
右栏历史聊天对手 / 行情明细
   ↓ 打开聊天弹窗
聊天确认成交 done
   ↓ AI 识别成交或人工确认成交
弹窗下方展开“快捷分配”
   ↓
只列出当前成交可直接分配的账户
```

### 快捷分配字段

| 字段 | 说明 |
|---|---|
| 选择 | 是否参与本笔分配，默认勾选 AI 推荐账户 |
| 账户/产品 | 可分配账户或产品简称 |
| 期限 | 账户任务期限，需与当前成交兼容 |
| 未出 | 当前账户剩余缺口 |
| 保本 | 当前账户保本利率 |
| 可分上限 | 当前账户本笔可分配上限，通常受未出、准入额度、成交剩余共同约束 |
| 分配金额 | 可编辑输入框，仅允许数字与小数点 |

### 操作规则

| 事件 | 行为 |
|---|---|
| AI 识别成交 | 自动展开快捷分配面板，并填入推荐分配金额 |
| 单击“AI自动分配” | 根据保本、未出、限户要求、押券要求重新生成建议分配 |
| 单击“清空” | 清空当前分配金额，不影响成交确认 |
| 单击“保存分配” | 保存当前分配金额，回写左栏台账 |
| 单击“挂入待分配” | 当前成交未处理金额进入左栏待分配额度区 |
| 单击“转全屏矩阵” | 打开全屏分配矩阵，带入当前成交作为待分配对象 |
| 分配金额超出可分上限 | 输入框标红并阻止保存 |
| 保存后仍有剩余 | 已分配部分回写台账，剩余部分挂入待分配 |

### 展示规则

```text
只展示可分配账户。
不展示不可分配账户。
不展示不可分原因。
复杂校验、不可分原因、跨多笔成交的拆分调整，统一进入全屏分配矩阵处理。
```
