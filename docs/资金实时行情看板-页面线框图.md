```mermaid

  C --> E["MainQuoteBoard 中间非银报价"]
  C --> F["RightSidebar 右侧趋势分析"]

  D --> D1["今天大行价格"]
  D --> D2["XREPO"]
  D --> D3["交易所回购"]

```
