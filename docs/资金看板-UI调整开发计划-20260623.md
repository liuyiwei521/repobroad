## 1. 本文档怎么使用

这份文档不再按“原始提需求顺序”平铺，而是按实际开发视角拆成：

- `UI规范`：应该长什么样、怎么交互、文案叫什么。
- `当前状态`：代码里已经做到哪一步。
- `差距`：离目标还差什么。
- `开发动作`：下一步具体改哪些文件。
- `验收口径`：开发完成后怎么判断算通过。

状态口径统一为四类：

- `已完成`：代码已满足需求，只需回归核对。
- `部分完成`：已有基础能力，但与最终目标仍有明显差距。
- `待开发`：还没有进入正确形态。
- `待确认`：需求方向基本明确，但落地口径仍需统一。

## 2. 本轮 UI 规范总则

### 2.1 顶部信息条

- 情绪类 chip 统一使用 `文字 + 数字 + 时间 + 状态` 的单行结构。
- 状态色固定为：
  - `紧张 = 红`
  - `宽松 = 绿`
  - `一般 = 灰`
- 两个情绪入口的命名统一为：
  - `泰康资金情绪`
  - `国际资金情绪`
- 情绪 popover 统一承载维度解释，不再把维度信息塞进 chip 本体。

### 2.2 大图查看交互

- 资金看板内不再新增翻卡式交互。
- 需要展开分析时，统一走 `直接弹窗 / 大图 frame`。
- 多机构对比统一走多选，不再保留单选翻面状态。
- 预览态与正式态交互保持一致，不能出现“预览翻面、正式弹窗”两套行为。

### 2.3 中区报价与下半区

- 报价区的期限筛选保留，但展示层增加结构化分组。
- 下半区如果承载多个分析模块，应明确使用纯 tab，而不是隐藏块或嵌套子 tab。
- “资金缺口 / 在途指令”保留融合展示，不再拆回两个层级。

### 2.4 右侧图表区

- 右下区域优先承载“紧凑小图”，不再用大图表达。
- 机构热度走势统一展示三类维度：
  - `价`：折线
  - `笔数`：柱状
  - `量`：柱状或面积
- 右侧三段布局中，底部区域应小于上、中两块，避免喧宾夺主。

### 2.5 文案统一

- `XREPO` 历史范围命名以需求口径为准，统一使用 `当天`。
- 滚动广播、情绪 chip、弹窗表单里，涉及国际情绪的文案应统一，不再混用 `国际情绪指数`、`国际货币资金面情绪指数`、`国际资金情绪`。
