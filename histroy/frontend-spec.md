## 1. 产品概述

**资金实时行情看板** — 银行间货币市场实时行情工作台。全屏桌面盯盘工具，三栏布局聚合报价、行情和图表分析。

- 目标用户：银行间市场资金交易员、风控/研究部门
- 技术约束：Desktop only (1920×1080+), SPA, 内联 Mock 数据, 自定义 SVG
- 核心价值：三栏并行 — 参考（左）、操作（中）、分析（右）

## 3. 三栏内容详解

### 左栏

1. **大行价格**：4 家银行双边报价，支持手工编辑弹窗
2. **XREPO**：5 期限正逆回购利率，**点击行 → 右栏走势图切到对应品种**
3. **交易所回购**：核心/上交所/深交所 Tab 切换，**点击行 → 右栏走势图切到对应品种**
4. **NCD**：趋势图/表格 Tab 切换

### 中栏

1. **1级/2级切换**：摘要视图 vs 全量视图
2. **逆回购报价**：利率地方/存单商金/信用 3 组
3. **正回购报价**：同上 3 组
4. **点击报价行 → 切品种**：右栏走势图切到该行 tenor
5. **拖拽分隔条**：调整上下区比例，localStorage 持久化
6. **区头聚焦**：点击激活/取消

### 右栏

1. **分时图**：当前选中品种日内走势（默认 R001）+ 叠加品种
2. **收盘价走势**：当前选中品种 + 5日/1月/半年 + 叠加 + 对比品种 + 利差柱状图
3. **参考面板**：CFETS 日报 / 利差 / 资金结构

## 5. 品种联动

- **全局状态 `selectedProduct`**：初始 "R001"，App 顶层 useState。
- **三个入口**：XREPO 行点击、交易所行点击、中栏报价行点击 → 均设置 selectedProduct。
- **互斥高亮**：仅当前选中入口高亮（左栏蓝色竖线），中栏点击仅短暂反馈。
- **右栏响应**：分时图和收盘价走势主品种同步切换。叠加/对比下拉独立。
- **数据要求**：需为各品种（DR007/GC007/R007 等）补充分时和历史数据集。

## 9. 数据校验规则

共 28 条规则，详见 `data-inventory.md`。

### 报价明细 (1-11)
bidRate≤askRate, 金额≥0, 利率>0, 期限有效, 等级有效, 机构名非空, 类型在分组, 机构不重复, 质押品非空, 账户类型非空, 时间格式合法

### XREPO (12-15)
bidRate≤askRate, 金额≥0, 可点击量≥0, 期限有效

### 交易所回购 (16-18)
最新价>0, 涨跌bp≤500, 成交额≥0

### NCD (19-22)
bidRate≤askRate, 利率>0, 期限有效, 银行名非空

### CFETS (23-25)
buyRate≤sellRate, 金额≥0, 机构类型在 8 类中

### 图表数据 (26-28)
时间排序, 价格/成交量≥0, 数据点≥2

## 10. 窗口自适应与多选对比

### 窗口自适应

- 根容器 `h-screen w-screen overflow-hidden`
- 三栏 `grid-cols-[30fr_35fr_35fr]` fr 比例自动缩放
- 面板内 `overflow-y-auto` 独立滚动
- SVG `viewBox` + `preserveAspectRatio="none"` 响应式
- 推荐 1920×1080 全屏，最小 1440×900

### 多选品种对比

- **主品种**：由 selectedProduct 决定（默认 R001），左栏/中栏点击切换
- **叠加**：琥珀色虚线，分时图+历史图共享，选项 DR007/GC007/R007
- **对比**：紫色虚线，仅历史图，选项 DR001/DR007/GC007/R007
- **利差**：主品种 - 对比品种 (bp)，红色正值/青色负值柱状图
- **同时使用**：最多 3 条线 + 完整 tooltip
- 叠加和对比下拉独立于 selectedProduct，互不影响
