## 一、产品定位

全屏桌面盯盘工具，三栏布局聚合报价、行情明细和图表分析。银行间货币市场一站式看板。

```

                    利率地方
```

## 三、各区域使用说明

### 左栏 — 参考数据

- **大行价格**：4 家银行的双边报价。想修改数据？点击「手工输入」→ 编辑后保存。修改只在本次会话有效。点击「重置」恢复默认。
- **XREPO**：匿名询价平台行情。5 个期限的正逆回购利率。
  - **点击任意品种行**（如 R007）→ 该行高亮 → 右栏走势图切到该品种的日内分时和收盘价走势。
- **交易所回购**：上交所+深交所回购行情。「核心」视图合并两市场隔夜和 7 天；「上交所」「深交所」各自完整展示。
  - **点击任意品种行**（如 GC007）→ 该行高亮 → 右栏走势图同样切换。
- **NCD**：「趋势图」看利率曲线，「表格」看具体报价。

### 中栏 — 报价明细 ★ 核心

这是你盯盘的主要区域。

- **1级/2级切换**：点击顶部的「1级」「2级」按钮。1级只显示最优和次优报价（精简）；2级显示全部报价（详细）。
- **逆回购报价（上区）**：机构融入资金的价格。三个分组（利率地方/存单商金/信用），每组内含最优、次优等级徽章。
- **正回购报价（下区）**：机构融出资金的价格。同样三组。
- **点击报价行切品种**：点击任意报价行 → 该行短暂高亮 → 右栏走势图切到该行对应的品种（tenor）。比如点某家机构的 R014 报价 → 右栏切到 R014 分时图。
- **拖拽分隔条**：上下区之间的灰色横条可以上下拖动——扩大你当前关注的那一半。早上关注逆回购？把分隔条往下拖。下午关注正回购？往上拖。调整后会自动记住，下次打开保持。
- **点击区头聚焦**：点击「逆回购报价」标题→ 上区放大，下区缩小。再点恢复。

### 右栏 — 图表分析

- **分时图**：当前选中品种的日内走势（默认 R001）。左栏/中栏选中其他品种后自动切换。上面的下拉菜单可叠加 DR007/GC007/R007 对比线。
- **收盘价走势**：当前选中品种的日频走势。顶部 Tab 切换 5 日 / 1月 / 半年时间范围。
  - **叠加品种**：下拉可选择叠加 DR007/GC007/R007，图表上出现虚线对比折线。
  - **对比品种**（多选对比）：下拉选择对比品种（DR001/DR007/GC007/R007）。选择后：
    - 图表上出现紫色虚线的对比品种走势。
    - 图表下方自动展示**利差柱状图**，显示主品种与对比品种之间的 bp 差值。正值红色柱（主品种高于对比品种），负值青色柱（主品种低于对比品种）。
    - 鼠标悬停 tooltip 同步展示：主品种价格、叠加品种价格、对比品种价格、利差值、成交量。
- **底部面板**：三个 Tab。
  - CFETS 日报：净融出、DR007、非银占比、成交总额摘要。
  - 利差：两个产品之间的利差柱状图。左右下拉各选一个产品。
  - 资金结构：7 类机构的资金结构堆叠图。可切换 14天/1月/半年。

## 四、关键交互速查

| 操作 | 效果 |
|------|------|
| 左栏点 XREPO/交易所品种行 | 该行高亮，右栏走势图切到对应品种 |
| 中栏点报价行 | 右栏走势图切到该行 tenor 品种 |
| 中栏点「1级」/「2级」 | 上下两报价区同步切换摘要/全量 |
| 中栏拖拽分隔条 | 调整上下区比例，记住你的设置 |
| 中栏点击区头 | 激活该区（蓝色竖线），另一区缩小 |
| 左栏「手工输入」→ 保存 | 修改银行报价（本次会话有效） |
| 右栏叠加下拉 | 分时图+历史图叠加对比品种 |
| 右栏对比下拉 | 收盘价走势叠加对比品种 + 利差柱状图 |
| 右栏时间范围 Tab | 历史图切换 5日/1月/半年 |
| 右栏底部面板 Tab | 切换 CFETS/利差/资金结构 |
| 左栏交易所 Tab | 核心/上交所/深交所 切换 |
| 左栏 NCD Tab | 趋势图/表格 切换 |

## 五、窗口缩放行为

### 整体自适应

- 三栏随窗口宽度按 **30:35:35 固定比例**自动缩放，使用 CSS Grid `fr` 单位。
- TopBar 固定高度，三栏区域 `flex-1` 填充剩余空间。
- 页面根容器为 `h-screen w-screen overflow-hidden`，无外层滚动条。

### 栏内滚动

- 每栏内部面板 `overflow-hidden` / `overflow-y-auto`，当内容超出面板高度时出现独立滚动条。
- 滚动条样式：5px 宽度，深色轨道（#0c1524），蓝色滑块（#34527a）。

### SVG 图表自适应

- 分时图和收盘价走势图使用 `viewBox` + `preserveAspectRatio="none"`，随容器尺寸自动缩放。
- 图表 tooltip 使用 `useChartTooltip` hook，通过 `containerRef` 获取实时容器尺寸计算鼠标位置。
- 分时图 viewBox: `0 0 680 178`
- 收盘价走势图 viewBox: `0 0 720 186`

### 推荐分辨率

- **最佳体验**：1920 × 1080 或更高分辨率的全屏显示。
- 1280 × 720 以下可能出现内容挤压，部分面板文字溢出。

### 中栏分隔条持久化

- 拖拽调整的上下区比例写入 `localStorage.setItem('repo-split-ratio', ...)`。
- 窗口 resize 不会重置分隔条位置。
- 刷新页面后恢复上次保存的比例。

## 六、品种联动

**左栏/中栏的任何品种行都是右栏走势的入口。**

- 页面加载时默认选中 **R001**，左栏 XREPO R001 行蓝色高亮。
- 在 XREPO 点 **R007** → R001 高亮消失，R007 高亮 → 右栏分时图和收盘价走势切到 R007。
- 在交易所回购点 **GC007** → 右栏切到 GC007。
- 在中栏报价区点某条 R014 报价 → 右栏切到 R014。
- 三个入口互斥：最后一次点击决定右栏展示什么。
- 叠加和对比下拉保持独立，不受品种联动影响。

## 七、多选品种对比交互

收盘价走势图支持同时叠加 + 对比两个品种的完整交互流程：

### 叠加（overlayProduct）
- 位置：分时图面板 header 下拉菜单。
- 选项：不叠加 / DR007 / GC007 / R007。
- 效果：琥珀色虚线叠加在蓝色实线（R001 收盘价）上。
- 分时图和收盘价走势图共享同一个 `overlayProduct` 状态。

### 对比（compareProduct）
- 位置：收盘价走势面板 header 的「对比」下拉菜单。
- 选项：不对比 / DR001 / DR007 / GC007 / R007。
- 效果：
  1. 紫色虚线显示对比品种走势。
  2. 图表下方出现独立利差柱状图面板。
  3. 利差 = R001 收盘价 - 对比品种收盘价，单位 bp（×100）。
  4. tooltip 展示完整数据：主品种、叠加品种、对比品种、利差、成交量。

### 叠加 + 对比可同时使用
- 同时激活时，图表上最多出现 3 条线：
  - 蓝色实线（R001 主品种）
  - 琥珀色虚线（叠加品种）
  - 紫色虚线（对比品种）
- 图例在图表右上角，每种颜色一行。
- 鼠标悬停 tooltip 同步展示所有激活品种的数据点。

## 八、空数据与异常

当前版本为原型阶段：
- 所有数据为静态展示，不会出现「加载失败」。
- 筛选功能（期限/金额/利率）当前为占位展示，不可操作。
- 「发送」「下载」按钮当前无实际功能。

## 九、设计原则

1. **三栏并行**：参考 → 操作 → 分析，从左到右。
2. **1级/2级视图**：快速扫视用 1级，深度分析用 2级。
3. **本地状态优先**：编辑的个人报价保存在会话中。
4. **可拖拽分隔**：中栏是核心，允许自由调整空间分配。
5. **叠加+对比双维度**：叠加看同图趋势，对比看品种间利差，互补不冲突。
6. **品种联动**：左栏和中栏的所有品种行都是右栏走势图的入口，一次点击切品种。
