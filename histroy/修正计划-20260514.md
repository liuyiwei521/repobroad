# 资金行情看板修正计划

## 1. 文档目的

基于演示文稿《资金行情看板修改意见20260514》整理本次修正计划，输出为可执行的前端改造清单。当前页面仅使用模拟数据，暂不关注真实业务数据对接、后端接口或数据落库。本文档聚焦三类内容：

- 需要调整的页面结构、文案与交互
- 涉及的模拟数据口径、状态规则与下载展示能力
- 实施优先级、影响范围与验收标准

## 2. 修改意见汇总

### 2.1 顶部与中部报价区

1. 将全局“期限”选项从顶部工具栏移出，挪到“非银报价”区域内，仅在该区域使用。
2. 缩小左侧模块列宽，为中间“非银报价”区域释放更多横向空间。
3. 中部报价表最右侧新增“报价获取时间”列。
4. 若保留下载按钮，当前仅作为模拟数据导出能力设计，不展开历史数据方案。

### 2.2 左侧“大行价格”区域

1. “当日大行价格”数据说明需要补充，明确其来源为每天 10:00~11:00 大行在群或私聊中给出的固定价格。
2. 数据结构需要支持隔夜与 7 天两个期限。
3. 如某机构当天无 7 天报价，则该行自动折叠或不展示。
4. 需要支持大行名单配置，而不应写死固定机构集合。

### 2.3 右侧图表区

1. 将“当日分时”走势图改为“匿名成交走势图”。
2. 将“收盘价走势”改为“加权价格走势”。
3. 页面顺序调整为：上方展示“各品种每日加权价格走势图”，下方展示“匿名成交当日走势图”。
4. 匿名成交数据需单独补数，备注来源为“可找赵旭要数据”。

### 2.4 机构统计区

1. 底部统计区域仅保留“机构分期限统计”。
2. 该区域新增三类筛选项：
   - 数据分类：正回购利率 / 逆回购利率 / 正回购交易额 / 逆回购交易额 / 正回购余额 / 逆回购余额 / 正回购净额 / 逆回购净额
   - 机构类型：大型银行 / 中小型银行 / 证券公司 / 保险公司 / 基金公司及产品 / 货币市场基金 / 理财子 / 其他
   - 期限：R001 ~ R1Y，多选
3. 数据分类也可拆为两个筛选维度：
   - 方向：正回购 / 逆回购
   - 指标：加权利率 / 交易额 / 交易余额 / 交易净额

## 4. 修正方案

### 4.1 顶部与整体布局调整

#### 改动项

- 删除顶部工具栏中的全局“期限”筛选展示。
- 顶部“金额/利率”两个筛选项保留为静态展示，不参与实际筛选逻辑。
- 调整三栏宽度，建议由 `30:35:35` 改为 `24:41:35` 或 `25:40:35`，优先保证中间报价区可读性。

#### 影响

- `TopBar` 结构与样式需要同步调整。
- 主体 grid 列宽要联动修改，避免左栏内容溢出。

#### 验收

- 顶部不再出现全局期限筛选。
- 左栏压缩后不出现标题换行、表格截断、按钮重叠。
- 中间报价区横向空间明显增加，新增列后仍可完整展示。

### 4.2 左侧“大行价格”模块改造

#### 改动项

- 增加模块级数据说明，明确“当日大行价格”的采集时间与业务定义。
- 数据模型从“每家机构一条记录”升级为“每家机构按期限记录”，至少支持“隔夜”和“7天”。
- 当某机构缺少 7 天报价时，该期限完全隐藏，不展示空白占位行。
- 增加“大行名单配置”能力，机构列表从静态常量中抽离。
- 手工输入弹窗也要同步支持按期限录入。

#### 建议的数据结构

- 机构维度：`institution`
- 期限维度：`tenor`，至少包含 `ON`、`7D`
- 字段：`bankRate`、`nonBankRate`、`deltaBankBp`、`deltaNonBankBp`、`updatedAt`、`hasQuote`

#### 实施说明

- 若当前阶段仍使用前端静态数据，可先把数据常量改造成二维列表。
- “折叠”建议表现为：同一机构只有存在报价的期限才展示，不单独展示“被折叠”文案。
- “大行名单配置”本轮采用配置清单控制展示范围，页面仅展示配置清单内机构。

#### 验收

- 同一机构可展示隔夜与 7 天两类报价。
- 缺失 7 天报价时页面不出现脏数据或占位符。
- 手工输入后，列表与更新时间计算逻辑正常。

### 4.3 中部“非银报价”模块改造

#### 改动项

- 将“期限选择”迁移到该模块内部，作为模块级筛选。
- 报价表新增“报价获取时间”列。
- 下载按钮、报价失效时间和“已出完”识别本轮暂不处理，先保留现有入口或占位展示。
- 为报价增加“有效性”判断预留字段与状态展示能力，作为后续可扩展项，不要求本轮实现完整规则。

#### 建议实现顺序

1. 先补“时间列”和“模块内期限筛选”的展示能力。
2. 再补报价状态字段，例如：`active` / `filled` / `expired` / `replaced`。

#### 验收

- 期限选择仅出现在非银报价区域。
- 每条报价均可显示获取时间。
- 下载、失效时间和“已出完”相关能力在本轮不作为验收项。

### 4.4 右侧图表区改造

#### 改动项

- 将“当日分时”更名为“匿名成交走势图”。
- 将“收盘价走势”更名为“加权价格走势”。
- 调整上下布局顺序：上方放“各品种每日加权价格走势图”，下方放“匿名成交当日走势图”。
- 更新图表数据说明，避免继续使用“收盘价”口径。

#### 模拟数据要求

- 匿名成交图继续使用前端模拟数据即可。
- 加权价格图不能继续复用当前“收盘价”命名和说明，需先统一口径和文案。

#### 验收

- 页面文案不再出现“当日分时”“收盘价走势”。
- 图表上下顺序符合最新要求。
- 图例、tooltip、说明文案与“匿名成交”“加权价格”口径一致。

### 4.5 底部统计区收敛与筛选增强

#### 改动项

- 仅保留“机构分期限统计”，移除或隐藏其他底部 Tab。
- 新增三组筛选项：数据分类、机构类型、期限。
- 支持单选 + 多选的组合筛选。
- 图表与表格联动刷新，且筛选项对标题、tooltip、导出名称同步生效。

#### 建议的产品取舍

- 优先采用“两层筛选”方案，更清晰：
  - 方向：正回购 / 逆回购
  - 指标：加权利率 / 交易额 / 交易余额 / 交易净额
- 若时间紧，可先按 PPT 原文实现一个“数据分类”单选，再在后续版本拆分。

#### 数据映射建议

- 机构类型名称保持与页面筛选文案一致即可，避免页面内命名混乱。
- 期限枚举按本轮确认值扩展为 `R001`、`R007`、`R014`、`R021`、`R1M`、`R2M`、`R3M`、`R4M`、`R6M`、`R9M`、`R1Y`。

#### 验收

- 底部区域默认只呈现“机构分期限统计”。
- 三类筛选项均可操作，且结果联动正确。
- 机构分类命名与筛选命名一致，无重复类别或空结果异常。

## 5. 已确认规则

以下规则已确认，可直接作为模拟页面实现依据：

1. 顶部“金额/利率”筛选保留为静态展示。
2. “大行价格”名单范围按配置清单筛选。
3. “当日大行价格”缺失 7 天报价时完全隐藏。
4. “已出完”识别本轮暂不考虑。
5. 报价失效时间规则本轮暂不考虑。
6. 非银报价下载本轮暂不考虑。
7. 匿名成交走势图和加权价格走势图继续使用前端模拟数据。
8. 机构分期限统计期限固定为 `R001`、`R007`、`R014`、`R021`、`R1M`、`R2M`、`R3M`、`R4M`、`R6M`、`R9M`、`R1Y`。
