# 资金交易智能工作台 · 交互规格（前端）

> 纯交互行为清单。每个控件的 点击 / 双击 / hover / 键盘 / 状态 / 联动 行为。
> 不含产品背景，配合《产品详细描述》使用。

---

## 0. 全局约定

### 0.1 交互术语

| 术语 | 定义 |
|---|---|
| 单击 | 鼠标左键 click（mousedown + mouseup 同一目标） |
| 双击 | dblclick，间隔 < 300ms |
| hover | mouseenter 显示 / mouseleave 隐藏，hover 提示延迟 300ms 出现 |
| 选中 | 元素进入 selected 态，带高亮边框，唯一或多选见各控件 |
| 联动 | 操作 A 引发其他区域 B 的状态变化 |
| 闪烁 | 数据更新时背景色短暂高亮（≤600ms）后恢复，涨绿跌红 |

### 0.2 全局键盘

| 按键 | 行为 |
|---|---|
| `Esc` | 关闭最上层浮层（聊天弹窗 / 中等浮框等，按层级逐层关）；矩阵键盘关闭本期暂不验收 |
| `Tab` / `Shift+Tab` | 焦点在当前可交互区内前进/后退 |
| `Enter` | 触发当前焦点控件的主操作 |
| `Ctrl/Cmd + S` | 本期暂不定义矩阵快捷保存 |

### 0.3 焦点与层级

- 浮层打开时，焦点锁定在浮层内（focus trap），背景不可 Tab 到达。
- 同时只允许一个全屏矩阵；聊天弹窗可与全屏矩阵共存（矩阵在更上层）。矩阵是左侧任务面板的扩展形态，不是独立表格页面。
- 任意浮层打开时，底层三栏仍实时刷新数据（不冻结）。

### 0.4 数据刷新

- 右栏行情、历史聊天对手、台账数值、待分配、聊天、中栏摘要卡片为实时推送，更新时对应行/单元格/字段闪烁。
- 用户正在编辑的关键输入框原则上不被推送覆盖；本期暂不要求矩阵分配格子的实时推送冲突保护。

## 1. 顶栏

### 1.1 资金面基准（DR007 / 情绪四值 / 结论）

| 事件 | 行为 |
|---|---|
| hover | 显示 tooltip：四值口径说明与更新时间 |

### 1.3 通知铃铛

| 事件 | 行为 |
|---|---|

| 单击某条通知 | 跳转到对应位置（如左栏待决策项 / 对应聊天弹窗） |

## 2. 左栏 · 任务

### 2.1 栏头 — 试算利率

| 事件 | 行为 |
|---|---|
| 单击数值 | 转为可编辑输入框，全选当前值 |
| 输入 | 仅接受数字与小数点；非法输入边框变红、阻止失焦提交 |
| `Enter` / 失焦 | 提交新值 → 台账所有账户保本金额、保本利率重算并闪烁 |
| `Esc` | 取消编辑，恢复原值 |

### 2.2 交易单台账 — 表头

| 事件 | 行为 |
|---|---|
| hover 列头 | 显示该列完整名称 tooltip |
| 单击列头 | 无排序（排序由手动拖拽行实现，见 2.3）；列头不可点排序 |

### 2.3 交易单台账 — 账户行

| 事件 | 行为 |
|---|---|
| hover | 行底色加深；右侧出现轻量操作把手（拖拽手柄） |
| 单击 | 选中该行（唯一选中，高亮边框）→ **联动右栏行情与历史聊天对手**：筛出并高亮能满足该账户的行情（利率≥保本、品种/质押/账户要求匹配） |
| 再次单击已选中行 | 取消选中 → 右栏行情取消筛选高亮 |
| 双击 | 打开全屏分配矩阵，定位到该账户行 |
| 拖拽手柄 | 进入拖拽排序；拖动时其他行让位预览；松手提交新顺序（顺序本地持久化） |
| 键盘 `↑/↓` | 在台账行间移动选中（焦点在台账时） |
| 键盘 | 本期不要求通过键盘打开矩阵 |

### 2.4 交易单台账 — 行状态（视觉，非交互）

| 状态 | 表现 | 可交互性 |
|---|---|---|
| 正常 | 常规显示 | 可选中/拖拽/双击 |
| 保本预警 | 左边框 + 保本率红字 | 同正常 |
| 已完成 100% | 整行淡化 | 仍可选中/双击查看，拖拽允许 |
| 数据更新 | 未出/完成度/保本率闪烁 | — |

### 2.5 待分配额度区

#### 2.5.1 区块头

| 事件 | 行为 |
|---|---|
| 显示条件 | 有待分配条目时显示；无则整区隐藏，台账上移 |
| hover 角标 | tooltip：待分配总金额与笔数 |

#### 2.5.2 待分配条目

| 事件 | 行为 |
|---|---|
| hover | 行底色加深 |
| 单击条目主体 | 唤起该对手的聊天弹窗（含成交上下文） |
| 单击"分配"按钮 | 打开全屏分配矩阵，预置该笔待分配额度为当前操作对象（对应对手列高亮） |
| 新条目到达 | 从顶部插入并短暂高亮，伴随角标数 +1 |
| 条目被分配完成 | 淡出移除 |

## 3. 中栏 · 投研 / 行情数据摘要区

### 3.1 摘要卡片（通用）

| 事件 | 行为 |
|---|---|
| hover 卡片 | 卡片底色加深，打开图标变为高亮态；若有更新时间 / 口径标记，显示 tooltip |
| 单击卡片主体 | 打开对应**中等浮框**（不遮挡右栏行情/聊天面板） |
| 单击打开图标 | 同上（图标只是显式入口） |
| 单击卡内小控件（如期限、一级/二级、周期切换） | 仅触发该控件自身行为，不冒泡打开浮框 |
| 摘要字段数据更新 | 仅变化字段闪烁，涨绿跌红；卡片高度和位置不变化 |
| 数据暂缺 / 延迟 / 取数失败 | 卡片保留原位，显示状态文案；单击仍可打开浮框查看状态说明 |
| 键盘 `Enter` / `Space` | 焦点在卡片主体时打开浮框 |
| 键盘 `Tab` | 先进入卡片主体，再进入卡内可聚焦小控件 |

### 3.2 中等浮框（投研/行情详情）

| 事件 | 行为 |
|---|---|
| 打开 | 浮于中栏区域上层，定位不覆盖右栏；标题区展示模块名、当前上下文、更新时间 / 数据状态；focus trap 生效 |
| 内部 tab/周期切换（如近5日/1M/半年） | 切换图表数据，仅刷新框内 |
| 单击框外遮罩 | 关闭浮框 |
| 关闭按钮 / `Esc` | 关闭浮框 |
| 多次打开不同摘要卡片 | 替换当前浮框内容（同时只存在一个中等浮框） |
| 浮框打开期间摘要数据更新 | 同步刷新浮框内对应数据；当前正在操作的 tab / 周期不被重置 |

### 3.3 弹性收缩（响应缩放，非用户直接控件）

| 阶段 | 触发 | 中栏行为 | 摘要卡片交互变化 |
|---|---|---|---|
| 宽松 | ≥100% 宽度充裕 | 完整卡片：标题 + 主指标 + 支撑字段/小表/迷你趋势 | 正常 |
| 紧张 | 空间变少 | 压缩卡片：标题 + 主指标 + 1-2 个关键字段 | 单击仍打开浮框；卡内小控件可减少但主指标保留 |
| 极限 | 空间极少 | 收成窄边/图标条，仅保留主题图标和异常/更新提示 | 单击窄边图标 → 临时滑出摘要浮层；滑出层内仍展示关键数据；单击某卡 → 打开中等浮框；点窄边外 / `Esc` 收回滑出层 |
| 矩阵打开 | 进入左侧任务面板扩展矩阵 | 中栏可折叠让位 | — |

> 收缩为自动响应布局宽度，无需用户手动切换。

## 4. 右栏 · 非银行情与历史聊天对手

### 4.1 层级切换（1级 / 2级）

| 事件 | 行为 |
|---|---|
| 单击 | 切换行情层级，上半区行情整体刷新；当前态高亮 |
| 键盘 | 焦点在切换器时 `←/→` 切换 |

### 4.2 筛选条（期限 / 发送机构 / 金额 / 利率 / 方向上下文）

| 控件 | 事件 | 行为 |
|---|---|---|
| 发送机构搜索 | 输入 | 过滤上半区行情发送机构；下半区历史聊天对手同步过滤机构/用户名 |
| 金额区间输入 | 输入 | 仅数字；下限>上限时标红阻止 |
| 利率区间输入 | 输入 | 同上 |
| 区间提交 | `Enter`/失焦 | 按区间过滤上半区行情，并同步过滤下半区相关聊天对手 |
| 正/逆回购方向 | 单击 | 作为右栏当前上下文切换；上半区行情与下半区历史聊天对手按该方向刷新；行情表内部不展示方向字段 |
| 仅看相同交易对手 | 单击 | 只保留与当前账户或当前聊天相关的发送机构 / 对手 |

### 4.3 期限标签（R001…R028）

| 事件 | 行为 |
|---|---|
| 单击 | 选中该期限，上半区仅突出/过滤对应期限列；下半区过滤相关聊天对手；当前态高亮（单选） |
| 再次单击已选 | 取消该期限过滤（恢复全部） |
| 键盘 | 焦点在标签组时 `←/→` 移动并即时过滤 |

### 4.4 上半区行情分组头（利率地方 / 存单商金 / 信用）

| 事件 | 行为 |
|---|---|
| hover | tooltip：分组口径、金额总量、利率均价更新时间 |
| 单击 | 折叠/展开该分组；分组标题、金额总量、利率均价始终可见 |

### 4.5 上半区行情行 / 期限单元格

| 事件 | 行为 |
|---|---|
| hover 行 | 行底色加深；显示发送机构全称 |
| hover 期限单元格 | 显示该报价的限户要求、押券要求、原始消息摘要 |
| 单击期限单元格 | 选中该报价，打开/定位聊天弹窗；弹窗顶部带本条报价摘要 |
| 单击“明细” | 展开该行明细，展示各期限完整金额、利率、限户、押券、更新时间 |
| 双击期限单元格 | 直接发送快捷询价/回复；发送后单元格出现“已发送”瞬时状态标记 |
| 价格更新 | 对应期限单元格闪烁，涨绿跌红 |
| 被左栏账户筛选命中 | 行或单元格高亮为“匹配”态；未命中行可置灰 |
| 键盘 `↑/↓` | 在发送机构行间移动焦点 |
| 键盘 `←/→` | 在期限单元格间移动焦点 |
| 键盘 `Enter` | = 单击当前期限单元格 |
| 键盘 `Shift+Enter` | = 双击当前期限单元格 |

### 4.6 下半区历史聊天对手 Tab（未回复 / 已回复 / 全部）

| 事件 | 行为 |
|---|---|
| 单击 Tab | 切换历史聊天对手列表；不影响上半区行情 |
| 未回复角标 | 显示需要我方响应的会话数 |
| 已回复角标 | 显示最后一条由我方发送、当前无需立即处理的会话数 |
| 全部角标 | 显示当前筛选上下文下的全部会话数 |

### 4.7 下半区历史聊天对手条目（两行展示）

| 事件 | 行为 |
|---|---|
| 展示第一行 | 期限 / 分组 / 限户要求 / 金额 / 利率 / 押券，例如 `R007｜利率地方｜可专户｜5.0亿｜@1.42｜利率债` |
| 展示第二行 | 用户名 / 机构 / 最新回复 / 时间，例如 `kai123｜某农商行｜最新回复：可以，5亿给你｜10:53:27` |
| hover | 行底色加深；显示最新回复全文 tooltip |
| 单击 | 打开聊天弹窗并定位到该会话最新消息 |
| 双击 | 打开聊天弹窗并聚焦输入框 |
| 新消息到达 | 条目移动到“未回复”，未读角标 +1，条目短暂高亮 |
| 我方发送成功 | 条目移动到“已回复”，更新时间刷新 |
| 键盘 `↑/↓` | 在会话条目间移动焦点 |
| 键盘 `Enter` | 打开聊天弹窗 |

### 4.8 最优/次优标签（视觉，非交互）

- 由 AI 自动标注，随数据刷新更新；不可点击。

## 5. 聊天弹窗

### 5.1 弹窗容器

| 事件 | 行为 |
|---|---|
| 打开来源 | 上半区行情单元格单击 / 下半区历史聊天对手单击 / 待分配条目单击 / 通知跳转 |
| 形态 | 浮于上层，不遮挡左栏与中栏关键区 |
| 拖拽标题栏 | 移动弹窗位置（限制在视口内） |
| 关闭按钮 / `Esc` | 关闭弹窗（不影响后台会话与解析） |
| 多次从不同对手打开 | 见 5.6 多会话策略 |

### 5.2 报价摘要条（弹窗顶部）

| 事件 | 行为 |
|---|---|
| 展示 | AI 解析出的品种/期限/价/限户要求/押券要求/建议 |
| 单击 | 定位到右栏上半区对应行情单元格（高亮）；非必须 |

### 5.3 消息流与输入

| 控件 | 事件 | 行为 |
|---|---|---|
| 消息流 | 新消息到达 | 自动滚到底；若用户上滑查看历史则不强制滚动，显示“新消息”提示按钮 |
| 输入框 | 输入 | 普通文本输入；编辑期间不被推送覆盖 |
| 输入框 | `Enter` | 发送消息 |
| 输入框 | `Shift+Enter` | 换行 |
| 发送按钮 | 单击 | 发送消息 |

### 5.4 成交后 — 快捷分配面板

| 事件 | 行为 |
|---|---|
| 出现条件 | 该会话产生成交（AI 解析判定）或交易员手动确认 done 后，在弹窗下半部展开 |
| 展示范围 | 只展示当前成交可分配账户；不展示不可分配账户 |
| 汇总信息 | 展示已成交金额、已分配金额、待分配金额 |
| AI 自动分配 | 根据可分账户、保本、未出、限户/押券约束填入建议分配金额 |
| 手动编辑 | 分配金额可编辑；仅接受数字与小数点 |
| 清空 | 清除当前快捷分配输入，不影响成交记录 |
| 保存分配 | 校验通过后保存，回写左栏台账；若仍有余额，可继续挂入待分配 |
| 挂入待分配 | 将本笔未分余额挂入左栏待分配额度区 |
| 转全屏矩阵 | 打开全屏分配矩阵，预置该笔成交额度与已填分配草案 |

### 5.5 快捷分配表格行

| 事件 | 行为 |
|---|---|
| hover | 行底色加深；tooltip 展示账户/产品全称与可分上限口径 |
| 勾选账户 | 参与本笔分配；取消勾选时清空该行分配金额 |
| 编辑分配金额 | 实时更新已分配金额、待分配金额、该账户分配后未出 |
| 输入超出可分上限 | 输入框标红，阻止保存 |
| 输入导致本笔超分 | 输入框标红，阻止保存 |
| `Enter` | 提交当前输入并移动到下一行分配金额 |
| `Tab` | 提交当前输入并移动到下一可编辑控件 |
| `Esc` | 取消当前格编辑；再次 `Esc` 关闭弹窗 |

### 5.6 多会话策略（待最终确认，前端预留）

| 选项 | 行为 |
|---|---|
| A 单弹窗替换 | 打开新对手 → 替换当前弹窗内容 |
| B 有限多弹窗 | 允许 N 个弹窗平铺/堆叠（N 上限由配置决定），各自独立 |

## 6. 全屏分配矩阵

### 6.1 容器与开关

| 事件 | 行为 |
|---|---|
| 打开来源 | 左栏台账行双击 / 待分配“分配” / 聊天快捷分配“转全屏矩阵” / 台账“展开” |
| 打开效果 | 作为左侧任务面板的扩展形态展开，可扩展到工作区宽度；中栏可折叠让位；矩阵层级高于聊天弹窗 |
| 收起按钮 | 自动保存当前矩阵草案并收起，恢复常态三栏 |

### 6.2 冻结窗格滚动

| 区域 | 行为 |
|---|---|
| 左侧冻结列 | 选择、账户ID、账户简称、期限、指令、金额分组（总额/差额/完成度/待分）横向滚动时**固定**不动 |
| 顶部对手行 | 机构一级表头、成交批次二级表头、总额行、差额行纵向滚动时**固定**不动 |
| 中间格子区 | 横向（看 20+ 对手）+ 纵向（看全部账户）滚动 |
| 滚轮 / 触控板 | 在格子区滚动；Shift+滚轮 = 横向滚动 |

左侧冻结列分为两组：

| 分组 | 字段 | 交互 |
|---|---|---|
| 账户信息 | 选择、账户ID、账户简称、期限、指令 | 选择用于批量分配 / 自动分配候选；账户简称过长时省略并 hover 显示全文 |
| 金额 | 总额、差额、完成度、待分 | 随格子编辑实时刷新；完成度用百分比展示，待分为正差额的业务提示 |

#### 6.2.1 表头和汇总行层级

| 层级 | 内容 | 行为 |
|---|---|---|
| 第一层表头 | 左侧账户字段、金额分组、机构 / 对手方一级表头 | 横向滚动时左侧冻结区固定，右侧机构区随矩阵滚动 |
| 第二层表头 | 金额分组下的总额 / 差额 / 完成度 / 待分；机构下的成交批次列 | 只读表头；期限是成交批次列的属性，同一机构同一期限再次成交也新增列，不合并 |
| 顶部总额行 | 每个机构成交批次列的成交总额 | 只读；随顶部冻结 |
| 顶部差额行 | 每个机构成交批次列的未分差额 | 只读；0、>0、<0 使用不同状态样式 |
| 明细行 | 账户行与机构成交批次列交叉格 | 可选中、可编辑 |
| 底部总计行 | 汇总指令、总额、差额、完成度、待分和各机构成交批次列已分金额 | 只读；纵向滚动到底部可见，条件允许时吸附在表格底部 |

### 6.3 分配格子（单元格）

| 事件 | 行为 |
|---|---|
| 单击 | 选中单元格（高亮），进入可编辑 |
| 双击 / 直接键入 | 进入编辑并替换内容 |
| 输入 | 仅数字与小数点；非法输入标红 |
| 提交后联动 | 该对手列总额/差额实时重算；该账户行总额、差额、完成度、待分实时更新 |
| 键盘规则 | 本期暂不要求方向键、Enter、Tab、Esc 等矩阵键盘操作 |
| 推送冲突 | 本期暂不要求矩阵编辑态实时推送冲突保护 |

### 6.4 校验显示（实时，非交互）

| 元素 | 行为 |
|---|---|
| 顶部差额行 | 0 = 正常色；>0（未分完）= 提示色且允许保存；<0 = 超分配高亮提示，不阻断自动保存 |
| 账户金额分组 | 总额 = 行内所有分配格之和；差额 = 指令 - 总额；完成度 = 总额 / 指令；待分 = max(差额, 0) |
| 底部总计行 | 指令、总额、差额、待分为账户行纵向汇总；机构成交批次列为该列已分金额汇总；所有字段只读 |
| 账户信息列 | 账户简称 hover 显示完整名称；账户ID作为定位和回写主键 |

### 6.5 工具栏按钮

| 按钮 | 单击行为 |
|---|---|
| 当前成交摘要 | 展示从待分配或聊天带入的对手、期限、成交总额、成交利率、方向、已填金额、待分余额和 AI 草案状态 |
| 自动分配 | 调 AI 生成草案，填充各格子；本期不展示不可分账户及原因 |
| 清空 | 清空当前矩阵草案输入，保留成交列与账户行结构 |
| 保存分配 | 手动保存当前草案 → 回写左栏台账与矩阵金额分组（总额/差额/完成度/待分刷新、保本重算）；**允许差额非 0 保存** |
| 新增需求 | 占位，单击暂无功能逻辑（保留按钮，置 disabled 或 toast"暂未开放"） |
| 广播 | 占位，同上 |
| 收起 | 自动保存当前草案并收起 |

### 6.6 矩阵键盘汇总

本期暂不要求矩阵键盘快捷操作。后续若进入增强阶段，再补充方向键移动、Enter / Tab 提交、Esc 取消、Ctrl/Cmd+S 保存等规则。

### 6.7 本次矩阵口径影响范围

| 范围 | 影响 |
|---|---|
| 焦点模型 | 表头、顶部总额行、顶部差额行、底部总计行均不可进入编辑焦点；本期不定义矩阵键盘移动规则 |
| 滚动模型 | 左侧冻结列固定；顶部表头与总额 / 差额行固定；右侧机构成交批次列横向滚动；账户明细纵向滚动 |
| 计算模型 | 编辑任一格后同时刷新账户金额分组、对应机构成交批次列差额、底部总计行 |
| 保存模型 | 允许顶部差额行 > 0 保存；顶部差额行 < 0 高亮提示；收起矩阵自动保存当前草案 |

## 8. 状态与边界清单

| 场景 | 期望行为 |
