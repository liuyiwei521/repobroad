## 0. 文档说明

本文档在评审版方案的基础上，进一步细化到字段、状态、交互、联动与边界情况的颗粒度，用于指导界面设计与前后端开发。文中数值（利率、金额、机构名）均为示意，不代表真实业务数据。

## 1. 产品概述

### 1.1 一句话定位

面向资金交易员的单屏一体化智能工作台，以**任务为核心**，将任务、投研、行情、交易四个支柱整合到同一屏幕，由 AI 贯穿全流程（实时解析报价、辅助分配、提示决策、跟踪进度），形成"判断方向 → 抓住机会 → 完成成交 → 回写任务进度"的完整闭环。

### 1.2 目标用户

资金交易台的交易员。其典型工作节奏为高频、快节奏，每天面对大量来自不同对手的私聊询价与报价，核心 KPI 是：在满足保本与合规约束的前提下，把各账户的指令缺口（未出金额）做到 0。

### 1.3 解决的核心问题

| 割裂 | 老版现状 | 新版方案 |
|---|---|---|
| 目标与机会 | 指令台账在 Excel，报价在看板，需反复对照 | 台账缺口与右栏行情联动，点账户即筛匹配行情 |
| 沟通与系统 | 私聊在外部工具，谈成后手工录入 | AI 实时解析私聊，自动结构化为行情与聊天摘要数据 |
| 判断与动作 | 投研判断停留在"看一眼" | 投研底价/观点直接作用于报价与分配决策 |

### 1.4 设计原则

- **任务为核心**：左栏任务与右栏行情/聊天面板是不可压缩的"硬骨头"，中栏投研/行情摘要区为弹性缓冲。
- **一屏完成**：常规交易动作（看判断、抓机会、谈成交、盯进度）不需要切换页面。
- **AI 包揽重复劳动**：解析、匹配、分配草案、进度跟踪由 AI 完成，人只做决策。
- **高频友好**：信息密度高、关键数突出、操作链路短，不依赖 hover 才出现关键信息。
- **默认态有数据价值**：中栏每个子内容默认展示可扫读的关键数据，不把信息价值藏到点击之后。

## 2. 总体架构

### 2.1 四个支柱

| 支柱 | 回答的问题 | 承载内容 | 界面落位 |
|---|---|---|---|
| 投研 | 今天往哪个方向、底价多少？ | 资金面松紧、走势预测、AI 观点 | 中栏数据摘要区 + 顶栏 |
| 行情 | 市场上有什么机会、谁在报？ | 基准价、非银行情、走势统计 | 中栏数据摘要区（基准/走势）+ 右栏上半区（行情） |
| 任务 | 我今天必须完成什么？ | 交易单台账、待分配额度 | 左栏 + 左侧扩展分配矩阵 |
| 交易 | 怎么把机会变成成交？ | 私聊、解析、报价、成交、快捷分配 | 右栏历史聊天对手 + 聊天弹窗 |

### 2.2 核心数据流与闭环

```
私聊（高频口语）
   │  AI 解析（品种/期限/价/对手）
   ▼
右栏上半区行情（结构化、可比、按发送机构与期限展示） ← 投研提供判断依据
   │  点击行情 / 点击历史聊天对手
   ▼
聊天弹窗（完成询价、回复、done）
   │  AI 识别成交
   ▼
弹窗内快捷分配（只展示可分配账户，支持 AI 预填与手工修改）
   │
   ├─ 保存分配 → 回写台账（已出↑、未出↓、完成度↑、保本重算）
   ├─ 未分余额 → 进入左栏待分配额度
   └─ 复杂场景 → 转左侧扩展分配矩阵
```

**闭环要义**：成交不是终点，回写任务才是闭环真正合上的地方；轻量成交优先在聊天弹窗内完成快捷分配，复杂拆分再进入左侧扩展分配矩阵。

### 2.3 AI 助手的角色

贯穿四环，承担：

- 解析私聊消息为结构化行情，实时推送到右栏上半区
- 在行情分组内自动标注最优/次优价
- 为缺口账户匹配可成交行情（结合保本、品种、质押、账户要求）
- 在聊天成交后生成快捷分配草案，只展示可分配账户
- 为左侧扩展分配矩阵生成完整分配草案（接口校验 + 保本约束 + 优先级排序）
- 跟踪指令进度，在需要人决策的节点发出提示

## 3. 整体布局

### 3.1 屏幕与适配

- 目标屏幕：1K（1920×1080）单屏。
- 缩放支持：80%–150%。
- 布局方式：弹性比例布局，不写死像素；缩放时优先保住核心数据。
- 风格：深色金融终端，沿用老版基调，紧凑高密度。

### 3.2 区域划分

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：DR007 · 资金情绪四值 · 松紧结论 · 账户/日期/通知          │
├──────────────┬──────────────────┬───────────────────────────┤
│ 左栏 · 任务   │ 中栏 · 投研/行情   │ 右栏 · 非银行情与聊天         │
│ （核心）      │ 摘要区（弹性缓冲）  │ （主战场，最宽）             │
│              │                  │                           │
│ 交易单台账    │ 数据摘要卡片       │ 上：行情报价                │
│ （精简视图）  │ · 投研摘要         │ · 利率地方 / 存单商金 / 信用 │
│              │ · 基准价格摘要     │ · 发送机构 × 各期限          │
│ 待分配额度    │ · 走势统计摘要     │ 下：历史聊天对手             │
│              │                  │ · 未回复 / 已回复 / 全部     │
├──────────────┴──────────────────┴───────────────────────────┤
│ 浮层：聊天弹窗（含快捷分配）／左侧扩展分配矩阵                  │
└─────────────────────────────────────────────────────────────┘
```

右栏不再采用“逆回购上、正回购下”的上下同屏结构。方向作为行情上下文或顶部筛选条件存在，行情表内部不展示方向字段。

### 3.3 三栏基准比例与优先级

| 栏位 | 基准宽度 | 优先级 | 说明 |
|---|---|---|---|
| 左栏 · 任务 | ~22% | 高（硬骨头） | 核心，缩放时尽量不压缩 |
| 中栏 · 投研/行情摘要 | ~28% | 低（弹性缓冲） | 默认态提供关键数据摘要；空间紧张时优先收缩，直至收成窄边 |
| 右栏 · 行情与聊天 | ~50% | 高（硬骨头） | 主战场，优先保证行情与历史聊天处理宽度 |

### 4.1 内容

| 区域 | 内容 | 说明 |
|---|---|---|
| 左 | 标题 | 工作台名称 / 布局入口 |

## 5. 左栏 · 任务（核心）

左栏是"任务为核心"的直接体现，自上而下：栏头 → 交易单台账（主体）→ 待分配额度区。

### 5.1 栏头

- 标题"任务"。
- 右上角：**试算利率**（如 1.35%），可点击编辑。
- 联动：修改试算利率后，下方所有账户的保本金额、保本利率联动重算。

### 5.2 交易单台账（精简视图）

交易指令执行台账的精简形态，供高频时快速扫看进度与保本。完整字段在全屏视图展开（见第 8 章）。

#### 5.2.1 展示列

| 列 | 含义 | 展示要点 |
|---|---|---|
| 账户 | 机构-产品-托管行（如 泰康人寿-长寿分红2025-招行） | 最宽列 |
| 期限 | 指令期限 | — |
| 未出 | 尚未做掉的缺口金额 | 核心数，预警色 |
| 完成度 | 已出 / 指令 的百分比 | 带色块：100%/75% 绿、0% 灰 |
| 保本利率 | 账户保本利率 | 触及/超过当前可得报价时飘红预警 |

#### 5.2.2 行状态

| 状态 | 视觉表现 |
|---|---|
| 正常 | 常规显示 |
| 保本预警 | 左边框 + 保本率红字，最需关注 |
| 已完成（100%） | 整行淡化，降低存在感 |

#### 5.2.3 交互

- **手动排序**：支持账户拖拽排序，不做自动排序。
- **点击账户行**：右栏行情自动筛出能满足该账户的行情（利率 ≥ 保本、品种/质押/账户要求匹配），并高亮匹配项——把"目标"与"弹药"连起来。

#### 5.2.4 边界

- 账户较多（十余行）时台账区可纵向滚动。
- 缺口为 0 但仍在列表中的账户（已完成）保留显示但淡化，便于全天对账。

### 5.3 待分配额度区

位于台账下方。交易员在私聊谈成一笔后，优先在聊天弹窗内使用“快捷分配”处理；未能在弹窗内分完的余额，或交易员选择暂不处理的成交，进入左栏“待分配额度”作为防遗漏池。

#### 5.3.1 触发与提醒机制（A 主 + B 辅）

| 方案 | 位置 | 作用 |
|---|---|---|
| A（主） | 聊天弹窗快捷分配 | 成交后立即在上下文内处理本笔分配 |
| B（辅） | 左栏待分配区 | 挂出未分余额 / 暂挂成交，防止遗漏 |

> 不采用独立强制浮层（方案 C）：高频成交下频繁弹窗会打断其他操作。

#### 5.3.2 待分配条目字段

| 字段 | 示例 |
|---|---|
| 对手 | 某农商行 |
| 金额 | 0.8 亿 |
| 成交利率 | @1.42 |
| 时间 | 10:32 |
| 品种/方向 | 逆回购 |
| 来源 | 快捷分配剩余 / 手动挂起 |
| 操作 | “分配”按钮 |

区块头显示：`待分配额度 ×N` + 汇总金额角标。

#### 5.3.3 处理流程

1. 成交后，聊天弹窗下半部展开“快捷分配”；
2. 快捷分配只展示当前成交可直接分配的账户；
3. 交易员可使用 AI 自动分配，也可手动修改分配金额；
4. 点击“保存分配”后回写台账；
5. 若本笔成交仍有余额，可点击“挂入待分配”，余额进入左栏待分配区；
6. 若需要跨多笔成交、查看完整字段或处理复杂拆分，点击“转全屏矩阵”。

#### 5.3.4 规则

- 成交量不会超过总缺口（不出现超额场景）。
- 快捷分配是“即时处理”；左栏待分配是“防遗漏池”。
- 快捷分配面板不展示不可分配账户；本期全屏矩阵也不展开不可分原因。

## 6. 中栏 · 投研 / 行情数据摘要区（弹性缓冲）

中栏不再只是投研与行情主题的入口列表，而是交易员做判断时的**数据摘要区**。它的默认态就要有可读数据价值：一眼能看到资金松紧、AI 方向、大行基准、回购/NCD 代表价和关键走势；需要深看时，再点击卡片打开中等浮框。

中栏仍然不承担右栏主行情盘的职责。右栏负责“谁在报、能不能聊、能不能成交”；中栏负责“当前市场基调是什么、基准价格在哪里、走势有没有变化”。它是判断辅助，不是第二张大行情表。

### 6.1 摘要卡片形态

每个子内容统一升级为摘要卡片：

```
[卡片标题]                         [更新时间 / 打开图标]
[主指标或结论]
[2-4 个支撑字段 / 核心期限小表 / 迷你趋势]
```

默认态要求：

- 每张卡必须展示至少 1 个主结论或主数值，不能只显示名称。
- 每张卡至少带 2 组支撑数据，例如涨跌、成交量、置信度、更新时间、代表期限。
- 只放影响判断的关键数据；完整列表、图表、矩阵和口径说明进入中等浮框。
- 数据更新时卡片内变化字段闪烁，并用涨跌色提示方向。
- 数据暂缺时保留卡片位置，展示“暂无 / 延迟 / 取数失败”等状态，避免布局跳动。

点击卡片任一区域 → 弹出**中等浮框**展示完整内容（列表/图表/矩阵）。浮框仍不遮挡右侧行情/聊天面板。

### 6.2 摘要内容（分三组）

| 分组 | 摘要卡片 | 默认态必须展示 | 点击后展示 |
|---|---|---|---|
| 投研 | 资金面情绪 | DR007、情绪四值、松紧结论、更新时间 | 情绪明细、指标口径、历史走势 |
| 投研 | AI 投研观点 | 方向、建议 bp、置信度或依据摘要 | 完整观点、依据、风险提示 |
| 基准价格 | 今天大行价格 | 核心期限报价小表，如隔夜/7D/14D 的银行价与涨跌 | 大行各期限完整报价表 |
| 基准价格 | 交易所回购 | GC/R 代表品种、最新价、涨跌 bp、成交量 | GC/R 系列完整列表 |
| 基准价格 | XREPO | 代表期限、正/逆回购利率、可点击量/挂单量、更新时间 | 完整挂单、可发送操作 |
| 基准价格 | NCD 同业存单 | 代表期限/评级、最新收益率、涨跌 bp、迷你趋势 | 一级/二级切换、趋势图、完整表格 |
| 走势统计 | 加权价格走势 | 当前产品/期限、最新加权价、涨跌、成交量柱或迷你线 | 多周期价格线 + 成交量 |
| 走势统计 | 匿名成交走势 | 代表期限、日内加权均价、相对均线偏离、迷你趋势 | 日内加权利率/成交量图 |
| 走势统计 | 机构分期限统计 | 当前期限、当前指标、领先机构类型/最高最低摘要 | 机构类型 × 期限 × 指标矩阵 |

> 分组仍使用“投研 / 基准价格 / 走势统计”，但视觉单元从入口条改为摘要卡片。
> 中栏的价值标准是“不点开也能辅助判断”，点击只是查看证据和完整数据。

### 6.3 与顶栏、右栏的分工

- 顶栏资金面信息是全局极简状态，保证任意三栏状态下都可见。
- 中栏资金面情绪卡负责补充解释，展示四值、更新时间和更完整的松紧判断。
- 右栏行情盘展示可交易对手和结构化报价，是交易动作的主战场。
- 中栏基准价格和走势卡只展示摘要，不替代右栏行情筛选、聊天触达和成交处理。

### 6.4 弹性收缩策略

优先级：**左栏任务 ≈ 右栏行情/聊天面板 > 中栏摘要区**。空间紧张时优先牺牲中栏，但保留最核心摘要信号。

| 阶段 | 触发 | 中栏表现 | 空间去向 |
|---|---|---|---|
| ① 宽松 | 100% 及以上 | 完整卡片：标题 + 主指标 + 支撑字段/小表/迷你趋势 | 三栏正常 |
| ② 紧张 | 缩放偏大 | 压缩卡片：保留标题 + 主指标 + 1-2 个关键字段 | 主要给右栏行情/聊天面板 |
| ③ 极限 | 150% 等 | 收成窄边/图标条，仅保留主题图标和异常/更新提示 | 右栏行情/聊天面板主导 |

- 极限态：点窄边图标 → 临时滑出摘要层，看完收回；功能不丢、常态不占空间。
- 左侧扩展分配矩阵展开时，中栏摘要区可折叠让位（见第 8 章）。

## 7. 右栏 · 非银行情与历史聊天对手（主战场）

右栏占最宽，承载两类高频信息：上半区展示结构化行情，下半区展示历史聊天对手。行情用于快速发现机会，历史聊天对手用于继续跟进私聊、成交与分配。

### 7.1 结构（自上而下）

1. **栏头 + 层级切换**：标题“非银报价盘”，1 级 / 2 级切换，保留刷新、下载、设置等入口。
2. **筛选条**：期限、发送机构、金额区间、利率区间、关注/相同交易对手等条件。
3. **上半区：行情报价**：按“利率地方 / 存单商金 / 信用”分组，每组横向展示 R001 / R007 / R014 / R021 / R028 等期限。
4. **上半区可切换：报价统计小页**：通过栏头 `统计` 入口查看按时间与期限聚合的报价利率、笔数和金额变化。
5. **下半区：历史聊天对手**：按“未回复 / 已回复 / 全部”切换，每条会话两行展示。

### 7.2 上半区行情结构

| 层 | 内容 |
|---|---|
| 第一层（分组） | 利率地方 / 存单商金 / 信用；每组带金额总量与利率均价 |
| 第二层（发送机构） | 每个发送机构一行，展示该机构在各期限上的报价 |
| 第三层（期限单元格） | R001 / R007 / R014 / R021 / R028 等期限单元格，展示利率 / 金额 |

> 行情表内部不展示方向字段。方向作为顶部上下文或筛选条件控制整块行情数据。

### 7.3 行情表字段

| 字段 | 含义 | 展示 |
|---|---|---|
| 状态 | 最优 / 次优 / 普通 | AI 自动标注，非交互标签 |
| 发送机构 | 报价来源机构 | 行首固定列 |
| R001 / R007 / R014 / R021 / R028 | 各期限报价 | 单元格展示“利率 / 金额”，无报价则显示 `--` |
| 限户要求 | 可专户 / 自营 / 年金户等 | 可在单元格或明细 tooltip 中展示 |
| 押券要求 | 利率债 / 信用债 / 国股存单等 | 可在单元格或明细 tooltip 中展示 |
| 操作 | 明细 / 聊天 | 点击可展开明细或打开聊天弹窗 |

### 7.3A 右栏报价统计小页

当非银报价不断新增时，交易员需要知道“什么时候报价变多、哪个期限利率抬升或下行、当前均价和高低点在哪里”。右栏顶部操作区增加 `统计` 入口，建议与层级和下载同组排列为 `1级 / 2级 / 统计 / 下载`。

统计页替换右栏上半区行情表，下半区历史聊天对手不变。统计页沿用当前筛选条件，统计对象为当前可见报价流水。

统计口径：

| 维度 / 指标 | 内容 |
|---|---|
| 横坐标 | 报价获取时间 |
| 统计维度 | 期限：R001 / R007 / R014 / R021 / R028 |
| 总计 | 每个时间点合并全部期限后的汇总 |
| 利率值 | 均价、最高利率、最低利率 |
| 数量值 | 报价笔数 |
| 金额值 | 总金额 |

图表表达：

- 总计均价作为主线，帮助交易员看整体报价中枢；
- 各期限均价作为细线，帮助区分不同期限变化；
- 底部小柱展示每个时间点的报价笔数；
- 最高 / 最低利率用范围线辅助判断报价离散程度；
- 汇总区展示总报价笔数、总金额、总均价、最高 / 最低；
- 明细区按期限展示报价笔数、均价、最高 / 最低、总金额。

### 7.4 下半区历史聊天对手结构

历史聊天对手不是完整消息流，而是当前右栏内的会话索引。每条固定两行：

| 行 | 内容 | 示例 |
|---|---|---|
| 第一行 | 期限 / 分组 / 限户要求 / 金额 / 利率 / 押券 | `R007｜利率地方｜可专户｜5.0亿｜@1.42｜利率债` |
| 第二行 | 用户名 / 机构 / 最新回复 / 时间 | `kai123｜某农商行｜最新回复：可以，5亿给你｜10:53:27` |

切换项：

| Tab | 含义 |
|---|---|
| 未回复 | 对手最新消息未处理，或 AI 判断需要我方响应 |
| 已回复 | 最后一条为我方回复，当前无需立即处理 |
| 全部 | 所有历史聊天对手 |

### 7.5 交互

| 操作 | 动作 |
|---|---|
| 点击行情单元格 | 高亮该行情并打开/定位到对应聊天弹窗，弹窗顶部带本条报价摘要 |
| 点击“明细” | 展开该发送机构或该期限的押券、限户、原始消息等明细 |
| 点击“统计” | 上半区切换为报价统计小页，按时间横轴和期限维度统计报价 |
| 点击历史聊天对手 | 打开对应聊天弹窗，并定位到最新消息 |
| 未回复 / 已回复切换 | 仅切换下半区历史聊天对手列表，不影响上半区行情 |
| 期限筛选 | 同时过滤上半区行情与下半区相关聊天对手 |
| 实时刷新 | 行情单元格、会话摘要与最新回复闪烁更新 |
| 与左栏联动 | 点左栏缺口账户后，上半区可满足账户的行情高亮；下半区相关会话同步高亮 |

### 7.6 规则

- 右栏上半区只展示行情，不混入完整聊天消息流。
- 右栏报价统计小页只替换上半区，不替换下半区历史聊天对手。
- 右栏下半区只展示历史聊天对手索引，每条两行，不展开长聊天。
- 完整聊天仍通过聊天弹窗承载。
- 正回购 / 逆回购不再上下同屏；方向用于切换或过滤当前行情上下文。
- 高频场景下行情为只读实时流，不提供报价修正入口。

## 8. 全屏分配矩阵（任务完整视图）

分配是"任务为核心"闭环中信息量最大、最具含金量的界面，同时是左栏台账的**完整视图**。矩阵是左侧任务面板的扩展形态，不是独立表格页面。

### 8.1 与左栏台账的关系

- 左栏台账 = 精简视图（仅 5 列）。
- 全屏矩阵 = 左侧任务面板扩展后的完整视图（指令表全字段 + 对手分配列）。
- "展开"与"分配"通向**同一张全屏矩阵**。

### 8.2 触发与布局变形

- 触发入口：左栏台账“展开”、待分配“分配”、聊天弹窗快捷分配区“转全屏矩阵”。
- 布局变形：进入时以左侧任务面板扩展形态展开，可扩展到工作区宽度；中栏摘要区可折叠让位；右上角"收起"自动保存并返回常态三栏。

### 8.4 关键规格

- **格子手动敲数字**；AI"自动分配"可先填一版，再手动调整。
- **允许留差额**：不强制分完，未分配额度可留存，差额非 0 也能保存。
- **成交批次列**：二级列按成交批次生成；同一机构、同一期限再次成交时新增二级列，不与已有 `R001` / `R007` 列合并。
- **冻结窗格**：对手列 20+，左侧账户信息 + 金额分组冻结、顶部机构/期限表头（含总额/差额）冻结，中间格子区横向/纵向滚动（Excel 冻结窗格体验）。
- **双向校验**：纵向校验账户是否凑够未出，横向校验对手额度是否分完。
- **差额提示**：顶部差额行 >0 允许保存，<0 只高亮提示，不阻断自动保存。
- **工具栏入口**：当前成交摘要、AI 自动分配、清空、保存分配、新增需求、广播、收起；"新增需求""广播"在界面占位，功能本期暂不展开。
- **自动保存回写**：点击收起时自动保存当前草案；手动保存或自动保存后回写矩阵金额分组和左栏台账（总额、差额、完成度、待分刷新，保本重算）。

#### 8.4.1 本次矩阵口径影响范围

| 范围 | 影响 |
|---|---|
| 左侧线框 | 全屏矩阵最左侧固定为选择、账户ID、账户简称、期限、指令、金额分组，不再按左栏精简台账列复用 |
| 表头结构 | 右侧分配矩阵采用机构一级表头 + 成交批次二级表头，期限只是成交批次属性，机构下可展开多列 |
| 汇总行 | 顶部总额行、顶部差额行、底部总计行均为矩阵必备结构，且为只读计算结果 |
| 回写逻辑 | 手动保存或收起自动保存后，同步刷新矩阵金额分组、底部总计、左栏台账进度和待分配余额 |
| 不影响范围 | 聊天弹窗快捷分配仍是轻量表格，只处理当前成交的一笔可分账户，不展示完整矩阵 |

### 8.5 AI 自动分配逻辑（概要）

> 详细算法另行评审，此处给出主干环节。

1. **接口校验（最硬约束）**：调后台校验账户准入白名单、剩余可投额度、账户要求与质押要求匹配。账户限制数据须经接口实时获取，不依赖前端静态数据。
2. **保本约束**：剔除保本利率高于成交利率的账户。
3. **优先级排序**：按既定优先级（如保本紧迫度、完成度、缺口规模）对候选账户排序。
4. **按序灌水**：从高优先账户起逐个填满，受账户剩余额度二次约束。
5. **生成方案**：快捷分配面板只展示可分配账户；本期全屏矩阵不展示不可分账户及原因。

## 9. 聊天弹窗与快捷分配

### 9.1 报价自动解析

- 交易员与对手仍按习惯在私聊中用自然语言沟通。
- AI 实时将口语消息解析为结构化行情（品种/期限/价/对手/限户/押券），自动填入右栏上半区行情。
- 右栏下半区同步生成或更新历史聊天对手摘要。
- 高频场景下行情不修正、来不及修正 → 行情区为只读实时流。

### 9.2 聊天弹窗

| 区域 | 内容 |
|---|---|
| 形态 | 浮于上层，不占栏位，左栏任务与中栏摘要区始终可见 |
| 顶部 | AI 解析出的报价摘要（品种/期限/价/限户/押券/建议） |
| 中部 | 私聊消息流（左右气泡） |
| 成交确认 | AI 识别 done / 成交后，展示成交摘要 |
| 快捷分配 | 成交确认后在弹窗下半部展开，只展示可分配账户 |
| 底部 | 回复框 + 发送 |

### 9.3 快捷分配面板

快捷分配用于处理当前聊天中的“这一笔成交”，不是完整账户 × 对手矩阵。

| 字段 | 含义 |
|---|---|
| 账户/产品 | 可分配账户简称 |
| 期限 | 账户任务期限 |
| 未出 | 当前账户剩余缺口 |
| 保本 | 账户保本利率 |
| 可分上限 | 该账户本笔最多可分金额 |
| 建议分配 | AI 推荐金额 |
| 分配金额 | 可编辑输入框 |

操作按钮：

| 按钮 | 作用 |
|---|---|
| AI 自动分配 | 根据可分账户、保本、未出、限户/押券约束自动填一版 |
| 清空 | 清除当前快捷分配输入 |
| 保存分配 | 保存已填金额并回写台账 |
| 挂入待分配 | 将本笔未分余额挂入左栏待分配区 |
| 转全屏矩阵 | 进入左侧扩展矩阵处理复杂拆分，并带入当前成交上下文 |

规则：

- 只展示可分配账户，不展示不可分配账户。
- 输入分配金额时，只允许数字与小数点。
- 分配金额不得超过该账户可分上限，也不得超过本笔成交剩余金额。
- 允许部分保存；未分余额可挂入待分配。
- 保存后回写左栏台账，更新已出、未出、完成度与保本测算。
- 点击“转全屏矩阵”时，自动带入对手、期限、成交总额、成交利率、方向、已填金额、待分余额和 AI 草案。

### 9.4 多会话（高频场景）

- 右栏下半区作为历史聊天对手索引，负责未回复 / 已回复 / 全部的快速切换。
- 完整会话仍通过聊天弹窗打开。
- 弹窗并发策略保留配置项：`chatPopup.mode = 'replace' | 'multi'`，默认 `replace`。

## 10. 关键依赖与待确认事项

### 10.1 后端 / 接口依赖

## 11. 术语表
