# 资金交易智能工作台 · 纯线框图

> 来源：根据工作台线框图片与评审讨论转写为 Markdown 纯文本线框。
> 目的：用于产品、设计、研发评审页面结构、信息层级与关键交互，不依赖图片查看。
> 本版更新：中栏从“投研 / 行情入口”升级为“投研 / 行情数据摘要区”；右栏改为“上：行情报价 / 下：历史聊天对手”；聊天弹窗增加“快捷分配”面板，且只展示可分配账户；分配矩阵作为左侧任务面板扩展形态，采用“左侧冻结账户列 + 金额分组 + 机构/成交批次双层表头 + 总额/差额行 + 底部总计行”的统一线框模式。

## 01. 主工作台常态（1920 × 1080）

## 02. 左栏任务模块

### 区域标注

| 编号 | 区域 | 说明 |
|---|---|---|
| 1 | 试算利率 | 可编辑输入，作为测算基准利率，影响完成度与保本利率计算 |
| 2 | 交易单台账 | 展示账户在不同期限下的任务台账信息 |
| 3 | 行状态 | 正常、保本预警、已完成三类状态 |
| 4 | 待分配额度 | 展示尚未分配的成交额度 |

## 04. 右栏非银报价盘 / 聚合聊天面板

### 区域标注

| 编号 | 区域 | 说明 |
|---|---|---|
| 1 | 栏头与当前方向 | 非银报价盘标题、正回购 / 逆回购互斥切换、1级 / 2级切换 |
| 2 | 筛选与期限标签 | 发送机构搜索、期限标签、刷新、筛选；期限标签用于定位或过滤行情 |
| 3 | 上半区：行情报价 | 按“利率地方 / 存单商金 / 信用”分组，展示发送机构在各期限的报价 |
| 4 | 下半区：历史聊天对手 | 按未回复 / 已回复 / 全部切换，每个对手两行展示 |
| 5 | 行情与聊天联动 | 点击行情可定位相关聊天对手；点击聊天对手打开聊天弹窗 |
| 6 | 实时刷新 | 行情报价、聊天未读、最新回复实时更新并闪烁提示 |

### 结构口径

| 区域 | 口径 |
|---|---|
| 最左侧冻结区 | 选择、账户ID、账户简称、期限、指令、金额分组固定展示，横向滚动时不离屏 |
| 金额分组 | 总额、差额、完成度、待分，随分配格子实时重算 |
| 右侧矩阵区 | 一级表头为机构 / 对手方，二级表头为成交批次；期限只是成交批次列的属性，示例中的 `R001` / `R007` 不代表按期限合并 |
| 顶部汇总行 | 总额行、差额行位于账户明细行上方，并随纵向滚动保持可见 |
| 明细格子 | 账户 × 机构成交批次，格子内录入该账户分到该成交批次列的金额 |
| 底部总计行 | 汇总指令、总额、差额、完成度、待分和各机构成交批次列已分金额 |
| 矩阵定位 | 作为左侧任务面板的扩展视图，不作为独立表格页面 |
| 收起保存 | 点击收起时自动保存当前草案并回到常态三栏 |

### 校验规则

```text
对手列差额 = 0  ：该机构成交批次列已分完
对手列差额 > 0  ：该机构成交批次列仍待分配，允许保存
对手列差额 < 0  ：该机构成交批次列超分配，高亮提示
账户行差额 = 指令 - 总额，待分 = max(账户行差额, 0)
底部总计行汇总指令、总额、差额、完成度、待分和各机构成交批次列分配金额
```

### 影响范围

| 范围 | 影响 |
|---|---|
| 视觉线框 | 全屏矩阵以本节为基准，不再使用仅“账户 / 期限 / 未出 / 进度”的简化表头表达完整分配 |
| 左栏台账 | 常态左栏仍保留精简视图，完整字段通过左侧任务面板扩展矩阵展开 |
| 交互规格 | 冻结列、冻结表头、总额/差额行、底部总计行需要统一滚动与只读规则 |
| Vue 原型 | mock 数据、表头渲染、sticky 布局、横纵向滚动、成交批次列和汇总计算都需要按该模式实现 |
