# TDX Theme Design Guide

## 主题定位

这个主题不是蓝色金融看板，而是更接近通达信证券终端的交易界面：深黑紫底、红色主激活、米金色行情文字、高密度表格、低装饰、弱圆角、弱阴影。

第一眼应当是“暗、密、稳”。红色承担主激活和关键负向状态，绿色承担正向状态，米金色承载主要行情数据。

## 全局规则

- 页面主背景使用 `#0d0d13`，面板使用 `#15151d`，表头和顶部导航使用 `#292835`。
- 不应出现白底、浅蓝底、浅灰卡片底、大面积纯白文字、大圆角卡片和明显渐变装饰。
- 圆角以 `0px - 4px` 为主，重复数据单元和 badge 保持小方角。
- 阴影只用于必要浮层，主交易界面优先依靠边框、背景层级和分割线。
- 字体优先使用系统中文无衬线，数字列保持等宽或接近等宽排布。

## 顶部导航

- 主导航、二级 tab 的激活态统一使用红色块 `--tdx-red`。
- 非激活态使用深灰紫背景和灰紫文字，hover 可以轻微提亮背景。
- 导航高度保持紧凑，避免大面积留白。
- 激活项不要使用蓝色下划线或浅色高亮。

## 表格

- 核心报价区优先服务表格密度，行高建议 `28px - 30px`。
- 表头使用深紫灰背景，字号建议 `12px - 13px`。
- 横向网格线保留，纵向分割线弱化。
- 普通行情数字使用米金色，不使用纯白。
- Bid、成交、负向数值使用红色；Ofr、正向数值使用绿色。
- hover 行使用轻微深灰紫提亮，不做明显卡片阴影。
- 固定列、数字列和状态列需要保持对齐，不因标签长度导致行高变化。

## 左侧筛选区

- 筛选项使用小型 tag filter，不使用大按钮。
- 普通态：深灰底、灰紫文字、弱边框。
- 选中态：红色边框或红底，文字使用红色或浅色。
- 输入框使用深色背景、弱灰边框，placeholder 使用灰紫。
- 筛选区保持高密度，组与组之间用细线或小间距分隔。

## 标签和状态

经纪商 badge 使用小方角，色彩稳定映射：

| 标签 | 建议颜色 |
| --- | --- |
| 国利 | 蓝色 `--tdx-blue` |
| 中诚 | 绿色 `--tdx-green` |
| 平安 | 橙色 `--tdx-orange` |
| 国际 | 红色 `--tdx-red` |
| 信唐 | 紫色 `--tdx-purple` |
| 上田 | 黄色 `--tdx-yellow` |

业务标签如“新”“免税”“回售”等应控制尺寸，避免变成胶囊按钮。建议高度 `18px - 20px`，圆角 `2px`。

## 图表和弹窗

- 主交易页面里的图表容器保持深底，不使用浅色图表卡。
- tooltip、popover、下拉层使用深色终端风格。
- 设置类、配置类、管理类弹窗可以使用白底，但交易主流程浮层仍建议保持深色。
- 图表颜色要降低饱和度，避免和红绿报价争夺视觉焦点。

## 开发顺序

1. 新增或替换主题 token。
2. 改全局背景、正文色、边框色。
3. 改顶部导航和 tab 激活态。
4. 改表格密度、表头、行 hover、数字颜色。
5. 改左侧筛选、输入框、按钮、badge。
6. 改图表、tooltip、popover、弹窗。
7. 使用 `1920x1080` 视口检查密度、对齐、截断和滚动表现。

## 验收标准

- 页面里不再出现白底、浅蓝底、浅灰卡片底。
- 顶部激活、主要 tab 激活统一为红色。
- 主要行情数据是米金色，红绿只用于买卖、涨跌、状态。
- 表格行高紧凑，第一屏信息密度接近交易终端。
- 左侧筛选是小 tag 风格，不是大号后台按钮。
- 卡片化、渐变、强阴影、大圆角被明显收敛。
- 在 `1920x1080` 下，主要区域对齐稳定，文字没有互相遮挡。
